> 全部通过 `npx tsc -p ./` 编译（0 错误）。产物在 `dist/`。

## 本阶段新增实现

### P0 收尾
| 模块 | 文件 | 说明 |
|------|------|------|
| options XML 完整解析 | `src/compiler/optionsLoader.ts` | 移植 `compiler.cpp LoadDefaultOptions`，支持 `extends` 继承、`<if platform>/<else>`、`<Common>` 引用、`<Category>`、`<Program>/<Switch>/<Option>/<Command>/<Sort>/<RegEx>` |
| 增量编译 | `src/build/buildEngine.ts` | mtime 比对，跳过未变更文件；rebuild 强制重编译 |
| wxRegEx→JS 兼容 | `optionsLoader.ts` | 修复字符类开头 `]` 语义差异（POSIX vs JS） |

**关键修复**：Code::Blocks 的 FILE 字符类 `[][{}()...]` 依赖「`]` 放首位是字面字符」的 POSIX 语义，JS 正则不支持。通过 `\[\]` → `[\]` 转义解决，错误行解析已验证正确。

| 编译选项 UI | `src/ui/compilerOptionsPanel.ts` | Webview 按 Category 分组展示 `<Option>`，勾选写回项目/目标编译选项 |

**实测**：本机成功探测到 MinGW-w64 GCC 8.1.0（`D:\Program Files\mingw64`）。
