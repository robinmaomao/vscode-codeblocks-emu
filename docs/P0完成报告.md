## 核心设计（与提示词定位一致：原生移植，非桥接）

1. **不依赖 tasks.json/launch.json**：构建由 `BuildEngine` 直接 `spawn` 编译/链接进程完成。
2. **命令模板 + 宏展开**：完整移植了 `$compiler $options $includes -c $file -o $object` 等模板，
   以及 Code::Blocks 的宏替换表（含 `$objects_output_dir` 必须在 `$object` 之前的顺序约束）。
3. **错误解析**：把 `options_common_re.xml` 的 POSIX 字符类正则（`[[:blank:]]`）转成 JS 正则，
   映射为 VS Code `Diagnostic`。

## 已知简化（后续阶段补齐）
