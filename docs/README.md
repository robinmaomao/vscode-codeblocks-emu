## 归档

- [`archive/`](./archive/)：历史盘点与核查报告（功能盘点 / 编译链接对齐 / 批次核查 / buildlog 专项 / 开关与 UI 核查 / 性能补充核查 / 代码审计）——已实施明细见 [`release/`](./release/) 对应版本。
- [`archive/开发进度-版本历史（~0.8.89）.md`](./archive/开发进度-版本历史（~0.8.89）.md)：0.8.89 及以前逐轮条目（原文保留）。
- [`release/`](./release/)：逐版本发布说明；`0.8.2`–`0.8.46` 已合并为 [`release/archive/0.8.2~0.8.46.md`](./release/archive/0.8.2~0.8.46.md)。

## 维护约定

- 提交/推送日志不写轮次编号；新增核查报告用主题命名；**实施完毕后归档到 `archive/`，待决项同步并入 [遗留问题决策清单.md](./遗留问题决策清单.md)**。
- 新增发布说明：`release/0.8.xx-dev.md`；版本摘要同步到 `开发进度.md` 第九节一行链接。
- 代码约定（空 catch 需注释、无 `console.*`、无 `@ts-ignore`）由 `tests/test-code-conventions.js` 自动检查。
