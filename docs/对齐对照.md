# 与 Code::Blocks 对齐对照表

> 本扩展的定位是**原生移植 Code::Blocks 的构建/调试内核**：直接解析 `.cbp` / `.workspace`、
> 内置 Code::Blocks 的命令模板与宏展开引擎、直接派生进程执行编译/链接/调试，**不是**
> `.cbp → tasks.json/launch.json` 桥接。本文档以表格逐项记录扩展与 Code::Blocks 的对齐依据
> （对应 `codeblocks-src/` 中的源码位置）、已对齐实现，以及有意保留的差异与尚未实现的限制。
> 最后更新：0.8.81-dev（2026-09-27）。

## 3. 有意的差异（保留，不追求逐字节一致）

| 差异 | 原因 |
|---|---|
| 引号规则更宽（空格 + cmd 元字符 `& \| < > ^ ( )`；CB 仅空格；含空格的编译器程序名也加引号——CB 不加会失败） | shell 二次解析防护；含空格库名的双层引号与 CB NeedQuotes 字节一致；可经 `codeblocks.build.strictQuoting` 开关为 CB 严格模式 |
| 脚本编号 `[script 1-3]`、单行完成式日志、Emoji 汇总块、最慢 Top3 | VS Code 环境下的可读性增强（用户已确认）；可经 `codeblocks.build.plainCbLog` 关闭为纯 CB 日志 |
| 中文日志文案 | 面向中文用户；可经 `codeblocks.log.english` 切换英文（汇总/状态类消息） |
| 输出目录创建失败提示：CB 模态弹窗 + 继续执行（必然失败的链接）；扩展错误日志 + 中止目标 | VS Code 模态弹窗阻塞扩展宿主进程，与异步构建/随时停止冲突；中止比徒劳执行更干净 |
| 响应文件长度阈值：CB 32767（CreateProcess 上限）/ 131072（Linux）；扩展 8000 | 扩展命令经 cmd.exe 执行（shell: true，支持 .bat/重定向），受 cmd 命令行 8191 上限约束；分割/转义/命名等其余行为一致 |
| CommandsOnly 目标 post 执行一次（CB 因 ttCommandsOnly 分支会执行两次） | CB 怪癖，不复制 |
| 时间戳粒度：CB 用秒（depsTimeStamp 的 time_t 比较），扩展用毫秒（mtimeMs） | 毫秒粒度更保守——同秒内先后写入的源/头文件也会触发重编译/重链接，CB 会判「已最新」；不会漏编，仅可能多编（用户已确认保留） |
| 构建前自动保存文件 | CB 普通 Build 不保存（SaveAllFiles 仅项目切换/工作区构建/DistClean/单文件编译，StartCompileFile:1103）；扩展在 Build/Rebuild/Clean/运行前统一保存（VS Code 环境增强） |
| WORKSPACE_DIR 多根工作区 | VS Code 无「当前工作区目录」概念（CB 单一 .workspace）；优先取 .code-workspace 文件目录，次首个文件夹，回退工程目录 |
