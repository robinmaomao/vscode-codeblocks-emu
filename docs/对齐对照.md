# 与 Code::Blocks 对齐对照表

> 本扩展的定位是**原生移植 Code::Blocks 的构建/调试内核**：直接解析 `.cbp` / `.workspace`、
> 内置 Code::Blocks 的命令模板与宏展开引擎、直接派生进程执行编译/链接/调试，**不是**
> `.cbp → tasks.json/launch.json` 桥接。本文档以表格逐项记录扩展与 Code::Blocks 的对齐依据
> （对应 `codeblocks-src/` 中的源码位置）、已对齐实现，以及有意保留的差异与尚未实现的限制。
> 最后更新：0.8.46-dev（2026-09-25）。

## 3. 有意的差异（保留，不追求逐字节一致）

| 差异 | 原因 |
|---|---|
| 编译器程序展开为**带引号完整路径**（CB 为裸名 + PATH 注入） | 防 PATH 注入失效时命令找不到；功能等价 |
| 引号规则更宽（空格 + cmd 元字符 `& \| < > ^ ( )`；CB 仅空格） | shell 二次解析防护；含空格库名的双层引号与 CB NeedQuotes 字节一致 |
| 脚本编号 `[script 1-3]`、单行完成式日志、Emoji 汇总块、最慢 Top3 | VS Code 环境下的可读性增强（用户已确认） |
