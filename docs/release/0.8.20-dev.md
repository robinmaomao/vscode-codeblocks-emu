# 0.8.20-dev

> 发布日期：2026-09-25

## 构建输出显示全面优化

### 编译日志结构

- **单行完成式**：每文件只输出一行 `✓ [Compiled] 123-248 xxx.c (2.0s)`，不再交错打印 `[Compiling]`/`[Compiled]` 两行（日志量减半、无乱序）。
- **进度序号**：`123-248`（当前/总数）便于观察进度。
- **每文件耗时**：编译失败时 `✗ [Failed]`（红色，原生日志级别）。

### 完整信息输出（设置控制）

- 新设置 `codeblocks.build.verboseOutput`（默认 `false`）：
  - 完整编译命令行（对齐 Code::Blocks 详细模式）
  - clean/rebuild 逐文件删除列表（`[Clean] <路径>`）
  - 增量跳过文件列表（`[Skipping] xxx.c (up to date)`）

### 阶段结构与计时

- 构建 Banner 对齐 Code::Blocks：`============== Build: Debug in app (compiler: RISCV32-V3) ==============`
- 阶段耗时：`[Code::Blocks] 编译完成 248 个文件 (42.1s)`、`✓ [Linked] app.rv32 (1.2s)`、`✓ [Archived] lib.a (x.xs)`
- pre/post build 脚本命令编号 `[script 1-3]`，子进程输出缩进区分层次
- 汇总追加「🐢 最慢」Top 3 文件

### 纯文本输出（根治乱码）

- **完全移除 ANSI 转义序列**：Output 面板与日志文件全链路纯文本，不再出现 `[1m[34m` 乱码。
- 层级表达改用官方日志级别（`error` 红 / `warn` 黄）+ 符号（`✓`/`✗`/`[script]`/`[Clean]`）。
- 序号/编号使用连字符（`123-248`、`[script 1-3]`），避免 VS Code Output 面板把 `123/248` 误判为路径链接产生蓝色下划线。
