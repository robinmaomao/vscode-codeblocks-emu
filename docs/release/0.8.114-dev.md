## P1 书签装饰热路径（每次按键整文档拆分 → 早退 + 按需取行）

- 原实现：`onDidChangeTextDocument`（每次按键）→ `refreshBookmarkDecorations` 首行 `ed.document.getText().split(/\r?\n/)` **整文档拆分**，无书签文件同样全量执行；
- 新实现：`src/tools/bookmarks.ts` 新增 `locateBookmarkLineInDocument(bm, doc, radius)`（`LineSource` 注入：只读书签行 ±50 窗口）；`extension.ts` 热路径先按文件过滤书签，**无书签直接早退**（`bookmarkDecoratedDocs` WeakSet 记录"曾设装饰"的文档，跳过重复 setDecorations）；`bookmarkGoto` 同步改用按需取行；
- 效果：每次按键开销 O(文档) → O(书签数×小窗口)，常见场景（无书签）→ O(书签表长度)。

## P2 兜底符号索引懒构建（打开工程不再同步全量读文件）

- 原实现：每次 `openProject`/`removeProject` 同步 `SymbolIndex.rebuild` 读取全部源文件；已装 clangd 的用户该索引仅被 Symbols 视图使用、兜底 provider 不生效——纯浪费；
- 新实现：`SymbolIndex.rebuildAsync`（分片 64 个/批，批间 `setImmediate` 让出）；`extension.ts` `markFallbackIndexDirty()`（只置脏）+ `requestFallbackIndexBuild()`（按需/单飞构建，构建完成刷新 Symbols 视图）；触发点＝兜底 provider 首次请求（`registerFallbackIntelliSense` 新增 onDemand 参数，四个 provider 均异步等待）或 Symbols 视图可见（`onDidChangeVisibility`）；
- 行为说明：首次兜底请求会等待一次异步构建（分片不阻塞 UI）；无 clangd 且从不使用补全/符号视图的会话零构建开销。

## P3 活动工程跟随（O(项目×文件) 全扫 → 属主索引 + 事件记忆化）

- 新增纯模块 `src/model/pathOwnerIndex.ts`（`buildPathOwnerIndex`/`findSoleOwner`/`normFilePath`）；`extension.ts` 惰性构建 + `invalidateOwnerIndex()`（`openProject` 起始、`removeProject` 两处失效——所有重解析路径均经由 openProject）；`syncActiveProjectToEditor` 精确匹配改 O(1) 查表 + `lastSyncMemo` 记忆化（同一文件重复触发跳过）；`hasSharedFiles` 结果按索引代缓存（语义保留旧实现：含目标文件 + `path.normalize`）。

## P4 新建工程向导编译器探测异步化

- 原实现：`getDetectedCompilers` 同步 `detectAllCompilers`（spawnSync gcc/clang/vswhere + 目录扫描，实测可达 0.3–1.5s 阻塞向导）；
- 新实现：删除同步包装；`pickCompiler` 改为 `loadDetectCache()` 跨会话缓存预填 + `detectAllCompilersAsync`（有缓存：后台异步刷新不阻塞；无缓存：await 异步探测，约 0.25s 且 UI 不冻结），探测结果写回同一缓存。

## P5 构建状态栏 250ms 定时器按需渲染

- 新纯模块 `src/ui/buildStatusRender.ts`（`nextBuildSpinRender` 状态机：'idle' | 秒数）；`extension.ts` 仅状态/秒数变化才重建 text/tooltip/command——空闲态零操作（不再每 tick 重建 `MarkdownString` tooltip），构建中每秒只渲染一次。

## P6 编译器 XML 结果缓存

- 新纯模块 `src/compiler/compilerCache.ts`（`buildCompilerCacheKey` + `BoundedMap`）；`extension.ts` `getCompiler` 命中缓存直接返回（键 = `id + masterPath + compilerPrograms` JSON——配置变化自动换键重建），未命中走新内部函数 `buildCompilerInstance`；全仓调用点已核查为只读、可安全共享实例；
- 效果：单次构建减少数次至十几次编译器 XML（含 extends 链）读+解析。

## P7 detectClangd 会话缓存

- `src/tools/clangd.ts`：`detectClangd` 带 TTL（5 分钟）缓存（含负结果）、拆出 `detectClangdUncached`、新增 `clearClangdDetectionCache`；`extension.ts` 监听 `clangd.path` 配置变化清除缓存。

## P8 工程树文件节点存在性异步化

- `src/ui/projectTreeProvider.ts`：节点创建不再同步 `fs.existsSync`——初始按存在渲染并登记异步检查（50ms 去抖 + 64 个/批 + `fs.promises.access`），发现缺失后更新为「缺失」并局部 `fire(node)`；`missingCache` 防重复 stat；`setProjects`/`setCategorize` 清缓存后重新检查；抽出 `applyFilePresentation` 供同步/异步共用（全目标归属时清 description，含从「缺失」恢复场景）。

## G1 + G3 输出时间戳惰性化 + 注释修正

- `src/build/cbChannel.ts`：`opts.timestamp` 由固定布尔改为 getter（与 `plainCb` 同款）——`codeblocks.build.outputTimestamp` **修改后即时生效（不再需重载窗口）**；package.json 描述与使用说明 §13 表同步更新；修正头注释「默认 true/默认开」与实际默认 false 的矛盾。
