## P1 Find file…（`projectmanagerui.cpp:2560-2690`）

- 新命令 `codeblocks.findFile`：命令面板（活动工程 / 多工程并列）与工程树右键（工程 / 文件夹 /
  虚拟文件夹 / 文件分组）——作用域即选中节点，复用 provider 新 API `filesUnder()`（对齐 `ListNodes`）。
- 未打开工程的工作区内 `*.cbp` 作为「工程文件」条目列出，选中即**打开工程**（对齐 `fileNameMap` 解析），
  不会当文本文件打开。
- 行为对齐 CB：默认仅在工程树中**逐级展开 + 选中定位**；新设置 `codeblocks.ui.findFileOpen`
  （默认 **false**，对应 CB `/project_manager/find_file_open`）为 true 时定位后同时打开文件。
- 为支撑 `TreeView.reveal`，`ProjectTreeProvider` 新增 **节点缓存 + `getParent`**：项目 / 目录 / 分组 /
  文件节点在缓存代内保持**同一对象实例**（`setProjects` / `setCategorize` 时失效重建），
  `findFileNode(project, file)` 按与懒加载相同的路径规则预建链条，`reveal(..., {select, focus, expand})` 可定位。
- 目录 / 分组节点补齐 `contextValue`（`folder` / `virtualFolder` / `fileGroup`），供右键菜单精确匹配。

## P2 Add files recursively…（`projectmanagerui.cpp:1625-1712`）

- 新命令 `codeblocks.addFilesRecursively`（Project 菜单 + 工程 / 文件夹 / 虚拟文件夹 / 分组右键）。
- 流程：选目录（默认工程根）→ 递归枚举 → `showQuickPick(canPickMany)` 默认全选 → 多构建目标时
  选归属目标（单选：全部 / 某目标）→ 写 `.cbp` → 重解析刷新。单目标 / 无目标时不弹目标选择（对齐 CB）。
- 新增纯模块 `src/project/recursiveAdd.ts`：
  - `enumerateRecursiveSourceFiles()`：跳过 `.git/.hg/.svn/CVS` 与 `obj/bin`（**保护性差异**：CB 仅过滤 SCM；
    但 CB 用文件组掩码全集，本扩展用源文件白名单，避免对象/依赖文件入工程），排除 `*.cbp` / `*.layout`，
    返回 POSIX 相对路径并排序；
  - `buildUnitXmlForTargets()`：`.c → CC`、Win `.rc → WINDRES`、其余省略 compilerVar；目标子集追加
    `<Option target="…">`（仅在「文件目标数 ≠ 工程目标数」时书写，对齐 `projectloader.cpp:1820-1841`）；
    XML 属性转义。
- 保护性差异：仅允许添加**工程目录子树内**的目录（CB 允许任意目录）。
