# Code::Blocks for VS Code 0.8.152

> 发布日期：2026-11-16 ｜ 体验版（0.8.151 → 0.8.152 逐项复核）

## 概述

🔍 本版以 Code::Blocks 源码为唯一基准，对 `Build options…` / `Properties…` 再做一轮逐项复核：对照 `project_options.xrc` + `projectoptionsdlg.cpp`、`compiler_options.xrc` + `compileroptionsdlg.cpp`、`editpairdlg.cpp`、`globals.cpp`、`select_target.xrc`，修掉 **11 项功能差异 + 6 项视觉 / 文案差异**，并按人工复核意见解除 3 项多余限制。

- 🧱 **Build options**：编译器标志与 `Other linker options` 双向同步（整串写入 / 反向勾选 / 冲突询问）；工程或目标带构建脚本时显示 CB 提示；`Linker executable` 只在目标作用域出现；自定义变量改用 CB 的键值对话框；属性面板内的覆盖层改为 `确定 | 取消`；切换编译器前先确认未保存改动。
- 🎛️ **Properties**：目标类型切换按 `OnProjectTypeChanged` 改写扩展名与 `lib` 前缀（不再受「自动生成」勾选限制，含 `$(...)` 宏名）；新增目标命名校验；修复「改完字段第一次点另一个目标无效」；`Selected file properties` 在自定义 Makefile 下恢复可用。
- 🧾 **构建脚本校验**：按 CB `DoCheckScripts` 三行文案一次列出全部问题，全通过显示 `All scripts seem to be valid!`。
- ⌨️ **Set Programs' Arguments**：保存时把参数中的换行统一替换为空格。
- 📐 规模不变：命令 **118**、设置 **88**、视图 **6**、快捷键 **34**。

## 🧱 Build options 再对齐

- **Compiler Flags ↔ Other linker options**（`OptionsToText` / `TextToOptions`）：勾选参数的 `additionalLibs` 以**整串**写入 `Other linker options`（此前误写进 Link libraries 且按空格拆分）；载入时按整串反向勾选并从文本隐去；取消勾选而文本仍保留时弹 `Enable compiler flags?`（是保留 / 否移除）。
- **构建脚本提示**：工程或任一目标存在构建脚本时，显示 CB `lblBuildScriptsNote` 的红字提示。
- **Linker executable**：仅目标作用域渲染（CB `Show(m_pTarget != nullptr)`），工程作用域整行隐藏；文案与 tooltip 用 CB 原文。
- **Custom variables**：新增 / 编辑改为 `EditPairDlg` 式键值对话框 —— 键名需匹配 `^[[:alnum:]_]+$` 才可确定、值可浏览目录、含空格时询问是否加引号；删除 / 清空用 CB 文案确认。
- **覆盖层按钮**：`Properties…` 内打开的 Build options 由单一「关闭」改为 `确定 | 取消`（取消丢弃本次修改，点遮罩等同取消）；独立面板保持 `保存 | 保存并关闭 | 还原设置`。
- **编译器切换**：未保存改动先问「应用改动后再切换？」（是 / 否 / 取消）；目标作用域建议完整重建；工程作用域先问是否同步到所有目标，再提示需要完整重建。

## 🎛️ Properties 再对齐

- **目标类型切换**（`OnProjectTypeChanged`）：GUI / Console → `.exe`、Dynamic → `.dll` + `libExtension` + `.def`、Static → `libExtension` + `lib` 前缀、Native → `.sys`，非动态类型清空导入库 / 定义文件。与 CB 一致**不看**「自动生成文件名前缀 / 扩展名」复选框，生成器对已带扩展名 / 前缀的名字幂等，`$(...)` 宏名同样在末尾追加扩展名。
- **目标命名**（`ValidateTargetName`）：新增 / 重命名 / 复制先询问名称（复制默认 `Copy of <title>`），拒绝空名、重名、与虚拟目标同名、含 `; , ! @ # $ % ^ & * " ' ~ = ? \ > <` 或反引号的名称。
- **列表点击**：切换到另一个目标 / 虚拟目标时不再因重渲染吞掉第一次点击。
- **启用联动**：`Selected file properties` 只依赖文件列表是否有选中行，自定义 Makefile 下恢复可用；构建脚本 ↑/↓ 需「有选中且条目数 > 1」。
- **字段展示**：`导入库文件名 / 定义文件文件名` 空值改为灰色占位符 `$(TARGET_OUTPUT_DIR)$(TARGET_OUTPUT_BASENAME)`，占位符不写盘，保存时按实际输入。
- **视觉 / 文案**：`工程的依赖… / 工程的构建选项…` 左对齐；目标类型 0 改为 `GUI application`；补「执行结束时暂停」tooltip；两段红字按 CB 分行；双击目标行打开其 Build options、双击文件行打开文件属性。

## 🧾 构建脚本校验与运行参数

- **脚本校验**：改为 CB 三行文案 `Invalid build script:` / `First seen in:` / `Error:`，一次列出全部问题（CB 遇错即停），并保留换行；全部通过显示 `All scripts seem to be valid!`。
- **Set Programs' Arguments**：保存时按 `TargetListData::SetExecParameters` 把参数中的换行替换为空格，避免 `.cbp` 写出多行 `parameters`。

## ⚠️ 行为变化与升级提示

- `Other linker options` 与编译器标志的库参数现在双向同步；此前被写入 `Link libraries` 的库参数会在下次保存时按 CB 规则归位。
- 目标类型切换会直接改写 `Output filename` / `Working directory` 的扩展名与前缀，不再要求先勾选「自动生成」；不保存则不生效。
- `导入库文件名 / 定义文件文件名` 为空时保存仍为空，不再自动写入默认宏。
- 构建脚本校验一次列出全部问题，结果为多行文本。
- `Set Programs' Arguments` 保存后参数不再保留换行。
- 不新增命令与设置项（保持 **118** / **88**），不修改 `.cbp` 数据模型与保存协议。
- 版本号 `0.8.152`；VSIX 文件名 `codeblocks-vscode-0.8.152.vsix`。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.152.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.152.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
