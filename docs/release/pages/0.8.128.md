# Code::Blocks for VS Code 0.8.128

> 发布日期：2026-10-09 ｜ 正式版（0.8.127 → 0.8.128 里程碑汇总）

## 概述

📌 本版为**增量小版本**：构建引擎与既有行为零变化，仅一处编辑器默认行为变更（汇编行注释，见下）。

- ⌨️ **汇编注释可配置**：`.s` / `.S` 行注释**默认 `//`**（预处理的 `.S` 安全）+ 新设置 `codeblocks.editor.asmHashComment`——开启后动态还原 GAS 原生 `#`（即时生效、无需重载）；
- 📝 **文档整理**：《扩展残留问题核查分析报告》归档 `docs/archive/`、去重与过期引用修正；
- 📖 **README 优化**：特性按主题分组、事实修正（编译器探测 / 输出通道 / 已知限制表）、新增 GitHub Releases 安装方式与 VS Code 1.85+ 要求。

## ⌨️ 汇编注释（0.8.128-dev）

- 默认值：`language-configurations/asm.json` 行注释标记 `#` → `//`（块注释保持 C 风格）；
- 新设置 `codeblocks.editor.asmHashComment`（boolean，默认关）：开启后经 `vscode.languages.setLanguageConfiguration('asm', …)` **动态注册** GAS 原生 `#`——`Ctrl+/`、`Ctrl+K Ctrl+C/U` 等全部注释路径一致；关闭即释放、自动回退静态 `//`；**修改即时生效**；
- 实测依据：原生 `.s`（GAS 直接汇编）在 RISC-V（binutils 2.28 / 2.43）与 x86 上均拒绝 `//`（整行 junk / 行尾 illegal operands / invalid char），`#` 才是 GAS 原生注释；`.S` 经 cpp 预处理则两者均可——默认 `//` + 开关并存。
