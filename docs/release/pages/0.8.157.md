# Code::Blocks for VS Code 0.8.157

> 发布日期：2026-11-19 ｜ 体验版（0.8.156 → 0.8.157）

## 概述

🔧 本版集中修复 0.8.156 新增功能的正确性与性能，并补齐 Code::Blocks 编译器资源与显示名。

- **AutoVersioning**：`version.h` 内容不变不重写；构建会话去重；`do_auto_increment`/`ask_to_increment` 生效；Bump/Generate 更新 manifest；SVN 字段与 Changes Log；version.h 加入工程。
- **Profiler**：拒绝旧 `gmon.out`；`gprof -A` `--separate-files` 回退；CSV/HTML 原子写。
- **编译器**：新增 `compiler_*.xml` 元数据加载（显示名/master 路径）；补齐 CB options/metadata；修正 `extends` 解析；新增 OpenWatcom/Cygwin/MSYS2/TDM/LCC/DMD/GDC/gfortran 探测。
- **规模不变**：命令 136 / 设置 91 / 视图 6 / 快捷键 34。

## ⚠️ 行为变化与升级提示

- `do_auto_increment` 开启后构建前可能弹版本递增确认；默认仍为关闭。
- `version.h` 内容不变不再刷新 mtime；需要刷新日期常量时执行 Generate Version Header。
- 新增编译器资源可手工选择；专有工具链是否自动探测取决于本机安装路径。
- XML 资源仍派生自 Code::Blocks GPL v3。
