# Code::Blocks for VS Code 0.8.133

> 发布日期：2026-10-22 ｜ 正式版（0.8.132 → 0.8.133 里程碑汇总）

## 概述

🎯 本版只做一件事：**构建日志补齐 Code::Blocks 的产物体积行**，让「链接成功」在两种日志模式下都能看到 CB 原文信息。

- 📏 **对齐 `CompilerGCC::OnJobEnd`**：链接成功（以及静态库 `ar` 打包成功）后输出 `Output file is … with size …`，档位 / 精度 / 边界与 Code::Blocks 完全一致；
- 🪵 **plain 模式也有成功行**：此前 `codeblocks.build.plainCbLog` 下没有任何成功提示，enhanced 模式只打印自研摘要行 `✔️ [Linked] …`；
- 🌐 **文案可本地化**：走 `logT()`，跟随 `codeblocks.ui.language`（中文为「输出文件为 …，大小 …」），`codeblocks.log.english=true` 时恒英文。

同时包含：`tests/test-output-file-size.js`（22 断言）与 E2E 构建矩阵 +3 断言（真实体积一致 / plain 模式仍输出 / 静态库输出）。

## 📏 实现（对齐 CB `CompilerGCC::OnJobEnd`）

- 链接成功后打印 Code::Blocks 的同一行：

  ```
  Output file is bin\Debug\hello.exe with size 478.53 KB
  ```

- 规则取自 `compilergcc.cpp`：`<1024` → `bytes`（小写）、`<1048576` → `KB`、否则 `MB`；一律两位小数（`512.00 bytes`）；判档用 `<`（1024 字节 ⇒ `1.00 KB`）；**无 GB 档**；产物读不到时不打印；
- plain 与 enhanced 两种日志模式都输出（plain 是 CB 原文基线；enhanced 另保留带耗时的摘要行）；
- 静态库目标同样输出（真实 `.a` 路径与体积）；
- 文案经 `logT()`，跟随 `codeblocks.ui.language`。

## ✅ 验证

- 新增 `tests/test-output-file-size.js`（22 断言）：档位 / 精度边界、缺失文件与目录降级、dist 接线（两处调用、走 `logT`、**不被 plain 门控**）；
- E2E 构建矩阵 +3 断言（真实体积与磁盘一致 / plain 模式仍输出 / 静态库输出）→ **48 断言**；
- 回归：`contract 2/2`、`unit 162 FAIL=0`、`e2e 4/4`、`pack 14/14`、`host 24/24`。

## ⚠️ 行为变化与升级提示

- 构建日志会多出一行 Code::Blocks 原文的产物体积行（plain 模式此前**完全没有**成功行）；
- 增强模式的 `✔️ [Linked] … (Ns)` 摘要行**保留**，两行并存；
- 无新增设置项；既有构建命令与增量语义零变化。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.133.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.133.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
