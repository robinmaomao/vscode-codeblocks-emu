# Originium IDE for Code::Blocks 0.10.0

> 发布日期：2026-11-20 ｜ 功能版（0.9.3 → 0.10.0）
> **主题**：Agent 变更审计与一键撤销（本地历史 / 字节级快照 / 冲突保护）

## 概述

自本版起项目更名为 **Originium IDE for Code::Blocks**：扩展 ID 为 `robinmaomao.originium-ide`，VSIX 文件名为 `originium-ide-0.10.0.vsix`；命令与设置前缀 `codeblocks.*` 保持不变，已有配置无需迁移。

功能上，0.9.x 让 Agent 可以完整控制 `.cbp` / `.workspace`，但误改后只能手工恢复。0.10.0 在 `invokeTool()` 统一挂钩：所有工具调用写本地审计，工程文件写入保存变更前字节快照；用户可以通过命令或 `@codeblocks` 撤销每个文件的**最新一条** Agent 变更。历史只存 VS Code 工作区扩展存储，不写工程目录、不进 Git，也不发送遥测。

## ✨ 新增

- **Agent Change History**：QuickPick 列出时间、工具、文件、大小与状态；可撤销、定位文件、复制路径、打开 `audit.jsonl`、清空历史。
- **Undo Last Agent Change**：撤销最近一次变更；确认框显示文件、工具、时间与大小。
- **`@codeblocks /history` / `/undo`**：与命令使用同一流程。
- **审计日志**：`audit.jsonl` 记录所有工具调用（工具、动作、结果、耗时、变更文件），不记录脚本/源码/full ops。
- **冲突保护**：撤销前校验 `afterHash`；外部修改默认拒绝，二次确认才强制覆盖；旧条目需先撤销同文件的新条目。
- **本地历史**：`context.storageUri/agent-history/`，默认 50 条 / 14 天；快照保留原编码与换行，可恢复 GBK/CRLF 工程。
- **Agent Status**：显示历史条数、审计字节数与存储路径。

## 🔒 行为变化

- 新增命令 2：`codeblocks.agent.history`、`codeblocks.agent.undoLast`；设置 2：`codeblocks.agent.history.enabled`（默认 `true`）、`codeblocks.agent.history.maxEntries`（默认 `50`）。
- 新增 `codeblocks.agent.history.enabled` 默认开启：本地保存工程文件快照；未受信任工作区不采集。
- 撤销只在 VS Code 扩展内可用（LM Tools / `@codeblocks`）；`cb-cli` 与外部 MCP 客户端没有工作区存储，不提供跨进程撤销。
- 构建/调试进行中拒绝撤销；历史写入失败只记输出通道，不影响工具结果。
- 不做 redo、任意文件撤销、逐行 diff 或 Git 集成。

## ⚠️ 行为变化与升级提示

- **扩展 ID 变更**：`robinmaomao.codeblocks-vscode` → `robinmaomao.originium-ide`；安装/卸载命令与 VSIX 文件名随之变化。
- 命令、设置、视图与键位 ID 全部保持不变（`codeblocks.*`），已有 `settings.json`、键位覆盖与 clangd 配置片段继续有效。
- 从旧 VSIX 升级时建议先卸载旧扩展，再安装 `originium-ide-0.10.0.vsix`，避免两个 ID 并存。
- 要求 VS Code **1.102.0+**。

## 📦 安装

```powershell
code --install-extension originium-ide-0.10.0.vsix --force
```

或从 Marketplace 安装：

```powershell
code --install-extension robinmaomao.originium-ide
```
