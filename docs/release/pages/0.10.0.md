# Originium IDE for Code::Blocks 0.10.0

> 发布日期：2026-11-20 ｜ 功能版（0.9.3 → 0.10.0）
> **主题**：Agent 变更审计与一键撤销

## 概述

自本版起项目更名为 **Originium IDE for Code::Blocks**：扩展 ID 为 `robinmaomao.originium-ide`，VSIX 为 `originium-ide-0.10.0.vsix`；命令/设置前缀 `codeblocks.*` 不变。

0.10.0 在 `invokeTool()` 统一挂钩：所有 Agent 工具调用写入本地审计，`.cbp` / `.workspace` 写入保存变更前字节快照，可用命令或 `@codeblocks` 撤销每个文件的最新一条变更。历史只存工作区扩展存储，不写工程目录、不进 Git、不发送遥测。

**同时包含**：`Agent Change History`、`Undo Last Agent Change`、`@codeblocks /history` `/undo`、冲突保护（外部修改默认拒绝）、本地 50 条 / 14 天保留。

- 详细报告：[test-report-0.10.0.md](https://github.com/robinmaomao/vscode-codeblocks-emu/blob/main/docs/testing/archive/test-report-0.10.0.md)。

## ⚠️ 行为变化与升级提示

- 扩展 ID 由 `robinmaomao.codeblocks-vscode` 改为 `robinmaomao.originium-ide`；命令、设置、视图与键位 ID 保持不变。
- 从旧 VSIX 升级建议先卸载旧扩展再安装，避免两个 ID 并存。
- 新增 `codeblocks.agent.history.enabled`（默认 true）与 `codeblocks.agent.history.maxEntries`（默认 50）；要求 VS Code **1.102.0+**。

## 📦 安装

```powershell
code --install-extension originium-ide-0.10.0.vsix --force
```

或从 Marketplace 安装：

```powershell
code --install-extension robinmaomao.originium-ide
```
