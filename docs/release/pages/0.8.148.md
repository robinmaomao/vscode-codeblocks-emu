# Code::Blocks for VS Code 0.8.148

> 发布日期：2026-11-11 ｜ 修复版（0.8.147 → 0.8.148）

## 概述

🐞 本版修复 **Build Log（诊断来源 `build`）里错误点击不跳转** 的残留场景，并兼容 ANSI 彩色编译输出。

- 🔗 **链接期错误真正可跳**：`src/main.c:(.text+0x9)` / `obj/Debug/main.o:(.text+0x9)` 形式的 `undefined reference` 不再回退到带段名的伪路径，落到真实源码/调用行。
- 📦 **对象文件不再当跳转目标**：`.o/.obj` 在链接阶段必然存在，现只作「找同名源码」的线索（工程索引 + 同目录源码回退）。
- 🧭 **无源码位置不再假装可点**：`ld.exe` / `collect2.exe` 等条目显示「无源码位置（链接器/工具输出）」，不挂跳转命令；打开失败会弹可见警告。
- 🎨 **ANSI 颜色输出兼容**：`-fdiagnostics-color=always` 的颜色转义在行解码阶段统一清理，Build Log / Problems 正常列出错误。
- 🧪 **回归**：新增/扩展 26 + 19 + 29 条单元断言与 9 条真实 gcc 链接期 E2E 断言。

规模（0.8.148 时点）：命令 **113**、设置 **85**、视图 **6**、快捷键 **34**（均未变化）。

## 🔗 链接期诊断定位

- 「无改善」判断改用原始 token 比较：剥掉 `:(section)` / `:line` 后落到真实文件即视为改善。
- `.o/.obj` 优先映射到同名源码（工程文件表 → 对象同目录的 `.c/.cpp/.cc/.cxx`），映射不到时不返回对象文件。
- 段名含函数名 → 定位到函数；只有 `.text` 时用消息里的未定义符号 → 定位到调用行（0.8.142 行为保留）。

## 🧭 无源码位置与 ANSI

- F4 导航与 Build Log 树节点共用 `isNavigableDiagnosticFile`：工具伪名、构建产物、残留段名、不存在的文件都不再挂跳转命令。
- 无源码位置条目在树中显示「无源码位置（链接器/工具输出）」，消息仍保留；点击跳转失败会弹出警告（不再静默）。
- Problems 面板（clangd 关闭时）对不可导航位置回退到工程根，避免指向不存在的文件。
- `stripAnsi` 在构建 / 脚本 / GDB 的行解码阶段统一清理 CSI/OSC 转义，`-fdiagnostics-color=always` 不再让整行解析失败。

## ⚠️ 行为变化与升级提示

- 无源码位置的诊断不再可点击（此前点击无反应）；Build Log 中会显示「无源码位置」提示。
- `.o/.obj` 不再作为跳转目标；找不到同名源码时只保留消息。
- 子进程输出中的 ANSI 颜色转义会被清理（日志更干净）。
- 不新增/修改设置项与命令；构建命令与产物零变化。
- 版本号 `0.8.148`；VSIX 文件名 `codeblocks-vscode-0.8.148.vsix`。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.148.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.148.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
