# Code::Blocks for VS Code 0.8.153

> 发布日期：2026-11-18 ｜ 体验版（0.8.152 → 0.8.153 里程碑汇总）

## 概述

🎛️ 本版对状态栏 `Menu`（Code::Blocks 菜单栏移植入口）做全量逐项排查与显示优化：9 个顶级菜单、168 个菜单项，对照 `main_menu.xrc`、`compiler_menu.xrc`、`debugger_menu.xrc`、`projectmanagerui.cpp`、`compilergcc.cpp`、`todolist.cpp`、`codecompletion.cpp`、`toolsmanager.cpp` 逐项核对。

- 🎨 **显示**：70 项无图标 → 0；非法 codicon `undo` → `discard`；11 条中英混排标签 → 0；`Copy` / `Duplicate` 译文重名修正；子菜单统一 chevron，description 只保留“快捷键 · 不可用原因”。
- 🧭 **结构**：一级收敛为 9 个菜单；Recent Files / Recent Projects / Workspace Build Order 移入 File；TODO List → View、Export Makefile → Build、Find/Changed line → Search、Remove Files / Save / Close / Properties 补齐。
- ⚙️ **可用性**：修正 `needsProject`，新增 `needsWorkspace` / `needsDebugSession`；Categorize 用图标显示开关；Settings 过滤串改为扩展作用域 + 设置组。
- 📐 规模不变：命令 **118**、设置 **88**、视图 **6**、快捷键 **34**。

## 🎨 Menu 显示与交互

- **所有菜单项统一图标**：仅使用 VS Code 1.85 已存在的 codicon；`tests/fixtures/codicons.json` 白名单 + 菜单展示模型回归保证 100% 覆盖。
- **子菜单与返回**：label 末尾统一 `$(chevron-right)`；每个子层级第一项为“返回”，标题显示 `Code::Blocks › File › …` 面包屑。
- **description 统一**：固定为 `快捷键 · 不可用原因`；不再混入“子菜单”等结构文案。
- **动态列表**：Recent / Workspace / Tools 自定义工具均有图标；最近工程显示相对路径与活动工程 ✓。
- **可过滤**：`matchOnDescription` / `matchOnDetail` 开启，可按快捷键检索。

## 🧭 结构与 Code::Blocks 对齐

- **File**：新增 `New ▸`、`Recent Files ▸`、`Recent Projects ▸`、`Workspace Build Order ▸`、Save Project、Close Project、Project Properties；按 CB 重排 Save / Close。
- **Edit**：按 CB 顺序重排；补 Uncomment、Select Skip、Fold / Unfold Current Block、Transpose；Find Selected 与 Goto changed line 移入 Search。
- **View**：TODO List 从 Search 移入。
- **Search**：Find / Replace / Goto / Changed line 按 CB 排序；Project Search 收拢为子菜单。
- **Project**：补 Remove Files…；Project Tree 子菜单与 Set Programs' Arguments → Notes → Build Options → Properties 顺序对齐。
- **Build**：Export Makefile… 从 Tools 移入 Build（backlog M1 完成）。
- **Debug**：新增 Debugging Windows ▸（Breakpoints / Call Stack / Variables / Watch / Registers / Disassembly）；Debug Information 更名 Information。
- **Tools**：自定义工具插到 Configure Tools… 之前（对齐 ToolsManager）。
- **Settings**：按 CB 顺序排列 Environment / Editor / Compiler / Debugger / Global Variables / Backtick Cache；clangd 维护入口收拢为子菜单。

## ⚠️ 行为变化与升级提示

- Menu 一级列表不再出现 Workspace / Recent Projects，改到 File 菜单内。
- 标签调整：`New…` → `New ▸ Empty File`；`Project tree` → `Project Tree`；`Debug Information` → `Information`；`Search Project Files…` → `Find Project Files…`。
- `Export Makefile…` 从 Tools 移到 Build；`TODO List` 从 Search 移到 View；Find Selected / Goto changed line 从 Edit 移到 Search。
- 菜单只展示扩展实际声明/托管的快捷键；Move Project Up/Down 的 Ctrl+Shift+Up/Down 仍只在工程树聚焦时生效。
- 不新增命令与设置项（**118 / 88 / 6 / 34** 不变），不修改 `.cbp` 数据模型与保存协议。
- VSIX 文件名 `codeblocks-vscode-0.8.153.vsix`。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.153.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.153.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
