# Code::Blocks for VS Code 0.8.127

> 发布日期：2026-10-09 ｜ 正式版（0.8.120-dev → 0.8.127-dev 里程碑汇总）

## 概述

🎯 本版两条主线：

- 🚀 **构建性能**：并行度默认值调优（全量 rebuild 实测约 70s → 40s）、环境准备改后台刷新、新增阶段计时探针；
- ⚡ **编译缓存**：新增 ccache / sccache 集成（默认关闭、零影响）——自动检测、一键引导安装、命中链真实实证。

同时包含：打包瘦身（VSIX -41%）、无效编译器日志与运行前校验对齐、4 项残留问题修复（X1–X4）、同步子进程超时收敛（Y2-A）。

## 🚀 构建性能（0.8.120）

- **并行度默认值**：默认并行任务数改为 `min(逻辑核数×2, 64)`。本机（4C/8T）实测全量 rebuild **68.6–77.2s → 38.5/40.9s（约 -45%）**；16 并发为效率拐点（96–98%）。内存紧张可调低 `codeblocks.build.parallelJobs`。
- **环境准备后台刷新**：Windows PATH 查询（2×reg.exe）由每次构建同步等待改为「首查同步 + 过期后台刷新」——热路径 **~150ms → ~1.0ms**。
- **阶段计时探针**：`codeblocks.build.profile`（默认关，或环境变量 `CB_BUILD_PROFILE=1`）输出 `[Code::Blocks,profile]` 分阶段耗时块，便于自行定位构建瓶颈。

## ⚡ R4 编译缓存 ccache / sccache（0.8.126 → 0.8.127）

- 新设置 `codeblocks.build.compilerCache`：`none`（默认，**零影响**——编译命令与基线逐字节一致）/ `ccache` / `sccache`；`codeblocks.build.compilerCachePath` 可显式指定工具路径（留空自动探测）。
- 仅对**标准编译命令**在 `$compiler` 展开点注入缓存前缀；链接 / 资源 / 库 / pre-post 脚本 / 自定义命令 / clangd 编译数据库均**不受影响**。
- **自动检测链**：显式路径 → PATH → 常见安装目录（WinGet Links / Scoop / cargo / Chocolatey / Program Files）→ WinGet Packages 便携包兜底；未找到时构建回退原编译器并告警一次。
- **提示与引导**：未安装 → 安装提示；检测到但未启用 → **每次打开工作区询问启用**（含「不再提示」，修改设置自动重置）；激活/重检结果（版本号 + 路径）写入输出通道；新命令 **`Install Compiler Cache…`** 一键复制/执行 winget 命令或打开官方下载页（不做静默安装）。
- **真实端到端实证**：启用后首次构建 miss → 删对象重建 **Direct 命中**（对象由缓存恢复）；工具缺失/无效路径 → 回退告警恰一次；路径恢复 → 重新生效。

## 🧠 A2 惰性命令生成（0.8.125）

- 收集阶段改为「先判过期、仅对过期/强制单元生成编译命令」（对齐 Code::Blocks `GetTargetCompileCommands` 判决顺序）；up-to-date 文件不再「先生成后丢弃」，每次构建省 ~0.25–0.31s。

## 📦 打包瘦身（0.8.123）

- 发布入口切换为 esbuild 单文件 bundle，依赖内联、`node_modules` 不再随包分发：**VSIX 199 文件/528KB → 74 文件/313KB（-63% / -41%）**。

## 📋 构建日志与运行前校验（0.8.121）

- 无效编译器消息完整对齐 Code::Blocks `PrintInvalidCompiler` 结构（含 `Skipping...` 独立条目与尝试路径；文案为扩展适配，含设置与探测命令修复指引）；
- `Run` 前增加同款校验：无效则输出完整消息 + `Run aborted...` 并中止。

## 🧩 残留问题核查修复 X1–X4（0.8.122）

- **X1**：缺 `<Option compiler>` 的工程/目标按 Code::Blocks 加载器缺省 `"gcc"` 解析，不再误判「无效编译器」；
- **X2**：平台不支持的目标补 Code::Blocks 原文跳过警告行；
- **X3**：调试器 launch.json 补 schema（`configurationAttributes` / 初始配置 / snippets）；
- **X4**：`.S` / `.s` 汇编文件补齐语言配置（`#` 行注释 + `/* */` 块注释）。

## ⏱️ 同步子进程超时收敛（0.8.124）

- 反引号命令展开与编译器版本查询的同步超时 15s/8s → **3s**（超时按失败缓存并回退），保护扩展宿主共享主线程。

## ✅ 验证

- 回归测试 **133 文件 FAIL=0 SKIP=1**（新增编译缓存 / 惰性命令生成 / 打包 / 调试器 schema / asm 配置等 11 个测试文件）；
- 真机构建自检 `headless-build-check` **EXIT 0**（含单文件编译 / Clean / distclean 链路，自动还原产物）；
- ccache 端到端复测 **18/18**（真实 ccache 4.14.1：miss → 命中 → 回退 → 恢复）；
- 文档链接校验 96 条 0 缺失；两次打包 bundle 哈希一致（可复现）。

## ⚠️ 行为变化与升级提示

- 编译缓存**默认关闭**，不改变现有构建行为；启用后首次构建为 miss，之后命中；
- 并行度默认值变化会提高 CPU 利用率（可用 `codeblocks.build.parallelJobs` 调低）；
- 检测到缓存工具但未启用时，**每次打开工作区**会询问（可「不再提示」或修改设置重置）；
- 缺 `<Option compiler>` 的工程不再跳过（按 `gcc` 缺省解析，X1）。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.127.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.127.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
