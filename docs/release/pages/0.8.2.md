# Code::Blocks for VS Code 0.8.2

> 发布日期：2026-09-23 ｜ 首个正式版

## 概述

🎯 首个正式版：把 Code::Blocks 的核心功能**原生移植**到 VS Code —— 直接驱动 GCC / GDB 的迷你 IDE 内核，而不是 `.cbp` → `tasks.json` 的桥接层。

- 📁 **原生工程解析**：直接读 `.cbp` / `.workspace`，完整还原项目 / 构建目标 / 文件模型（含虚拟文件夹），编辑后可写回；
- 🔨 **真实构建引擎**：不依赖 `tasks.json` / `launch.json`，按 Code::Blocks 的编译 / 链接命令逐条执行，支持增量编译（头文件 mtime 比对）；
- ⚙️ **编译器管理**：内置编译器模板 + 交叉编译器支持（自动读取 `default.conf`，RISC-V 开箱即用）；
- 🐞 **GDB 调试**：原生 DAP 适配器，断点 / 单步 / 调用栈 / 变量 / 寄存器 / 反汇编；
- ✨ **clangd 补全**：自动生成 `compile_commands.json` 并写入 clangd 用户配置，未安装 clangd 时回退内置符号补全。

同时包含：可视化工程属性面板、新建工程向导（Console / Static / Shared / Empty 四模板）、多项目管理、结构化 Build Log 与符号浏览器。

## 📁 打开 `.cbp` 工程并直接编译

- 原生解析 `.cbp` / `.workspace`，完整还原项目 / 构建目标 / 文件模型；
- 内置构建引擎，不依赖 `tasks.json`，增量编译（头文件 mtime 比对）；
- 可视化工程属性面板，编辑后写回 `.cbp`；
- 新建工程向导（Console / Static / Shared / Empty 四模板）；
- 交叉编译器支持（自动读取 `default.conf`，RISC-V 开箱即用）。

## ✨ 集成 clangd

- 自动生成 `compile_commands.json` 并写入 clangd 用户配置；
- 头文件智能回退上下文，解决嵌入式 SDK 的 `unknown type name`；
- 自动剔除 clang 不认识的 RISC-V / GCC 专属 flag；
- 未安装 clangd 时自动回退到内置符号补全。

## ⚠️ 行为变化与升级提示

- 首个版本，无升级兼容问题；要求 VS Code **1.85.0+**。
- 构建 / 调试**不写** `tasks.json` / `launch.json`，与常见 C/C++ 扩展的用法不同（这是本扩展的设计前提）。
