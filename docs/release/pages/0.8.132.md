# Code::Blocks for VS Code 0.8.132

> 发布日期：2026-10-22 ｜ 正式版（0.8.131 → 0.8.132 里程碑汇总）

## 概述

🎯 本版把扩展「中英混杂」的界面收口为**完整双语**：静态贡献全量走 nls（跟随 VS Code 显示语言），运行时文案由新设置 `codeblocks.ui.language` 控制并**即时生效**，构建日志也有统一的 `logT()` 出口。

- 🌐 **i18n 设施（本版新增）**：`src/i18n/core.ts`（纯逻辑：语言解析 / 占位符 / 查表）+ `src/i18n/index.ts`（`t()` / `uiLanguage()` / `refreshUiLanguage()`），字典随编译内联，无运行时文件 IO；
- 🈶 **静态贡献全量 nls**：107 条命令标题、77 项设置描述（含 9 条 `markdownDescription`、6 条 `enumDescriptions`）、5 个视图名、2 个容器标题、欢迎语、调试器片段、`displayName` / `description` 全部改 `%key%`，nls 键 **212** 个；
- 💬 **运行时文案全覆盖**：弹窗 / QuickPick / 状态栏 / 树视图 / 调试层 / WebView 面板 / 148 条菜单项，迁移点 **290 → 1123**、词条 **239 → 1072**（含 193 条中文→英文 WebView 反查）；
- 🎛️ **新设置与新命令**：`codeblocks.ui.language`（`auto` / `en` / `zh-cn`，默认 `auto`）与 `Code::Blocks: Switch UI Language…`（三态切换 + 重载窗口入口）。

同时包含：WebView 面板「源级插桩」（不替换渲染后文本）、`logT()` 统一构建日志、文档双语（`README.en.md` / `usage.en.md` / `i18n.en.md`）。

## 🌐 i18n 设施（本版新增）

| 新增 | 说明 |
| --- | --- |
| `src/i18n/core.ts` | 纯逻辑：`resolveLanguage(setting, envLanguage)`（`auto` + 显示语言 → `zh-cn` / `en`，非法值按 `auto`）、`formatSource`（`{0}` / `{1}` 占位符；缺参保留占位符原样）、`lookupTemplate`、`translate` |
| `src/i18n/index.ts` | 扩展入口：`t(source, ...args)`、`uiLanguage()`、`refreshUiLanguage()`、`translationsTable()`；语言进程内缓存（热路径不读配置），设置变更 / 激活时刷新 |
| `src/i18n/strings.zh-cn.json` | 词条表（**英文源串为键** → 中文译义），随 `resolveJsonModule` 内联进 dist / bundle |
| `tsconfig.json` | 新增 `resolveJsonModule`（导入 JSON 词条） |

设计取舍：**不使用** `vscode.l10n.t()` —— 标准机制只能跟随显示语言，无法满足「设置级强制切换」；字典仍按 l10n bundle 的「源串为键」风格组织，后续可平滑对接标准流程。命名空间调用 `i18n.t(...)`（文件内已有多个名为 `t` 的局部变量），消息模板禁止内插 `${}`（守卫拦截）。

## 🈶 静态贡献全量 nls

- `package.json`：107 命令标题、77 设置描述（含 9 条 `markdownDescription` 与 6 条 `enumDescriptions`）、5 视图名、2 容器标题、1 条视图欢迎语、2 条调试器片段描述、`displayName` / `description` 全部改 `%key%`；
- 中文原文逐条保留为中文 nls 值（`markdownDescription` 的锚点、`command:` 链接、`%APPDATA%` 等字面量原样）；英文为**新写**（68 条设置描述此前只有中文）；
- 二级占位符（nls 值本身是 `%key%`）会导致原样显示 `%key%` —— 本版修掉了新设置引入的这一处，并加入守卫。

## 💬 运行时文案全覆盖

- 迁移点 290 → **1123**、词条 239 → **1072**；WebView 采用**源级插桩**（`i18n.tr()` + 193 条中文→英文反查表，不翻译工程名等数据）；
- 覆盖：状态栏菜单与 **148 条菜单标签**、5 个树视图 provider、调试层（适配器 / MI 会话 / 调试配置）、构建引擎 5 个文件、clangd / 键位 / 统计等工具类与工程 / 模型 12 个文件、`extension.ts` 剩余日志与 UI；
- 构建日志统一走 `logT()`：`codeblocks.log.english=true` 时恒英文（Code::Blocks 原文口径），否则跟随 `ui.language`。

## ⚠️ 行为变化与升级提示

- **静态贡献**（命令标题 / 设置描述 / 视图名）跟随 **VS Code 显示语言**，切换后需 **Reload Window**；
- **运行时文案**跟随 `codeblocks.ui.language`，**即时生效**（无需重载）；
- 构建日志默认跟随 `ui.language`；需要恒英文（对齐 Code::Blocks 原文）可设 `codeblocks.log.english=true`；
- 已知限制：词条缺失一律回退英文源串（不会出现空白或键名泄漏）。
