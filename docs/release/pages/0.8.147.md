# Code::Blocks for VS Code 0.8.147

> 发布日期：2026-11-11 ｜ 体验版（0.8.146 → 0.8.147）

## 概述

🎨 本版把 **Project Search 的 Text 结果排版对齐 VS Code 内置 Search**，并修复**切换视图后另一种模式的搜索记录丢失**。

- ✍️ **排版对齐内置 Search**：匹配行改用界面字体（`--vscode-font-family`）与 `--vscode-font-size`，工程头 / 文件行 / 匹配行统一 **22px** 行高；行号右对齐、按本批最大位数定宽，不再占用固定列；预览从 200 字符收紧到 120。
- 🔊 **Files 模式补回「搜索」按钮**：`Files / Text / Search / All projects` 强制同一行（空间不足时先压缩下拉框，极窄兜底才换行）。
- 🕘 **搜索记录不再丢失**：侧边栏隐藏（切到 Explorer）会销毁 webview，现在 Provider 缓存两种模式的结果并在重新显示时直接回放，不重跑扫描；状态行也按模式记忆，切换模式不再显示另一模式统计。
- 🎚️ **开关修正**：`Keep history` 改为 `border-box`，滑块四周留白对称（此前底边多 1px、开启态右侧少走 2px）。
- 🚫 **Files 模式选项置灰**：文件搜索恒不区分大小写、不支持正则/全字匹配，`Aa` / `Ab` / `.*` 在 Files 模式禁用并提示「仅内容模式有效」。

规模（0.8.147 时点）：命令 **113**、设置 **85**、视图 **6**、快捷键 **34**（均未变化）。

## 🎨 Text 结果排版

- 匹配行字体：`--vscode-font-family`（界面字体，与内置 Search 一致），字号继承 `--vscode-font-size`。
- 行高：工程头 / 文件行 / 匹配行统一 **22px**（内置 `filematch` / `linematch` 同为 22px）。
- 行号：右对齐 + 等宽数字，列宽取本批最大行号位数（`--cb-line-num-ch`），代码左边缘稳定不跳动。
- 预览：`TEXT_PREVIEW_LENGTH = 120`（原 200），仍保留 `…` 前缀/后缀与命中高亮偏移计算。
- Text 模式不再单独覆盖工程头 / 文件行 / 徽标尺寸，与 Files 模式完全一致。

## 🕘 搜索记录保持

- 视图隐藏时 VS Code 会销毁 webview，之前只恢复“当前模式”，另一种模式的结果直接消失。
- 现在 `ready` 时通过 `postCachedResults()` 回放 `fileResults` 与 `textResults` 缓存（含 `matchCount`），不触发重新扫描。
- 缓存 query 与当前 query 不一致时不回放，避免恢复已清空/已改写的旧结果；当前模式无缓存且查询非空时才回退到重跑。

## ⚠️ 行为变化与升级提示

- 预览长度默认值 200 → 120 字符；`maxPreviewLength` 显式传参时不受影响。
- Files 模式下 `Aa` / `Ab` / `.*` 变为禁用（此前可点击但无效果）。
- 不新增/修改设置项与命令；不涉及构建、调试、clangd 行为。
- 版本号 `0.8.147`；VSIX 文件名 `codeblocks-vscode-0.8.147.vsix`。
