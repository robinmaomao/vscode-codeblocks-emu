# Code::Blocks for VS Code 0.8.151

> 发布日期：2026-11-13 ｜ 正式版（0.8.148 → 0.8.151 里程碑汇总）

## 概述

🧱 本版把 Code::Blocks 工程右键的 **`Build options…` / `Properties…`** 完整搬进 VS Code，并按 CB `project_options.xrc` 对属性面板做二次精修；同时补齐工程右键菜单与 `Project Tree ▸` 子菜单。

- 🧱 **`Build options…`（0.8.150）**：工程 / 目标两级编译器、链接器、搜索目录、构建前后步骤、自定义变量与 `"Make" commands`，独立面板与属性面板内的覆盖层共用同一套 `.bo-*` 视图。
- 🎛️ **`Properties…`（0.8.150 → 0.8.151）**：6 个页签完整移植；0.8.151 按 XRC 真实几何重排为单张 2 列网格、PCH `Strategy` radio box、构建目标文件列表回右栏、脚本页 1:2。
- 🖱️ **工程右键菜单**：分组顺序对齐 CB `00_save` → `06_extra`，新增 `Save Project` / `Close Project` / `Remove Files…` / `Project Tree ▸ (Expand All / Collapse All)`。
- 🧩 **还原设置**：Build options 与 Properties 均可丢弃未保存修改、回到上次保存值；WebView 内改用面板内模态，规避沙箱禁用 `window.prompt/confirm`。
- 🐞 **Expand All 修复**：清空节点缓存重建 + `reveal({ expand: true })` 兜底，并改为一次性请求。
- 📐 **规模**（0.8.151）：命令 **118**（+5）、设置 **88**、视图 **6**、快捷键 **34**。

## 🧱 工程右键与 Build options

- 工程节点右键 → `Build options…` 打开独立面板；目标节点右键打开并直接定位到该目标；`Properties…` 内以居中对话框打开同一视图。
- 编译器设置分「编译器标志 / 其它编译器选项 / 其它资源编译器选项 / `#定义`」，标志列表按分类分组，保留 CB 的右键菜单：新建 / 修改 / 删除参数、仅 C / 仅 C++ 参数、展开 / 折叠所有分类。
- 新增 `codeblocks.compiler.customFlags`、`codeblocks.compiler.flagOverrides`、`codeblocks.compiler.languageFlags`；只有当前选中的编译器受影响。
- 链接器设置拆为「链接库 / 其它链接器选项」并排卡片；`Linker executable` 工程级只读展示，并说明 CB 按目标保存该值。
- `"Make" commands` 中 `Silent build` 始终由 `Build` 派生（`> $(CMD_NULL)`，只读）；`Dist-clean` 仅在存在非默认值时只读显示。
- `Selected compiler` 自动匹配 `.cbp` 的 `<Option compiler="…" />`：`id` 精确 → 忽略大小写/连字符 → 名称；未注册时下拉标注「(未找到)」，不静默回退。

## 🎛️ Properties 版式对齐

- **Project settings**：改为 CB 的单张 2 列 FlexGrid，去掉浮动卡片；`执行目录` 回到 Makefile 右列子行；PCH 使用标题为 `策略` 的 radio box；`对象文件名生成` / `检查外部修改的文件` 为「左标签 + 右复选框 + 红字」。
- **Build targets**：左栏目标列表 + 竖排操作按钮与两个弹簧分组，↑/↓ 使用 SVG 箭头；右栏「所选构建目标选项」下方为 `Build target files:` 列表。
- **Build scripts**：左右 1:2；`校验所有已附加脚本` 位于左栏工程概览树下方；脚本列表右侧带上下 spin。
- **Notes / C/C++ parser**：去卡片、内容撑满；**Debugger** 子标签复用 Build options 的 `.bo-subtabs`。
- 页签、页脚、操作行、↑/↓、模态统一复用 Build options `.bo-*` 体系；控件 24px / 字号 12px / 行距 4px，窄面板（≤760px）自动上下堆叠。

## 🖱️ 工程菜单与 Expand All

- 分组顺序对齐 CB：`00_save` / `01_files` / `02_find` / `03_tree` / `04_build` / `05_options` / `06_extra`；保留扩展已有项（Build / Rebuild / Clean、Run / Debug、虚拟文件夹等）。
- 新增 5 个命令：`codeblocks.saveProject`、`codeblocks.closeProject`、`codeblocks.removeFiles`、`codeblocks.projectTree.expandAll`、`codeblocks.projectTree.collapseAll`。
- **Expand All 修复**：VS Code 只对新元素采用 `collapsibleState`；先清空 `nodeCache` / `dirIndexCache` / `parentMap` / `missingCache` 重建节点，再对工程节点 `reveal({ expand: true })` 兜底。
- 该请求为一次性：工程重载或切换分组后复位，不会再把用户折叠的节点重新顶开。
- `Project Tree ▸` 子菜单项补齐 `view == codeblocks.projectTree && viewItem == project` 条件，避免在其他树节点误现。

## 🧩 还原设置与 WebView 模态

- Build options 与 Properties 都新增「还原设置」：打开时对宿主数据做基线快照，保存成功后刷新基线；点击后确认放弃未保存修改，回滚全部草稿并重绘当前页签。
- WebView iframe 沙箱不含 `allow-modals`，`window.prompt` / `window.confirm` 会静默失效：调试器搜索目录的添加 / 编辑改用面板内 `askText`，还原设置改用 `confirmBox`。
- 底部按钮统一描边；Linker settings 全控件包入 CB 卡片；`保存` 使用默认按钮描边。

## ⚠️ 行为变化与升级提示

- 命令总数 113 → **118**；工程右键分组顺序变化，新增保存 / 关闭 / 移除文件 / Project Tree 子菜单。
- `Expand All` 为一次性操作，工程重载或切换分组后按默认折叠状态渲染。
- `Restore settings` 会丢弃当前未保存修改；保存成功后基线才更新。
- WebView 内不再调用 `window.prompt` / `window.confirm`（沙箱中本就无效）。
- `Silent build` 只读并跟随 `Build` 派生；`Dist-clean` 默认值不显示，存在自定义值时只读展示。
- 不新增设置项（总数保持 **88**），不修改 `.cbp` 数据模型与保存协议。
- 版本号 `0.8.151`；VSIX 文件名 `codeblocks-vscode-0.8.151.vsix`。

## 📦 安装

- 下载本页附件 **`codeblocks-vscode-0.8.151.vsix`**，或：

  ```powershell
  code --install-extension codeblocks-vscode-0.8.151.vsix --force
  ```

- 要求 VS Code **1.85.0+**；安装后请 **Reload Window**。
