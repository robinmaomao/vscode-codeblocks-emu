# Code::Blocks for VS Code 0.8.155

> 发布日期：2026-11-18 ｜ 体验版（0.8.154 → 0.8.155 里程碑汇总）

## 概述

🛡️ 本版是 P3 架构批次：WebView CSP 从 `unsafe-inline` 收紧为 nonce、`.cbp` 未知节点透传、激活期扫描优化、`extension.ts` 首批 Feature 拆分与架构文档。

- **WebView 安全**：五个面板（属性 / 构建选项 / 快捷键 / 程序参数 / 工程搜索）内联脚本统一 nonce + 公共 CSP/转义/JSON 注入运行时。
- **工程文件安全**：Project / Target / Unit 的插件自定义 XML 与未知 Unit Option 属性保存后不丢失。
- **启动/树性能**：`detect.autoOpen=off` 跳过激活期全量工程扫描；compile/link 切换改为模型就地更新 + 单节点刷新。
- **可维护性**：`features/toolCommands.ts` / `workspaceCommands.ts` / `newProjectCommands.ts` 三批拆分；新增架构与模块地图。

## ⚠️ 行为变化与升级提示

- WebView 内联脚本必须带 nonce；复制旧模板时需同步 CSP。
- `detect.autoOpen=off` 时不再显示待打开工程数量，需手动 Detect workspace projects。
