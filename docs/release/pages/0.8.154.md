# Code::Blocks for VS Code 0.8.154

> 发布日期：2026-11-18 ｜ 体验版（0.8.153 → 0.8.154 里程碑汇总）

## 概述

🧩 本版补齐 Code::Blocks 剩余高价值缺口，并收口一轮健壮性问题：Workspace 生命周期、`.workspace` 外部修改检测、无工程编译编码、指令级步进/内存查看、Backtick Cache、Copy Strings、Profiler (gprof)、SymTab 跨库符号、Makefile CompileFile/DistClean。

- 🗂️ **Workspace**：Save Project As / Save·Close·Open default workspace；关闭最后一个工程清理工作区状态。
- 🛡️ **健壮性**：`.cbp`/`.workspace` 原子写；含 `&` 等特殊字符的单元路径可正常添加/改名/切换 compile·link。
- 🐞 **调试**：Next Instruction / Step Into Instruction / Examine Memory…。
- 🧰 **工具**：Backtick Cache 管理器、Copy Strings、Profile Target、Find Symbol in Libraries。
- 🌐 **i18n**：launch.json 调试属性、寄存器视图标题、自定义工具说明全部 nls。

## 📐 规模

## ⚠️ 行为变化与升级提示

- 无工程编译默认使用扩展输出通道解码（UTF-8/GBK）；可用 `codeblocks.noProjectCompile.useTaskTerminal` 回退。
- 关闭最后一个工程会清空工作区状态；如需保留工程列表，请先 Save Workspace。
- Profiler/SymTab 为子集实现；call graph、源码注解、任意目录扫描未包含。
