# Code::Blocks for VS Code 0.8.144

> 发布日期：2026-11-07 ｜ 正式版（0.8.142 → 0.8.144 里程碑汇总）
>
> **分支预发布**：`0.8.144-feat.project-search`（`feat/project-search`）；本页为 0.8.144 正式版发布页底稿，分支验证阶段不创建 GitHub Release。

## 概述

🔎 本版新增**工程内搜索（Project Search）**：只搜索已打开 `.cbp` 工程，不替换 VS Code 内置搜索。

- 🗂️ **Sidebar 视图**：文件 / 内容双模式，活动工程优先，结果按「工程 → 文件 → 匹配」分组，点击直接跳转；
- 🎨 **UI 对齐内置搜索**：VS Code 字体与 22px 行高、内联 codicon SVG、`Aa` / `.*` / 清除内嵌搜索框、状态行工具条；工程头吸顶可折叠；
- ⚡ **性能**：文件模式纯内存 + prepared entries 缓存；内容模式 `worker_threads` 隔离、可取消、超时终止、失败回退；
- 🕘 **历史**：搜索栏顶部 **搜索历史** 按钮（含模式图标）+ `保留历史` 可视化 switch；点击历史优先跳转上次结果；
- ⌨️ **入口**：`Ctrl+Alt+P`、命令面板、C::B Search 菜单、工程树右键（子树范围）；
- 🛡️ **边界**：不写 `search.exclude`、不创建 watcher、不调用 `workspace.findFiles`；只搜 `.cbp` 中登记的文件。
- 🛠️ **修复**：视图声明 `"type": "webview"` 并提前注册 provider；新版 VS Code 默认按 TreeView 解析，缺省会显示“no data provider registered”而看不到搜索栏。
- 🛠️ **修复（clangd）**：打开/切换工程与改编译器时的连续重启请求合并（1.5s 窗口 + 5s 最小间隔），等客户端稳定后优先用 `LanguageClient.restart()`；修复 `command 'clangd.applyFix' already exists` 导致语言服务器启动失败。

规模（0.8.144 时点）：命令 **113**、设置 **85**、视图 **6**、快捷键 **34**。

## 🔎 文件模式

- 数据源 = `openProjects[].files`，内存内构建 prepared entries；活动工程 1.25× 加权，跨工程同路径去重（活动工程优先）。
- 空查询浏览全部工程文件（Top 500）；输入即搜（防抖）；单击打开，行尾定位按钮在工程树定位；文件行显示语言图标（`.c` 蓝色 C、`.h` 紫色 C（VS Code Explorer 的 Seti 图标字体））+ 文件名 + 目录；最多渲染 200 行 + 加载更多。
- 多个工程 `.cbp` 的 `title` 相同（如 `earphone/app.cbp` 与 `esop8/app.cbp` 都叫 `app`）时，分组名改用父目录名区分。

## 🔎 内容模式

- 常驻 worker（`bundle/search-worker.js`）；单飞，新搜索取消旧搜索；5 分钟空闲退出。
- UTF-8 / GBK / UTF-16 BOM；二进制与 >4MB 文件跳过；32MB 字节预算 LRU；脏编辑器文本优先。
- 单文件 50 条 / 全局 500 条；20s 总超时 + 5s 无进度终止；字面量回退宿主内扫描。
- 结果按工程 → 文件 → 行分组，工程头与文件行可折叠并显示匹配数徽标；每次搜索默认全部展开；点击跳转并选中匹配文本；状态区显示「N 个结果，M 个文件 · 耗时」/ 进度 / 截断 / 取消 / 超时。
- 新增 `Ab` 全字匹配（仅字面量），状态持久化并写入历史。
- 搜索完成后结果固定：切换活动工程不再自动重排/重搜，需更新时点「刷新」。

## 🕘 历史与设置

- 历史存工作区状态（文件/内容各 20 条），不保存文件内容；子树范围搜索不写历史。
- 点击「搜索」/`Enter` 即记录（0 结果也保留）；历史区在视图最底部、默认折叠，头部含当前模式条数/保留历史开关/清空。
- 点击历史：有效上次结果直接跳转，失效则恢复查询/模式/范围/选项并重跑；重跑图标仅重跑；清空使用 VS Code 模态确认。
- 新增 `codeblocks.search.scope`（`openProjects` / `activeProject`）与 `codeblocks.search.keepHistory`（默认 `true`）。
- 重置布局顺序：Project → Search → Symbols；不提升布局版本。

## ⚠️ 行为边界与升级提示

- 不替换内置搜索，不修改 `search.exclude` / `files.watcherExclude`；
- 只搜索 `.cbp` 中列出的文件，工程外文件不会出现；
- 内容搜索为逐文件扫描，不建立全工作区索引；超大工程建议使用更精确的查询或内置搜索；
- 正式版版本号 `0.8.144`；分支预发布版本号为 `0.8.144-feat.project-search`（不创建 Release）。
