# Code::Blocks for VS Code 0.8.156

> 发布日期：2026-11-19 ｜ 体验版（0.8.155 → 0.8.156）

## 概述

📊 本版补齐三个没有成熟 VS Code 替代的 Code::Blocks 缺口：**Profiler 完整化**（call graph / `gprof -A` / CSV·HTML 导出）、**AutoVersioning**（`.cbp` 配置 + `version.h` 构建钩子）和**编译器资源扩展**（TCC / BCC / DMC / ARM / PowerPC）。Doxygen、打印、Fortran、环境变量、单库 nm、Valgrind 改用推荐扩展。

- **Profiler**：解析 gprof call graph；源码注解写入独立输出通道；导出 CSV/HTML；完成后 QuickPick 选择操作。
- **AutoVersioning**：AutoVersioning… / Bump Version / Generate Version Header 三个命令；构建前生成 `version.h`，成功后递增 `BUILDS_COUNT`；支持 C/C++、前缀、命名空间、`#define`、manifest 同步。
- **编译器**：新增 TCC、Borland C++、Digital Mars、ARM ELF GCC、PowerPC EABI GCC 的 `options_*.xml` / `compiler_*.xml` 与自动探测。
- **文档**：新增推荐扩展页（Doxygen / Print / Fortran / dotenv / nm / Valgrind），README 与使用说明已链接。

## ⚠️ 行为变化与升级提示

- `codeblocks.profiler.annotatedSource` 默认开启；大工程可关闭以缩短分析时间。
- AutoVersioning 构建前会重写 `version.h`；手工维护该文件时请先备份或关闭工程配置。
- 新增编译器资源不改变现有工程选择；需要时在 Select Compiler / New Project 中选择。
