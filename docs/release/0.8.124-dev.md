# 0.8.124-dev

> Y2 选项 A：同步 `spawnSync` 超时下调（反引号命令 15s→3s；`<C> --version` 8s→3s）。
> 用户确认：Y2 选 A；Y3（A2 惰性命令生成 / R4 ccache 前缀）**均暂缓**。

## 背景（报告 §7.1）

以下同步调用都发生在**扩展宿主主线程**（多扩展共享的单线程）——挂起时整机扩展能力冻结：

| 位置 | 触发 | 原超时 |
|---|---|---|
| 反引号命令求值（`.cbp` 选项/模板内容，每轮构建重执行，对齐 CB `cbClearBackticksCache`） | 每轮 Build/Rebuild | 15s |
| `<C> --version`（PCH include 前置需主版本号，exe+mtime 缓存） | 首次 / exe 变更后 | 8s |

CB 同样同步执行且**无超时**（挂起会永久卡住其 UI）——本次超时下调属**保护性偏差**，并记入 `对齐对照.md`。

## 变更

- `src/compiler/commandGenerator.ts`：`expandBackticks` 中 `spawnSync` `timeout: 15000 → 3000`
  （超时/失败按空串处理并写入 LRU 缓存，同轮不重试；注释说明保护性语义）；
- `src/compiler/compilerVersion.ts`：版本查询 `timeout: 8000 → 3000`
  （超时/失败 → `undefined` 并缓存负结果）；文件头注释同步；
- `docs/对齐对照.md`「反引号展开」行补保护性差异注记。
