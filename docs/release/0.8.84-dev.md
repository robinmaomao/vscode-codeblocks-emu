# 0.8.84-dev

> 第三轮功能盘点·批次4：编辑器辅助对齐（R10 书签 / R11 Open include file / R12 Add TODO item）。

## R10 书签（Edit → Bookmarks）

- 新纯模块 `src/tools/bookmarks.ts`（与 UI 解耦，注入式持久化）：切换书签、按文件+行排序、
  跨文件「上一个 / 下一个」跳转（首尾回绕）、Clear All（当前文件 / 全部）；
- **行漂移回找**：记录行号 + 行文本，跳转/渲染时优先文本匹配（±50 行窗口），
  代码增删后书签仍能落在正确行（对齐现代编辑器体验）；
- 命令：`codeblocks.bookmarks.toggle` / `previous` / `next` / `clearAll`；
  编辑菜单新增 **Bookmarks** 子菜单（Toggle / Previous / Next / Clear All）；
- 快捷键 `Alt+K`（切换）/ `Alt+H`（上一个）/ `Alt+L`（下一个），作用域 `editorTextFocus`（均为 VS Code 空闲键）；
- 存储：`workspaceState`（键 `codeblocks.bookmarks`），按工作区隔离；
- 概览尺装饰：`editorGutter.addedBackground`（VS Code 无原生书签图标，使用增行型 gutter 装饰，
  与源码扫描结论一致：本体 `out/` 检索证实无书签功能，见第三轮报告 M1）。

## R11 Open Include File（Search 菜单）

- 新纯模块 `src/tools/includeResolver.ts`：解析光标处 `#include` 指令（引号 / 尖括号 / 宏）、
  存在性检查函数注入可测；
- 解析顺序对齐 CB「Open include file」：**当前文件所在目录** → **目标 include 搜索目录**；
  搜索目录取自 `CommandGenerator.orderedIncludeDirs`（本批次新增公开方法：目标/工程搜索目录关系合并
  + 反引号 `pkg-config` 目录 + `include_prj` / `include_file_cwd` 开关，与真实构建同一口径），
  支持 `$(VAR)` 与内置宏展开、相对路径按工程目录归一；
- 命令 `codeblocks.openIncludeFile` + Search 菜单 `Open Include File`；找不到时给出候选项 / 提示信息。

## R12 Add TODO Item（Edit 菜单）

- 命令 `codeblocks.todo.add`（`Code::Blocks: Add TODO Item…`）：选择类型（新设置 `codeblocks.todo.keywords` 驱动）、
  输入用户名与内容，在当前行下方插入 `// TODO(user): text`（缩进跟随当前行），对齐 CB TODO 插件 Add item；
- 新设置 **`codeblocks.todo.keywords`**（默认 `["TODO","FIXME","NOTE","HACK","XXX"]`）同时接入
  TODO List 扫描（`Code::Blocks: TODO List` 的关键字集合），实现扫描与新增两条路径同源。
