# 0.8.21-dev

> 发布日期：2026-09-25

## 编译随时停止

### 取消入口

- 构建通知改为**可取消**：通知右上角 ❌ 按钮一键停止。
- 新命令 `Code::Blocks: Stop Build`（命令面板/快捷键可用）。
- 构建互斥保护：构建进行中忽略新的构建命令，防止双开构建进程打架。

### 停止机制（秒级响应）

- 新增构建取消源 `BuildCancelSource`：取消标志 + 活动子进程注册表，`cancel()` 强杀所有活动进程。
- **Windows 进程树强杀**：`taskkill /T /F` 杀整棵进程树（cmd.exe → gcc → cc1/as/ld 孙子进程一并终止），无残留编译器进程；非 Windows 用 SIGKILL。
- 检查点全覆盖：每个编译单元前、每组 weight 之间、pre/post 每条脚本命令前、链接/打包前、多行命令每行之间、每个目标之间（工作区多项目）。
- 取消后未启动的单元不再启动；被强杀的编译不计入失败，显示 `⚠ [Interrupted]`。

### 取消语义

- 取消 ≠ 失败：汇总显示「⚠ 构建已取消」，不误报「❌ 构建失败」；
- 已完成的编译计数如实统计，最慢 Top3 不计入被中断的文件。

## Rebuild 前确认对话框

- 状态栏/命令/右键菜单触发 Rebuild 时，先弹出模态确认框（对齐 Code::Blocks "Rebuild project?" 行为）：
  「重新构建将删除所有对象文件并全量重新编译，确定继续？」——选择「重新构建」才继续，关闭则无动作。
- 普通 Build 不弹窗。

## 测试

- 新增取消源回归测试（8 断言），全量回归 32 pass。
