- 运行工作目录 `working_dir`、deps 输出目录 `deps_output`、平台（Windows/Unix/Mac 复选，全选 = All）、
  宿主程序 `host_application` + 终端开关 `run_host_application_in_terminal`、console runner `use_console_runner`、
  import 库 `imp_lib`、def 文件 `def_file`、`createDefFile`、`createStaticLib`、`prefix_auto`、`extension_auto`；
- `projectWriter` 补齐对应序列化（对齐 CB `ExportTargetAsProject` 的写出条件）；
- **顺带修复旧缺口**：`working_dir / deps_output / host_application / run_host_application_in_terminal / platforms (目标级)`
  此前在「透传 handled 集」中被排除但**没有任何显式写出路径**——保存工程属性时会丢失这些字段；现已补齐。

## R9 从目标导出独立工程（Create project from target）

- 新纯模块 `src/project/exportTarget.ts`，对齐 `projectloader.cpp:1472-1830 ExportTargetAsProject`：
  单目标（完整目标选项）、文件按归属过滤（仅 `buildTargets` 含该目标者）、虚拟目标不导出、
  Extensions / 环境变量 / 自定义变量保留、自动生成文件不导出；
- 新命令 `codeblocks.exportTargetAsProject`：面板「导出为工程」按钮 + Project 菜单 `Create Project from Target…`；
  默认文件名 `<工程名>_<目标名>.cbp`，导出完成后可直接打开。
