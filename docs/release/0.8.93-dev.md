# 0.8.93-dev

> 修复：构建结束无条件写 `buildlog.html` —— 现对齐 Code::Blocks 保存语义（开关默认关 + CB 文件名/路径）。

## 问题

- `finishBuildSummary`（`src/extension.ts`）此前每次项目/工作区构建结束都**无条件**把 `buildlog.html`
  写到活动工程目录，文件名也与 Code::Blocks 不一致（用户反馈：「用扩展编译项目后出现 builglog.html」）。

## CB 取证（compilergcc.cpp）

- `InitBuildLog:3866-3893`：文件名 = 工程目录 + 工程文件名（去扩展名）+ `_build_log.html`；
  工作区构建取 `.workspace` 文件名；标题 = 工程标题 + " build log"。
- `SaveBuildLog:3898-3938`：开关 `/save_html_build_log` **默认 false**（`:3900-3903` 未启用直接返回；
  复选框 `compileroptionsdlg.cpp:619`）；正文含
  `Build started on: dd-mm-yyyy at HH:MM.SS` / `Build ended on: …`（`:3926/3929`）；
  调用点 `:4051`（构建收尾）与 `:1436`（命令启动失败）。

## 修复

- 新设置 **`codeblocks.build.saveHtmlLog`（默认 false，对齐 CB）**：不启用时不再生成任何文件。
- 启用后写 `<工程文件名>_build_log.html`（工作区构建 `<工作区文件名>_build_log.html`；
  无 `.workspace` 文件时回退活动工程，保护性差异）。
- 内容 = CB 格式起止时间 + 诊断汇总表（非全量日志文本，保护性差异记录）；
  保存后在输出通道提示 `file:///…` 路径（对齐 CB「Build log saved as:」）。
- 失败非致命（对齐 CB：文件打开失败直接返回）。
- 实现：新纯模块 `src/build/htmlBuildLog.ts`（`buildLogBaseName` / `cbTimeStamp` / `escapeHtml` /
  `renderHtmlBuildLog`）；`saveHtmlBuildLog()` 在 `buildWorkspace` / `buildSingleProject` 收尾调用。
