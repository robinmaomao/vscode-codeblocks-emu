# 0.8.45-dev —— import/def 默认基础名（第二十四轮 L1）

以 `compiletargetbase.cpp` 输出/import/def 推导函数全文为基线取证。

## L1 动态库 import 库/def 默认基础名 = 输出去扩展名

- CB：`GetDynamicLibImportFilename:390-404` / `GetDynamicLibDefFilename:406-420`——`imp_lib`/`def_file`
  未设置时默认值为 **`$(TARGET_OUTPUT_DIR)$(TARGET_OUTPUT_BASENAME)`**（输出目录 + 输出文件名**去掉扩展名**），
  随后 `SetupOutputFilenames` 再按策略加前缀/扩展。
- 原状：fallback 用 `target.outputFilename`（**含扩展名**）——默认动态库工程：
  import 库 `libfoo.dll.a`（CB 为 `libfoo.a`）、def `libfoo.dll.def`（CB 为 `libfoo.def`），
  并连带影响 `$static_output`/`$def_output` 与 cleanTarget 删除路径。
- 实现：`expandOutputBasename`（宏展开后去扩展名）；`setupStaticOutput`/`setupDefOutput` 的
  动态分支 fallback 改用它（显式 `imp_lib`/`def_file` 保持原样含扩展名）；`cleanTarget` import
  库删除路径同步。

## 本轮已核实等价（无需改动）

- `GetObjectOutput`/`GetDepsOutput`（203-233）空默认 = 项目根 + `/.objs`/`/.deps`（相对等价）；
- `GetExecutableFilename` 的 `.exe` 附加仅用于运行/建议路径，不进入链接命令（654）；
- `GetStaticLibFilename`/`GetDynamicLibFilename` 策略分支与 `computeStaticOutput` 一致；
- `GetOutputFilename` 对 CommandsOnly 返回空。
