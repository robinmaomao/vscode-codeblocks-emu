## F1 构建/重建/清理前停止调试会话

- CB：`DoBuild:2897` → `StopRunningDebugger`（compilergcc.cpp:879-905）——调试器运行中
  弹窗询问「The debugger must be stopped to do a (re-)build.」：YES → 停止调试并继续构建；
  NO/CANCEL → 记录 `Aborting (re-)build.` 并**中止构建**。覆盖 Build/Rebuild/Clean/工作区构建。
- 原状：扩展没有任何 stopDebugging 调用——调试运行中直接构建（GDB 会话与编译进程并存，
  可能锁死二进制导致链接失败）。
- 实现：`stopDebuggerIfRunning()`（`vscode.debug.activeDebugSession` 非空时模态询问
  「停止调试并构建」，拒绝则记录 `[Code::Blocks] Aborting (re-)build.` 并中止）；
  在 `build(rebuild)`、`buildSingleProject`、`clean()` 三个公共入口调用。
