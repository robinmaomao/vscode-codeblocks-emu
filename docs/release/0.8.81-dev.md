# 0.8.81-dev

> 第三轮功能盘点·批次1：环境变量体系对齐（对齐 Code::Blocks Build options → Custom variables）+ 两处文档认知修正。

## M1 书签表述修正

- 核实：VS Code 本体 `resources/app/out` 全量检索 `bookmark` 仅命中 codicon 图标名与扩展徽章样式，**无内置书签功能**；
- `docs/对齐对照.md` §5 Edit 行「Bookmarks 由 VS Code 原生书签承担」更正为「未对齐（计划见第三轮报告 R10）」。

## M2 项目自定义变量语义修正

- 核实：CB 25.03 全树 + 公开代码搜索对 `codeblocks_project_custom_variables` **0 命中**（`cbProject` 无 `SetVariable/GetVariable`）；
- CB 的 Build options「Custom variables」页实际编辑的是 `<Environment>` 项目/目标变量
  （`compileroptionsdlg.cpp:587/1206-1240` + `projectloader.cpp:900-915` + `macrosmanager.cpp:217-243` 并入宏表）；
- 文档更正：「项目自定义变量」标注为扩展增强（Extensions 节点，供 `$(name)` 宏/脚本），不再声称等同 CB Custom variables。

## R1 环境变量编辑（<Environment>）

- 工程属性面板新增编辑入口：
  - **项目设置页**「环境变量（每行 `name=value`）」→ `<Build><Environment><Variable name value/>`；
  - **构建目标页**「环境变量」分组 → `<Target><Environment>`；
- 空值不写节点；解析/写回/往返均有测试（writer 既有能力直接复用）。

## R2 `$(VAR)` 宏接入

- 新增 `envVarMap(...lists)`：合并项目/目标环境变量为宏表（**键大写、目标覆盖项目**，对齐 `ReadMacros` 语义）;
- 合并点：`buildEngine.targetMacroVars`、`commandGenerator.cbVars`、扩展的 Run/Debug/make/自定义工具构造点、
  `buildEngine` 编译器 PATH 展开（项目级）；
- 效果：构建命令、链接库、外部依赖、pre/post 脚本、运行参数、宿主程序、工作目录输出路径中的 `$(PROJ_VAR)` / `$(TGT_VAR)`
  由此前**展开为空**变为按 CB 语义展开；
- 宏名查找支持**大写回退**（`$(port)` 与 `$(PORT)` 等效，对齐 `macrosmanager.cpp:675/708`）；
- **保护性差异**：内置宏优先于同名环境变量（`TARGET_OUTPUT_FILE` 等核心宏不被覆盖；CB 中部分早期宏可被覆盖）。
