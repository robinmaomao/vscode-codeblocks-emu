## 概述

本版不新增功能，只把独立功能审计（[functional-audit-0.8.159.md](../testing/functional-audit-0.8.159.md)）确认的缺陷按用户决定落地：
F-01、F-04…F-13 全部修复，F-02（`.ld` 行注释）与 F-03（TODO 注释语言口径扩展）按决定保留现状。
每个缺陷都先写失败测试再修复，并补上对应的回归守卫。

## 🛠 修复

- **F-01 新建工程覆盖**：目标目录已有同名文件时逐文件确认，默认保留；不再整目录覆盖。
- **F-04 HeaderGuard**：仅对头文件（`.h` / `.hpp` / `.hh` / `.hxx`）生成或更新 include guard，源文件不再插入。
- **F-05 Open Include File**：支持系统头（`<vector>`、`<stdio.h>` 等）与工程内后缀补全，`#include` 跳转不再落空。
- **F-06 TODO 扫描器**：按语言识别注释起始符（`#` / `REM` / `::` / `.S` 预处理守卫），不再把代码当注释文本。
- **F-07…F-10 本地化**：构建日志 `Target '{0}' is up to date…`、`Make: {0}` 与「先构建再调试」门控提示改走词条；补齐 WebView / 运行目标面板词条。
- **F-11 文档计数**：键位 / 词条 / 菜单 / WebView 计数与实现对齐。
- **F-12 测试体系**：10 个 print-only 脚本补断言与退出码；新增 112 命令入口冒烟、英文 UI 守卫、TODO 扫描器语言用例。
- **F-13 工程名校验**：拒绝 `.` / `..` / 结尾点或空格 / Windows 保留名（`CON`、`NUL`、`COM1`…）。
