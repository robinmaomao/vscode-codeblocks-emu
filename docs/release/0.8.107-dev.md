# 0.8.107-dev

> `codeblocks.build.linkInputExtensions` 默认仅保留 `.xm`：`ld/lds/icf/def` 改为按需自行添加。

## 背景

原默认 `["ld","lds","icf","def","xm"]` 对使用 `.ld` 链接脚本的项目会在每次脚本改动后自动重链接（保护性增强）。用户实际仅需 `.xm` 资源识别，其它扩展名的重链判定按项目需求显式配置更可控。

## 改动

- 默认值：`["ld","lds","icf","def","xm"]` → `["xm"]`（package.json 与 `linkInputExtensions()` 回退默认同步）。
- 设置描述与文档同步：默认仅 `.xm`，`.ld`/`.lds`/`.icf`/`.def` 可按需添加（如 `["xm","ld"]`）；误配回退默认、`[]` 关闭、`compile="1"` 走 CB 条目计数等语义不变。
- 测试适配：`test-settings-structure.js` 默认断言改 `["xm"]`；`test-link-input-outdated.js` 中依赖 `ld` 白名单的场景显式设置 `['ld']`，误配回退场景改用 `custom.xm` 验证（回退默认即 `xm`）。

## 验证

- `test-link-input-outdated.js` 24 断言、`test-settings-structure.js`、`test-abs-unit-path.js` 全过；全量 `TOTAL=111 FAIL=0 SKIP=1`；`tsc` 0 错误。
