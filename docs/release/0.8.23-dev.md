## 编译/链接对齐第二轮（G1-G4）

### G1：`$libs` 链接库构造对齐 `FixupLinkLibraries` / `SetupLinkLibraries`

- **追加编译器全局链接库**（default.conf `/compiler_sets/<id>/link_libs`，此前仅用于外部依赖检查）；
- **含路径的库名原样保留**（含 `/` 或 `\` 的库不做前缀/扩展处理、不加 `-l`，此前会误剥路径）；
- **剥扩展名条件对齐**：仅当已剥 lib 前缀时才剥扩展（`foo.a` → `-lfoo.a`，`libfoo.a` → `-lfoo`）；
- `linkerNeedsLibExtension=true` 时自动补 `.a` 扩展；
- `linkerNeedsPathResolved=true` 时用库目录解析库全路径；
- 逐库引号（含空格库名的双层引号行为与 CB NeedQuotes 字节级一致）。

### G2：编译阶段空命令跳过日志

- 编译命令展开为空（工具未匹配 / 程序缺失）时输出 `Skipping file (no compiler program set)`（对齐 `GetCompileFileCommand`，头文件除外）。

### G3：源文件缺失 WARNING

- 增量判断中源文件不存在 → 输出 `WARNING: Can't read file's timestamp: <file>` 后跳过（对齐 `IsObjectOutdated` 的 err 语义）。

### G4：编译器开关对齐

- `forceFwdSlashes`：逐组件 `\`→`/`（跳过 `\ `，不做整命令转换以保护 `cmd /c`），应用于 `$compiler`/`$file`/`$object`/`$deps`/搜索目录（对齐 `FixPathSeparators` 的逐组件应用方式）；
- `Use83Paths`：源文件存在时用短路径（对齐 `GenerateCommandLine:417`，此前仅资源文件与目录）；
- `UseFullSourcePaths=false`：`$file` 用相对路径（编译与自定义命令，此前始终绝对路径）。

### 取证结论（写入对齐对照文档）

- `forceCompilerUseQuotes` / `forceLinkerUseQuotes`：CB 命令生成中**未实际使用**（仅读取/保存/UI），不实现；
- `include_prj_cwd` / `include_file_cwd`：默认 false，不实现（记入已知限制）。
