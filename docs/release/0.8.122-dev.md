## X1：缺 `<Option compiler>` 的工程/目标不再误判「无效编译器」

- **问题**：工程/目标均无 `<Option compiler>` 时 `parser` 默认 `compilerId: ''` → 构建目标被
  「invalid compiler」过滤跳过 / 运行 `Run aborted...` / Clean 跳过对象清理；而 UI 与单文件编译路径
  （`getCompiler('')`）回退 GCC 模板 → 行为自相矛盾。
- **CB 依据**：工程加载器缺省 `compilerId = "gcc"`（`projectloader.cpp:396`；完全无 `<Option>` 节点时沿用
  `cbProject` 构造默认，`cbproject.cpp:69`）；目标继承工程（`projectloader.cpp:547/664`）——CB 中编译器 ID 永不为空。
- **实现**：新增纯模块 `src/compiler/compilerRegistry.ts`（依赖注入，无 vscode）——
  `compilerIdCandidates`（原样→小写→去 `-`，对齐 `compilerfactory.cpp:42-58`）、
  `findRegisteredCompilerId`（设置值 / default.conf 用户编译器 / `options_*.xml` 三源）、
  `resolveEffectiveCompilerId`（**空 ID → 已注册的 `"gcc"`；未注册时回退设置 `codeblocks.compilerId`**）。
  `extension.ts` 的 `resolveTargetCompiler` 改为经该模块解析；未注册的**显式** ID 仍按无效编译器处理（语义保持）。
- **测试**：`tests/test-compiler-id-default.js`（16 断言：候选序列/三源注册判定/空 ID 缺省链/旧「立即无效返回」已移除/宿主接线）。

## X2：平台不支持的目标补 CB 原文警告 + 收尾行扩展

- **CB 依据**：`PreprocessJob:2745-2764` 单循环——先 `SupportsCurrentPlatform` → 警告
  `"<工程> - <目标>" does not support the current platform. Skipping...`（:2749-2756），再 `CompilerValid` 报错（:2759-2764）；
  任务列表为空 → `NotifyJobDone` 收尾行（:4123-4140）。
- **实现**：`buildEngine.build()` 预过滤改为同序单循环（平台警告 → 无效编译器消息）；
  全目标被平台/无效编译器跳过后输出 `Nothing to be done (all items are up-to-date).`（0.8.121 P3-B 收尾行扩展至平台跳过）。
  `collectCompileCommands` 两处平台过滤保持静默——对齐 `GenerateCommandLine:238`（CB 该路径不告警）。
- **测试**：`tests/test-platform-skip-log.js`（6 断言：警告原文逐字/无无效编译器误报/收尾行/banner 不打印/跨平台标题选择）。

## X3：调试器 `launch.json` 配置 schema

- `contributes.debuggers` 补 `configurationAttributes`（launch：必填 `program`，另有
  `cwd` / `args` / `environment` / `gdbPath` / `searchDirs` / `remoteDebugging`；attach：必填 `pid`，另有可选 `program` 等）、
  `initialConfigurations`（Debug (Code::Blocks)）与 `configurationSnippets`（launch / attach 两条）。
- 影响：手写 `launch.json` 获得 IntelliSense / 「添加配置」模板，不再有未知属性提示；F8 / 命令入口不受影响。
- **测试**：`tests/test-debugger-schema.js`（12 断言：schema 完整性/声明属性均在适配器有 `args.<name>` 读取/
  `remoteDebugging` 子字段与 `RemoteDebuggingOptions` 一致/初始配置与 snippets 占位符）。

## X4：asm（`.S` / `.s`）language-configuration 补齐
