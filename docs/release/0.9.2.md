# 0.9.2

> 发布日期：2026-11-19 ｜ 补丁版（0.9.1 → 0.9.2）
> **主题**：0.9.0 合入 Agent 控制面后的九轮复查修复（跨端契约 / 失败语义 / 资源回收 / 数据安全）

## 概述

0.9.0 把 Agent 控制面（LM Tools 11 + MCP provider + CLI）与 UI 统一到同一份构建内核后，逐项复查发现四类问题：
失败被当成成功（平台不支持的目标、clean spawn 失败）、跨传输响应漂移（调试帧 / 变量）、资源泄漏与挂起（gdb 进程、
无人应答的通知）、相对路径口径不一（`cwd` / `out` / `Makefile`）。本版只修正确性与安全问题，不新增功能面。

## 🐛 修复

- **构建**：当前平台不支持的目标改为 `unsupported` 失败（虚拟目标按成员并集判定）；`build_status` 无构建记录返回 `no-build`；clean 统一走共享实现并如实上报失败；make 已最新时不再递增自动版本号。
- **挂起（P1）**：agent 构建路径的产物排除通知改为 `{ notify: 'interactive' }`，无人应答不再永久挂起、`timeoutMs` 不再失效。
- **运行**：`cwd` 相对工程目录解析；默认超时 120s（`DEFAULT_RUN_TIMEOUT_MS`）。
- **调试**：三端响应统一归一化（`src/api/debugShapes.ts`），`level` 兼作帧 `id`，`variables` / `evaluate` 支持 `frameId`，`setBreakpoints` 为替换语义，`stop` / `dispose` 清理断点与等待器，gdb 启动失败回收进程并映射 `compiler-missing`。
- **工程编辑**：未知目标引用、`weight` 越界、重名目标 / 文件、重命名冲突一律 `invalid-input`；编辑失败不污染内存模型（深拷贝）。
- **导出**：`Makefile.cb` 默认输出（不覆盖工程 Makefile）、`out` 按工程目录解析、`systemIncludes` 贯通。
- **CLI / MCP**：`--json` 失败亦输出 JSON、退出码全量映射（1/3/4/5 + `no-build`）、`debug --timeout`；MCP `cwd` 与 `tools/list` `annotations`；未受信任工作区强制关闭。
- **编译器**：C/C++ 语言标准参数独立成 `compiler/languageFlags.ts` 并纳入缓存键。

## ⚠️ 行为变化与升级提示

- `codeblocks_export` 的 `makefile` 默认输出由 `Makefile` 改为 `Makefile.cb`；显式 `out` 指向工程自带 `Makefile` 时拒绝执行。
- `build` / `run` / `export` 的相对路径统一按**工程目录**解析。
- 平台不支持的目标、未知目标引用、越界 `weight`、重名等由「静默忽略」改为返回错误（`unsupported` / `invalid-input`）。
- `codeblocks_build_status` 无构建时错误码为 `no-build`；CLI 失败也输出 JSON，退出码新增 3 / 4 / 5。
- 无设置项 / 命令 / 键位变化（命令 136 / 设置 93 / 视图 6 / 键位 34 / LM Tools 11 / MCP provider 1）。
