## L6 空目标回退修正（对齐 `directcommands.cpp:143-157`）

- `buildEngine.ts` 六处 `target.files.length ? target.files : this.project.files` 全部改为权威的 `target.files`：
  目标无文件 → 0 编译命令 + 跳过链接（CB `Linking stage skipped`）。
- 实测（修复前）：Release 空目标会编译并链接整个工程（`compiledCount:2, linkSuccess:true`）；修复后 0 编译无链接。

## L4 `includeInTargetAll` 口径（对齐 `projectloader.cpp:551/619-620/682/210-221`）

- 属性名改 camelCase `includeInTargetAll`（兼容旧扩展写出的下划线变体 `include_in_target_all`）；
- 默认值 `true` → `false`（现代 .cbp 默认，仅 pre-1.2 legacy 文件默认 true）；
- 加载后按 CB 规则合成 `All` 虚拟目标：存在 legacy `includeInTargetAll="1"` 目标且无同名虚拟目标时
  `All = <true 目标列表>`（已有同名则跳过）；`createEmptyTarget` 默认同步改 false。

## L5 编译器 `logging` 开关（对齐 `compiler.cpp:943-952`；make 对齐 `compilergcc.cpp:2560-2620`）

- `CompilerSwitches` 新增 `logging?`（`full`/`simple`/`none`）；`optionsLoader` 消费 XML 开关；
  `value="default"` → `undefined`（交由扩展设置控制；CB `defaultLogging=clogFull` 保护性不强制，文档化差异）；
- `buildEngine`：`logging=full` 并入详细输出（打印完整命令行）、`logging=none` 抑制每文件完成行（错误行不受影响）；
- makefile 项目模式：Build 前同步执行 `askRebuildNeeded`（退出码 0 = 已最新跳过构建）；
  `logging != full` 时优先使用 `silentBuild` 命令（未配置回退 `build`，保护性差异）。

## L8 `hasCppFilesToLink` 按 compilerVar（对齐 `compilercommandgenerator.cpp:585` + `directcommands.cpp:772/903`）

- 链接器 AutoDetect 选择改按 compilerVar：`linkFiles.some(f => f.compilerVar === 'CPP')`，扩展名仅作回退；
