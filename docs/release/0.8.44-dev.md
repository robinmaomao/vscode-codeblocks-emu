# 0.8.44-dev —— def 命名与 import 库扩展名（第二十三轮 K1/K2）

以 `SetupOutputFilenames` 全文（compilercommandgenerator.cpp:654-789）为基线取证。

## K1 def 文件命名分支化

- CB：非动态分支（774）`SetExt("def")` **恒替换**最后一个扩展名，仅前缀随 prefix_auto 策略；
  动态分支（704-716）def 扩展名**追加**且比较恒大小写不敏感。
- 原状：统一走 `computeLibOutput(..., 'def', prefixAuto, extensionAuto)`——扩展名追加且随 extension_auto
  （`libfoo.a` → `libfoo.a.def`，CB 为 `libfoo.def`；extension_auto=false 时保留原扩展名，CB 仍为 `.def`）。
- 实现：`setupDefOutput` 分支化——静态：前缀随策略 + 恒替换 `.def`（保留 multi-dot 名）；
  动态：前缀随策略 + 追加 `.def`（大小写不敏感判定）。

## K2 import 库扩展名比较恒大小写不敏感

- CB：`SetupOutputFilenames:687` import 库 `IsSameAs(requested_ext, false)` 不分平台；
  静态分支（756）才按平台区分。
- 实现：`computeLibOutput`/`computeStaticOutput` 新增可选 `insensitiveExt` 参数（默认按平台）；
  `setupStaticOutput` 的 DynamicLib 强制分支与 `cleanTarget` import 库删除路径传 true。
