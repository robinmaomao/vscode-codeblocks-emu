# 0.9.0

> 发布日期：2026-11-19 ｜ 正式版（0.8.160 → 0.9.0）
> **主题**：Agent 控制面（Copilot / MCP / CLI）合入，构建内核 UI 与 Agent 同源

## 概述

本版把 `feat/agent-control` 分支以 `--no-ff` 合入 main：Copilot agent / 任意 MCP 客户端 / CI 都能通过同一套工具读取与修改
工程、构建/清理、运行、调试、导出与探测编译器；同时把 `extension.ts` 里的单工程构建逻辑下沉为
`src/build/buildProject.ts`（唯一实现），保证「Agent 看到的」与「用户看到的」完全一致。

> **破坏性变更**：`engines.vscode` 由 `^1.85.0` 抬到 **`^1.102.0`**（Language Model Tools 与 MCP server provider API 需要 1.102）。

## 🤖 Agent 控制

- **11 个 Language Model Tools**：`project_read` / `project_edit` / `project_file` / `project_target` / `build` /
  `build_status` / `run` / `debug` / `compiler` / `export` / `workspace`。
- **MCP server**：`contributes.mcpServerDefinitionProviders`（provider id `codeblocks`）指向随包 `bundle/cb-mcp.js`，
  用编辑器自带的 Node（`process.execPath`）启动，不依赖用户 PATH。
- **独立 CLI**：`bundle/cb-cli.js`，供 CI / 终端直接调用同一套工具。
- **开关（新增设置，第 10 个分区 Agent）**：
  - `codeblocks.agent.enabled`（默认 `true`）：关闭后 LM Tools 不注册、内嵌 MCP 不暴露，外部客户端直启的 MCP server 也拒绝调用；**未受信任工作区一律按关闭处理**；切换即时生效。
  - `codeblocks.agent.readOnly`（默认 `false`）：仅放行只读工具与动作（`project_read`、`build_status`、`compiler list/info`、`workspace info/deps/list`、`debug state`），其余返回 `read-only`。
  - 独立的 `cb-cli` 不受开关影响（由用户显式执行）。
- **安全**：字段白名单、`dryRun`、`allowScripts` 门控、构建互斥、写盘签名在读盘前捕获（并发外部修改 → `external-modified`，`force: true` 覆盖）；每次调用写一行审计日志。
- 详见 [Agent 控制](../guide/agent-control.md) / [English](../guide/agent-control.en.md)。

## 🧩 共享内核与架构

- **构建内核**：`src/build/buildProject.ts`（无 vscode 依赖）成为唯一单工程构建实现，UI / LM Tools / CLI / MCP 共用；
  main 侧审计修复全部保留：语言标志覆盖（`readLanguageFlags`）、编译器缓存签名、自动版本号钩子、makefile 语义
  （`silentBuild` / `askRebuildNeeded` / Stop）、链接期诊断定位、`maxReportedErrors` 截断、不可导航诊断归一化、构建日志本地化。
- **下沉模块**：`src/api/*`（工程读改/构建/运行/调试/导出/编译器/设置读取/策略）、`src/lm/tools.ts`、`src/mcp/*`、
  `src/cli/*`、`src/compiler/compilerFactory.ts`、`src/build/buildSummary.ts`。
- **clangd**：`withClangdBatch` 把启动恢复/多选打开的生成合并为一次；启动恢复期间「仅配置变化」跳过 `clangd.restart`
  （`decideClangdRestart`，避免 `applyFix already exists` / 连接失败弹窗），与既有重启合并器（debounce + minInterval + 等客户端稳定）共存。

## ⚠️ 行为变化与升级提示

- **VS Code 最低版本 1.102.0**：低于此版本不会安装/激活；升级 VS Code 后再更新本扩展。
- **设置新增**：`codeblocks.agent.enabled`、`codeblocks.agent.readOnly`（默认值与既有行为兼容，不影响普通使用）。
- **构建输出/诊断**：`Target '{0}' is up to date…`、`Make: {0}` 等日志行改走词条，英文界面不再出现中文。
- **构建行为**：自动版本号、makefile 的 Stop / askRebuildNeeded、clangd 重启节流均与 0.8.160 一致，仅实现位置变化。
