# 0.8.147 — 2026-11-11

> 体验版：工程搜索（Project Search）的 Text 结果排版与 VS Code 内置 Search 对齐，并修复切换视图后另一种模式的搜索记录丢失。

## 问题

1. **Text 结果观感与内置 Search 不一致**：正文沿用 `--vscode-font-size` 但匹配预览仍是编辑器等宽字体、行高 20px（内置是 22px），密集列表读起来“字体不一样、行距偏挤”。
2. **Files 模式没有「搜索」按钮**：只有 Text 模式显示，Files 模式只能靠输入即时刷新。
3. **控件换行**：Text 模式多出 Search 按钮后，`Files / Text / Search / All projects` 总宽超出，下拉框被挤到第二行。
4. **行号占位固定**：行号列固定 26px + 38px 缩进，窄侧栏里代码区被压掉一大块。
5. **搜索记录丢失**：Files 搜索 → 切 Text → 切 Explorer → 回来，Files 结果消失；Text 同理。
6. **状态行串模式**：切到另一模式后，状态行仍显示上一个模式的统计。
7. **`Keep history` 开关歪斜**：`content-box` + 1px 边框使外框变成 30×18，滑块底边多 1px、开启态右侧少走 2px。
8. **Files 模式下 `Aa`/`Ab`/`.*` 可点但无效**：文件搜索恒不区分大小写、不支持正则，按钮仍可交互造成误导。

## 修复

### Text 结果排版（`src/ui/projectSearchViewHtml.ts`）

- 匹配行的字体改为 `--vscode-font-family`、字号继承结果区（`--vscode-font-size`），行号同字体。
- 工程头 / 文件行 / 匹配行统一 22px 行高（内置 `filematch` / `linematch` 均为 22px）。
- 行号**不占固定列**：`text-align: right` + 按本批最大行号位数设定 `min-width`（CSS 变量 `--cb-line-num-ch`），`font-variant-numeric: tabular-nums`；代码左边缘不随位数跳动。
- 预览上限由 200 降到 120 字符（`TEXT_PREVIEW_LENGTH`），窄侧栏可少滚动。
- 删除 Text 模式对工程头 / 文件行 / 徽标的独立尺寸覆盖，两模式共用基础样式。

### 控件布局

- `#searchBtn` 在 Files 模式也显示；仅在 Text 模式搜索进行中替换为「停止」。
- `.controls` 改 `flex-wrap: nowrap`，`#scope` 用 `flex: 0 1 auto` 先压缩而不是换行；≤240px 的极窄兜底仍允许换行。

### 搜索记录保持（`src/ui/projectSearchView.ts`）

- 侧边栏隐藏时 webview 会被销毁、内存结果全丢；新增 `postCachedResults()`，在 `ready` 时把两种模式最近一次的 DTO 直接回放，**不重跑扫描**。
- 回放前校验缓存 query 与当前 query 一致，避免恢复已清空/已改写的旧结果；当前模式无缓存且查询非空时才回退重跑。
- `TextResultState` 增加 `matchCount`，回放时统计数字正确。

### 其他

- 状态行按模式记忆（`S.summary = { files, text }`），切换模式恢复各自摘要。
- `Keep history` 开关加 `box-sizing: border-box`，`border-radius` 9px → 8px，滑块四周留白对称。
- Files 模式禁用 `Aa`/`Ab`/`.*`（`disabled` + `aria-disabled` + 提示「仅内容模式有效」），Text 模式恢复原 tooltip。
