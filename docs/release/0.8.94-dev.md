## F5 GDB `-nx`（disable startup scripts）

- **问题**：扩展启动 GDB 固定不传 `-nx` → 会执行用户 `.gdbinit` / `gdb.ini`；CB 默认行为相反。
- **CB 取证**：`disable_init` **默认 true**（`debuggeroptionsdlg.cpp:136`）；launch 与 attach 的 GDB 命令行均加 `-nx`（`gdb_driver.cpp:104-105` / `:127-128`，注释 "don't run .gdbinit"）；UI 复选框 **Disable startup scripts (-nx) (GDB only)**（`debugger_options_dlg.xrc:93`）。
- **修复**：新设置 **`codeblocks.debug.disableInit`（默认 true，对齐 CB）**；`gdbMiSession.start` 在 `userArguments` 之前插入 `-nx`（launch/attach 两处接线；`userArguments` 中重复的 `--nx` 不去重——GDB 容忍重复，对齐 CB）；`debug.userArguments` 描述去掉已过时的 `--nx` 示例。
- **行为变化（注意）**：默认不再执行本机 `.gdbinit`（依赖启动脚本的用户请关闭该设置；release notes 明示）。
- **验证**：新增 `tests/test-debug-nx.js`（7 断言：argv 顺序 / 关闭 / 缺省向后兼容 / 适配器两处接线）；**真机冒烟（MinGW GDB 8.1）**：临时 HOME 的启动脚本 `set print elements 123` 在 nx=false 时生效（`-gdb-show print elements` = 123）、nx=true 时被抑制（= 200）。

## F8 HTML 构建日志完整命令行（full_command_line）

- **CB 取证**：`/save_html_build_log/full_command_line` **默认 false**（`compileroptionsdlg.cpp:623`；UI「Always output the full command line in the generated HTML file」）；构建期间每条队列命令在「完整命令行 / 短消息」**二选一**写入 HTML 日志正文（`compilergcc.cpp:1330-1338`）；行格式 = 转义文本 + `<br />`（`LogMessage:3819-3831`）。
- **修复**：新设置 **`codeblocks.build.saveHtmlLogFullCommandLine`（默认 false，对齐 CB）**；`BuildEngine.lastCommands` 采集本轮实际执行命令（编译/链接/打包 + 项目/目标 pre/post 脚本；响应文件改写后记录，对齐 CB 记录 `cmd->command`）；`renderHtmlBuildLog` 开启时在起止时间与诊断表之间追加命令行块（逐工程块头 + 逐命令一行；**叠加而非二选一**——扩展正文本就是诊断摘要，保护性差异记录于模块注释）。
- **验证**：新增 `tests/test-build-commands-capture.js`（7 断言，真实 gcc：采集/顺序 pre→编译→链接/每轮重置）；`test-html-build-log.js` 15→**22** 断言；真机构建冒烟 PASS（3 条命令 + HTML 命令行块）。
