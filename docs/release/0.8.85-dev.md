# 0.8.85-dev

> 第三轮功能盘点·批次5（最终批）：用户模板机制（R13）+ 更多内置模板（R14）+ Debug Information 子菜单。

## R13 用户工程模板（对齐 CB File → New → From template… / Save project as template…）

- 新纯模块 `src/project/userTemplates.ts`（仅 fs/path，命令与测试共用）：
  - **保存**：工程名写入 `$(PROJECT_NAME)` 占位符（仅 `title` / `output` / `def` / `imp_lib` 属性，避免误伤
    编译选项等文本）；骨架文件按引用清单收编（缺失跳过、保持目录结构、`obj/` 与 `bin/` 不收集）；
  - **实例化**：复制骨架 + 把占位符替换为新工程名 + 工程文件改名为 `<新名>.cbp`；
  - 清单读写（`template.json`，schema 版本化）、列表排序、重名/非法工程名/未知模板防御。
- 模板目录：`<globalStorage>/templates/<id>/`（`template.json` + `project.cbp` + 骨架），纯文本可手工编辑/分享；
  模板 id 由名称 slug 化（保留中文）。
- 命令与入口：
  - `Code::Blocks: Save Project as Template…`（File → Save Project as Template…，重名时确认覆盖，可一键打开模板目录）；
  - `Code::Blocks: New Project from Template…`（File → From Template…；无模板时引导先保存）；
  - `Code::Blocks: New Project` 向导顶端混列用户模板（`$(library)` 图标），与内置模板同流程。
