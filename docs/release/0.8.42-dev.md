## I1 flatObject 恒为扁平命名

- CB：`GetCompileFileCommand` 与 `GetTargetLinkCommands` 传 `pfd.object_file_flat` 作为 flat_object——
  无论 `useFlatObjects` 开关，flat_object 恒为扁平命名（对象目录 + 纯文件名）；`FlatLinkFiles`
  （GetTargetLinkCommands:803/813）逐文件构建扁平路径。自定义编译命令/自定义链接模板里
  `$link_flat_objects` 拿到的是扁平路径。
- 原状：四处把普通对象路径原样塞进 `flatObject`——`useFlatObjects=false` 时该宏拿到非扁平路径。
- 实现：新增 `objectPathRelativeFlat`（强制扁平：对象目录 + 纯文件名，extended_obj_names 同样扁平，
  .o/.a 原路径，PCH 沿用 pchObjectRelative）与 `linkObjectRelativeFlat`；四处传参修正——
  `makeCompileUnit`、链接（含 OpenWatcom 分隔符语义）、静态库打包（prependHack 前缀保留）、
  `expandCustomCommand`，另 `collectCompileCommands` 同步。
