# 0.8.105-dev

> 绝对路径规范化的补全（F6）：前导 `~` 展开为家目录，对齐 CB `Normalize(wxPATH_NORM_TILDE)`。

## 背景

CB `cbProject::AddFile` 在路径规范化时执行 `Normalize(wxPATH_NORM_TILDE, projectBasePath)`——`<Unit filename="~/x.c">` 会展开为家目录绝对路径再相对化。扩展此前不展开 `~`（`isAbsolute=false`）→ 拼接到工程根 → 文件不存在 → 按 F4 语义被判「源缺失」（伪 WARNING + 强制重链）。

## 修复（F6）

- `parseUnits` 在绝对路径判定前展开前导 `~` / `~/`（`os.homedir()`，与 CB NORM_TILDE 对齐；`~user` 形式极罕见，不展开）。
- 展开后进入既有规范化链（同盘相对化 / 跨盘保留）。

## 验证

- `tests/test-abs-unit-path.js` 9→**10 断言**：D1 `~/cb-abs-tilde-probe.c` → `absolutePath` = 家目录路径；A-C 回归不变。
- 全量 `TOTAL=111 FAIL=0 SKIP=1`；`tsc` 0 错误。
