# 0.8.103-dev

> 0.8.102-dev（else 分支 WARNING 条目强制）的补全：compilerVar 显式为空且源缺失时补齐 CB 同款 WARNING 输出；补缺失可链接源文件的回归断言。

## 修复（F4a）

- CB 的 else 分支（directcommands.cpp:562-566）在 `GetCompileFileCommand` 的 compilerVar 判定**之前**执行（`IsObjectOutdated` 先于它），故 compilerVar 为空且源缺失时同样输出 `WARNING: Can't read file's timestamp: <路径>`。扩展此前该路径已计入强制（`missingSourceFiles` 在 compilerVar 检查前收集）但未打印 WARNING。
- 现在 compilerVar 空分支在源缺失（非 rebuild、非 autoGeneratedBy）时补齐同款 WARNING（文案与 `isUpToDate` 一致），与 CB 输出完全对齐。

## 验证

- `tests/test-link-input-outdated.js` 23→**24 断言**：C23 缺失可链接源（`gone.c`，link=true）+ compilerVar 空缺失源（`gone2.ld`）→ 双 WARNING + 不再 `Nothing to be done` + 链接被强制执行（因缺失对象失败，与 CB 一致，两次构建均如此）；C1-C22 回归不变。
- 全量 `TOTAL=110 FAIL=0 SKIP=1`；`tsc` 0 错误。
