# 0.8.110-dev

> UI 核查 N1/N3 修复：
> - **N1**：Symbols 视图换独立图标 `resources/symbols.svg`（不再与 Project 视图共用）；
> - **N3**：Build Log「只看错误」开关的两种状态分两条命令呈现——未开启显示 `$(filter)`、已开启显示 `$(filter-filled)`（新命令从命令面板隐藏）。

## 背景

- N1：`codeblocks.symbols` 视图原 `icon` 复用 `resources/project.svg`，侧栏标题图标与 Project 视图相同。
- N3：`codeblocks.buildLog.toggleErrorsOnly` 的两条 `view/title` 条目 when 互补但指向同一 command、同一图标——VS Code 的 icon 定义在 command 上，无法按 when 区分，导致开/关无视觉反馈。

## 改动

- 新增 `resources/symbols.svg`（symbol-method 风格：菱形 + 圆点，`currentColor` 描边随主题，与现有图标风格一致）；`package.json` views 中 Symbols 视图 icon 改指向它。
- 新增命令 `codeblocks.buildLog.showAllMessages`（icon `$(filter-filled)`，标题 "Code::Blocks: Show All Messages (Build Log)"），与 `toggleErrorsOnly`（`$(filter)`）共用同一开关处理器（`extension.ts` 注册两条命令）；`view/title` 两条条目改为互补 when + 不同命令；新命令经 `menus.commandPalette` `when: false` 从命令面板隐藏（仅工具栏可见）。

## 验证

- 新增 `tests/test-ui-icons.js`（9 断言：图标不共用 / 文件存在 / 两命令图标不同 / when 互补 / 命令面板隐藏 / dist 双注册）。
- `tsc` 0 错误；全量回归 `TOTAL=113 FAIL=0 SKIP=1`；headless 构建检查 EXIT 0（跑完自动还原 hello.exe）。
