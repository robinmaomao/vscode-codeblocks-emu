# 0.8.100-dev

> 编译条目计数强制重链：对齐 Code::Blocks `GetTargetCompileCommands:585`——`compile=1` 但对象永不产生的文件（自定义空命令 / 工具未匹配）**每次构建**都强制重链接 / 重新打包。

## 背景（用户实测反馈）

- 用户工程（RISC-V `efuse_patch.cbp`）中 `ram.ld` 配置为：
  ```xml
  <Unit filename="ram.ld">
      <Option compile="1" />
      <Option compiler="riscv32-v3" use="1" buildCommand=" " />
      <Option compiler="riscv32" use="1" buildCommand=" " />
  </Unit>
  ```
- 实测 Code::Blocks 修改 `ram.ld` 后增量编译**会重链接**；扩展此前输出 `Nothing to be done`（编译链将空白命令判为 no-command 跳过、链接输入白名单又跳过带自定义命令的文件 → 双重落空）。

## CB 机制取证（directcommands.cpp 逐行）

1. `compile="1"` → `ram.ld` 进入编译文件列表（`GetProjectFilesSortedByWeight(target, true, false)`，:545）；
2. `IsObjectOutdated`（:1148）：对象 `Output/obj/ram.o` 永不产生 → `if (!timeObj) return true`（:1175）→ **每次构建都判定过期**；
3. `GetCompileFileCommand`（:263）：`useCustomBuildCommand` → 命令 = `" "`（空白≠空，未触发 :349 的空命令跳过）→ 默认「完整命令行」日志 → `ret.Add(COMPILER_SIMPLE_LOG + " ")` → **至少产生 1 个条目**；无自定义命令时同样产生 "Skipping file (no compiler program set)" 条目（:350）；
4. `GetTargetCompileCommands` 末尾（:585）：`GetLinkCommands(target, ret.GetCount() != counter)` → **编译阶段产生过任何条目即 force=true**；
5. `GetTargetLinkCommands(target, force=true)` 跳过全部时间戳检查 → 生成链接命令 → 重链接；
6. `compilergcc.cpp:2627-2633`：`hasCommands = cmds.GetCount()`（含日志行）→ 不输出 "Target is up to date."，post-build 照跑。

即 CB 在该类工程下**每次增量构建都重链接**（条目计数把日志行也计入的实现副作用，`logging=clogNone` 时不触发）。

## 修复（对齐，非保护性差异）

- `buildEngine` 编译循环新增 `staleNoopFiles`：`compile=true` 且 `makeCompileUnit` 返回 `no-command` / `not-compilable` 的文件，按 CB `IsObjectOutdated` 语义判定过期（对象缺失即过期；`rebuild` 恒真；`autoGeneratedBy` 与 `compilerVar` 空不产生条目，对齐 CB 不强制）。
- 三处接入：链接 `forceLink`、静态库 `forceArchive`、「Nothing to be done」早退分支（条目存在则不再早退）。
- 触发日志：`目标 "Debug" 含 N 个过期且无可执行命令的编译文件（ram.ld），强制链接（对齐 CB 条目计数）`（重新打包同款）。
- `linkInputsOutdated`（0.8.96-dev 的 mtime 保护性增强）保持不变：仅覆盖 compile=false 的普通链接输入；带自定义命令（use=1）文件改由条目计数规则负责，注释已同步更正。

## 验证

- `tests/test-link-input-outdated.js` 11→**16 断言**：新增用户工程原样场景（compile=1 + 自定义空命令）——C11 首次构建、C12 **无修改也重链接**（CB 条目计数）、C13 改动仍重链、C14 无自定义命令（Skipping 条目）仍强制、C15 静态库无修改也重新打包；既有 C4/C10（compile=false 无改动 → Nothing to be done）回归不变。
- 全量 `TOTAL=110 FAIL=0 SKIP=1`；`tsc` 0 错误。
