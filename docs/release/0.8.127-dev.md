# 0.8.127-dev

> 编译缓存检测行为调整（用户指定，承接 0.8.126-dev 的 R4 集成）：
> 检测到但未启用 → **每次打开工作区都询问是否启用**；
> 激活/重检的检测结果（**版本号 + 路径**）**写入 Code::Blocks 输出通道**。

## 变更

- `src/extension.ts`：
  - **启用询问改为每次激活弹出**：移除一次性标记 `enablePrompted`（不再写入/读取 globalState 键 `codeblocks.compilerCache.enablePrompted`）；每次扩展激活（打开含 `.cbp`/`.workspace` 的工作区或其他激活事件）只要「已检测到工具且未启用」就弹窗；文案含版本号（如「检测到编译缓存工具 ccache 4.14.1，是否启用？」）；新增「不再提示」按钮（写入 `dontAsk`；修改两项编译缓存设置自动重置；引导命令「重新检测」的 manual 路径仍绕过）；
  - **检测结果输出**：激活预热 / 设置变化 / 引导「重新检测」后，对检测到的工具逐条写入输出通道：`[Code::Blocks] 编译缓存: 检测到 ccache 4.14.1 → <路径>（已启用/未启用）`；
- `src/build/compilerCache.ts`：提示矩阵更新——「未启用 + 检测到」不再一次性去重（仅受「不再提示」约束）；`CompilerCachePromptFlags` 移除 `enableShown` 字段；
- 测试：`test-compiler-cache-detect` 36→**37**（新增 enable+dontAsk/manual 用例与无去重断言）；`test-install-guide` 版本断言与接线更新（移除 enablePrompted、新增检测结果输出/「不再提示」按钮断言）22→**23**；
- 文档：使用说明 §13.2（询问频率 + 输出通道说明）、package.json 设置描述、开发进度、本说明。
