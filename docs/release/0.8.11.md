# 0.8.11

> 发布日期：2026-09-24

## 概述

本版本主线是**编译产物与 Code::Blocks 字节级一致（Build Parity）**。经过 0.8.3 → 0.8.11 共 8 个小版本的持续对齐，扩展生成的 `.o / .a / .bin / .map` 以及 debug 段信息（`.debug_info` / `.debug_line` / `.debug_str`）已可与 Code::Blocks 原生构建做 map.txt 级逐字节对比验证，适用于真实 RISC-V 工程的产物比对。

## 编译产物一致性（核心）

### 文件类型判定对齐 `FileTypeOf`（v0.8.4）

此前扩展用硬编码正则过滤「可编译文件」，只识别 `.c/.cpp/.cc/.cxx/.rc`，导致：

- **汇编源文件（`.S` / `.s` / `.asm` / `.ss` / `.s62`）被跳过**：例如 RISC-V 工程的启动/复位向量 `reset.S` 未被汇编、未参与链接，最终链接产物缺少 `reset.o`，二进制内容错误（链接日志只有 `main.o`，却显示「构建成功」的假象）。
- **链接脚本（`.ld`）与自定义构建命令语义不符**：`<Option compile="1"/>` + `<Option compiler="..." use="1" buildCommand=" "/>` 的 no-op 自定义命令未被按 Code::Blocks 语义识别（此前对 `buildCommand` 做了 `trim()`，`" "` 被误判为空）。

改动：新增 `src/model/fileTypes.ts`（`FileTypeOf` 等价实现），`parser` 按文件类型计算 `compile/link` 默认值，`buildEngine` 编译/链接分两遍收集、资源文件走 `CompileResourceCmd`（windres），汇编源固定归 C 编译器。

### 静态库归档对齐 Code::Blocks（v0.8.7）

- 静态库归档改用 `LinkStatic` 模板（`$TO_WINDOWS_PATH` 宏 + 多行命令拆分，对齐 gcc LinkStatic 两行模板）。
- 静态库/def 输出名自动加 `lib` 前缀（`computeLibOutput`，对齐 `SetupOutputFilenames`）。
- `resolveOutputFile` 对静态库返回实际库文件路径（`libdemo.a`）。

### 编译单元按 weight 排序 + 资源对象分离（v0.8.8）

- 编译/链接文件按 `weight` 排序（对齐 `GetProjectFilesSortedByWeight` / `MySortProjectFilesByWeight`）。
- 并行编译按 weight 分组，同组并行、跨组串行屏障（对齐 `COMPILER_WAIT`）。
- 资源对象（`.rc`）分离到 `$link_resobjects`（对齐 `GetTargetLinkCommands`）。
- `ProjectFile` 新增 `weight` 字段并解析 `<Option weight>`。

### 文件排序改用字节序（v0.8.9）

`compareFilesByWeight` 由 `localeCompare` 改为字节序比较（对齐 `wxString::CmpNoCase`），修复 `func.c` 被错排到 `func_aux.c` 之后导致链接对象顺序不一致的问题。

### `$file` 分隔符对齐（v0.8.10）

- 构建命令统一用反斜杠对齐 Windows Code::Blocks（新增 `toNative`，win32 才做 `/`→`\` 转换，只改命令字符串边界，不动全局 `absolutePath`）。
- clangd 生成的 compile_commands 保持正斜杠（`nativeSep:false`）。

### 盘符归一化（v0.8.11）

- 编译命令路径盘符大写对齐 Code::Blocks（方案 A：`upperDrive()`，win32 且 `/^[a-z]:/` 才大写，相对/UNC 不变）。
- `runSingleCommand` / `runScriptCommand` 的 `spawn` `cwd` 同步归一化，消除 debug 段内 `d:\` vs `D:\` 不一致。

## 健壮性修复

### 构建命令路径引号与响应文件（v0.8.5）

- `ar` 归档命令对含空格工具链路径加引号（导出复用 `quoteIfNeeded`）。
- 超长命令行自动改用响应文件（`@file`，对齐 Code::Blocks `CheckForToLongCommandLine`，阈值 8000 字符）。

### pre/post-build 脚本实时读取系统 PATH（v0.8.3）

- 新增 `src/tools/windowsPath.ts`：从注册表 Machine+User 实时读取 PATH，展开 `%VAR%`，TTL 5 秒缓存。
- `scriptRunner` 在 Windows 下合并实时系统 PATH，解决运行期新加入 PATH 的工具找不到的问题。

## 文档

- 新增《编译产物一致性排查经验》：记录 localeCompare/字节序排序差异、map.txt 逐行对比定位法及检查清单。
