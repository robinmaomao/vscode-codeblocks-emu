# 0.8.154

> 发布日期：2026-11-18 ｜ 体验版（0.8.153 → 0.8.154）
> **主题**：Code::Blocks 剩余功能缺口 + 健壮性收口

## 概述

本轮按 0.8.152 逐项排查结论实施 P0/P1/P2 批次：补齐 Workspace 生命周期、`.workspace` 外部修改检测、无工程编译编码、指令级步进/内存查看、Backtick Cache、Copy Strings、Profiler、SymTab、Makefile CompileFile/DistClean；同时修复单元路径 XML 转义、原子写盘与 `package.json` 静态中文等健壮性问题。

## 🧩 功能

- **File / Workspace**：Save Project As…、Save Workspace、Save Workspace As…、Close Workspace、Open default workspace；关闭最后一个工程清理工作区状态；保存工作区写回工程顺序、`active` 与 `<Depends>`。
- **`.workspace` 外部修改检测**：`**/*.workspace` watcher + 焦点兜底；提示 Reload / Ignore；只重载磁盘签名变化的工程。
- **New 子菜单**：New Build Target…（GUI / Console / Static / Dynamic / CommandsOnly）、New File…（C / C++ / Header / Empty）。
- **Debug**：Next Instruction / Step Into Instruction；Examine Memory…（16 字节/行 hex + ASCII）。
- **Tools**：Backtick Cache…（Expression/Value + 清空并关闭）、Copy Strings、Profile Target（gprof flat profile）、Find Symbol in Libraries…（工程链接库 `nm -C -A`）。
- **Makefile 项目**：CompileFile 与 Dist Clean 接入 `<MakeCommands>`。

## 🛡️ 健壮性与一致性

- **原子写盘**：`.cbp` / `.workspace` 改为同目录临时文件 + rename；失败保留原文件。
- **单元路径 XML 转义**：含 `&` / `<` / `>` / `"` 的路径可添加、改名、切换 compile/link、移除。
- **无工程编译编码**：默认扩展自管进程 + UTF-8/GBK 逐行解码；`codeblocks.noProjectCompile.useTaskTerminal` 可回退旧任务终端。
- **i18n**：launch.json 调试属性、寄存器视图标题、自定义工具设置说明全部走 `package.nls.*`；新增 `package.json` 无直接中文守卫。

## ⚠️ 行为变化与升级提示

- `Compile File (Without Project)` 默认不再使用 VS Code 任务终端；需要旧行为时设置 `codeblocks.noProjectCompile.useTaskTerminal = true`。
- 关闭最后一个工程会清空工作区状态；如需保留工程列表，请先 Save Workspace。
- Profiler/SymTab 为子集实现：call graph 交互树、源码注解、任意目录批量扫描未包含。
