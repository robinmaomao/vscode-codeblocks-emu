## B1 / B2 / C4 评估结论（方案 A：不做）

- **结论**：default.conf 为 Code::Blocks 本体私有配置（CB 退出/打开设置对话框时整文件覆写，写入竞态无法消除）；程序路径已由「Detect Compilers → `compilerPrograms`」与 default.conf `user_sets` 双重覆盖，全局搜索目录/选项/库/变量已被完整读取并注入构建——**收益 < 成本，不做**（2026-09-27 用户确认）
- **替代**：新增命令 `Open default.conf`（Settings → Default Config…）——打开文件手工编辑；保存后扩展读取立即生效（CB 本体需重启）；管理动作（Copy/Rename/Delete 编译器集、全局变量编辑）由 Code::Blocks 本体承担
