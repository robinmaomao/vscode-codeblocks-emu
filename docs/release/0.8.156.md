## 概述

本版补齐 Code::Blocks 工具链中三个「无成熟 VS Code 替代」的缺口：gprof Profiler 的调用图/源码注解/报告导出、AutoVersioning 的项目配置与构建钩子、以及 TCC/BCC/DMC/ARM/PowerPC 编译器资源。Doxygen、打印、Fortran、环境变量、单库 nm、Valgrind 等有成熟替代的功能不重复实现，改为在推荐扩展文档中给出扩展 ID 与使用建议。

## 📊 Profiler（gprof）

- 新增 **call graph 解析与输出**：`parseGprofCallGraph` 识别 `index/% time/self/children/called/name` 条目和调用者边，按函数分组展示。
- 新增 **`gprof -A` 源码注解**：设置 `codeblocks.profiler.annotatedSource` 默认开启；结果写入独立的 **Code::Blocks Profiler (Annotated Source)** 输出通道。
- 新增 **报告导出**：Profiler 完成后 QuickPick 提供「导出 CSV…」「导出 HTML…」；CSV 按 RFC 4180 转义，HTML 为自包含报告（flat profile + call graph）。
- `formatProfilerTable` / `formatProfilerCallGraph` 输出保持纯文本，可复制到 Issue/日志。

## 🔢 AutoVersioning

- 读写 `.cbp` 的 `<Extensions><AutoVersioning>`：`Scheme` / `Settings` / `Changes_Log` / `Code` 全部字段与 Code::Blocks 对齐。
- 新命令：
  - `Code::Blocks: AutoVersioning...`：配置工程、编辑 `major.minor.build.revision`、切换自动递增、设置头文件路径。
  - `Code::Blocks: Bump Version`：按 CB `CommitChanges` 规则递增 revision/build/minor/major。
  - `Code::Blocks: Generate Version Header`：立即生成 `version.h`。
- 构建钩子：配置存在时，**构建前**重新生成 `version.h`；**构建成功后**递增 `BUILDS_COUNT` 并写回（原子写）。
- 支持 C / C++ 输出、`#define` 模式、前缀、命名空间、日期声明、header guard、`BUILD_HISTORY`、可选 `manifest.xml` 版本同步。
- 生成文件可用于 Windows 资源：`RC_FILEVERSION` / `RC_FILEVERSION_STRING` / `FULLVERSION_STRING`。

## 🧰 编译器资源

- 新增随包编译器选项：**TCC**、**Borland C++ 5.5/5.82**、**Digital Mars**、**ARM ELF GCC**、**PowerPC EABI GCC**。
- 编译器自动探测接入上述工具链（PATH + 常见安装目录 + `master/bin` 与 `master` 直接布局）。
- `compiler_*.xml` / `options_*.xml` 派生自 Code::Blocks GPL v3 资源，保持原有命令模板与选项分类。

## ⚠️ 行为变化与升级提示

- `codeblocks.profiler.annotatedSource` 默认开启；大工程生成 `gprof -A` 输出可能较慢，可关闭。
- AutoVersioning 会在构建前重写 `version.h`；如果该文件由手工维护，请先备份或关闭工程的 AutoVersioning 配置。
- 新增编译器资源不会改变现有工程的编译器选择；需要时在 New Project / Select Compiler 中选择。
- 有成熟替代的 Doxygen/打印/Fortran/环境变量/单库 nm 仍不内置，见推荐扩展文档。
