> 发布日期：2026-09-25

## 第五轮对齐：M1/M2 + 单文件编译与单文件 Clean

### M1 — 显式空 compilerVar 文件跳过

对齐 CB `GetCompileFileCommand` 开头：`compilerVar` 为空的文件直接跳过（`Cannot resolve compiler var for project file`，debug 日志）。此前扩展按扩展名兜底继续编译，行为不一致。

### M2 — 响应文件阈值差异补入文档

CB `CheckForToLongCommandLine` 阈值 32767（CreateProcess 上限）/ 131072（Linux）；扩展 8000（命令经 cmd.exe 执行，受 cmd 命令行 8191 上限约束）。功能等价但阈值不同，已补入「有意差异」表。

### 单文件编译 / 单文件 Clean（对齐 CompileFile / GetCleanSingleFileCommand）

- **Build File**：工程树右键文件 → 只编译该文件不链接。增量判断（`DepsSearchStart` + `IsObjectOutdated`）、取消支持、错误输出解析与整目标构建一致；编译命令与整目标构建**共用 `makeCompileUnit`**（字节级一致，重构自 1b 循环）。
- **Clean File**：删除该文件的对象文件；编译器 `needDependencies` 时连带删除 `.depend` 依赖文件。
- compile=false / compilerVar 空 / 非可编译类型时按 CB 语义跳过；命令为空输出 `Skipping file (no compiler program set)`。
- 新增命令 `codeblocks.compileFile` / `codeblocks.cleanFile`（工程树文件节点右键菜单）。
