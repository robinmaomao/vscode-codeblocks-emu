# 0.8.111-dev

> 输出清理核查（用户确认：A + C 做；B 加 `codeblocks.build.persistLog` 开关，**默认 false**）：
> - **A**：新命令 `Code::Blocks: Clear Build Output`（Build Log 视图标题栏 `$(clear-all)`）——清空输出面板 + Build Log 树 + Problems 诊断；`Clear All Errors` 顺带增强为同语义；
> - **B**：输出通道按 `codeblocks.build.persistLog` 选择——默认 false 用普通 `OutputChannel`（窗口重载即空、可彻底清空）；true 用 `LogOutputChannel`（写盘跨窗口保留，历史取证）；
> - **C**：单文件编译 / 单文件清理 / Clean / 自定义工具（output 模式）开头自动清空输出（与整目标构建一致）。

## 背景

原「Code::Blocks」输出通道固定 `createOutputChannel('Code::Blocks', { log: true })`——日志通道写盘持久化，窗口重载后历史仍在；且唯一清除命令 `Clear All Errors` 只清 Build Log 树，不清输出文本与 Problems 诊断；单文件编译/清理路径开头不清输出，历史不断累积。

CB 对照：`CompilerGCC::ClearLog`（compilergcc.cpp:1129-1145，`m_pLog->Clear()`），`DoPrepareQueue(clearLog=true 默认)` 每次构建开始清空日志面板。

## 改动

- 新模块 `src/build/cbChannel.ts`：`CbOutput` 接口 + `createCbOutput(name, persistLog)`——日志模式直通 `LogOutputChannel` 分级方法；普通模式 `info/warn/error → appendLine`、`debug/trace` 丢弃（与日志通道默认 Info 级的可见集合一致）。
- `extension.ts` / `buildEngine.ts` / `compileCommands.ts` 通道类型收敛为 `CbOutput`；
- `extension.ts`：`clearBuildOutput()`（outputChannel.clear + 树 setSummary(undefined) + diagnosticCollection.clear）注册为两条命令 `codeblocks.clearErrors`（增强）与 `codeblocks.buildLog.clearOutput`（新）；`buildSingleFile` / `cleanSingleFile` / `clean()` / `runConfiguredTool`（output 模式）开头 `clear()`；
- `package.json`：新命令（`$(clear-all)`）+ Build Log `view/title` 入口 `navigation@2`；新设置 `codeblocks.build.persistLog`（boolean，默认 false，构建与日志分区）。

## 行为变化提示

- 默认输出通道由日志通道改为普通通道：**窗口重载后历史自动清空**（此前会保留）；如需跨会话保留历史，开启 `codeblocks.build.persistLog` 后重载窗口。
- `Clear All Errors` 现在同时清空输出面板与 Problems 诊断（原仅清 Build Log 树）。
