## 事实更正（基于 wxWidgets 3.2.4 filename.cpp 源码核对）

- **`~` 展开**：wx `Normalize` 的 NORM_TILDE 仅 `wxPATH_UNIX` 格式生效；CB 在 Normalize 前已将工程根拼入路径（cbproject.cpp:903-904），故 CB **Windows 从不展开 `~`/`~user`**（字面 `~` 目录），Linux 经 `MakeAbsolute` 展开两者。0.8.105 的 F6 因此重新定性为**保护性增强**（等价 CB-Linux 行为）；`~user` 维持不展开（与 CB-Windows 一致）。parser 注释、对齐对照行同步更正。
- **跨卷对象路径**：wxFileName `SplitVolume` 存 `posFirstColon` 之前（**不含冒号**），故 CB `pfDetails::Update`（projectfile.cpp:474-492）跨卷对象 = `obj\Debug\D\Source\foo.o`——扩展 isAbsolute 分支输出相同。此前「卷字母去冒号为保护性差异」为误判，已更正为「与 CB 一致」。对齐对照「跨卷/绝对路径对象」行同步重写（UNC：CB 自身双重段怪路径；扩展合并单段为保护性近似）。
