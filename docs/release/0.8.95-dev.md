# 0.8.95-dev

> 第六轮「CB 有开关、扩展无条件执行」核查 **F1 + F1b** 实施：构建结束 Build Log 聚焦门控 / 首个错误自动跳转 / 失败 toast 静默开关。
> （F5/F8 已于 0.8.94-dev 实施；F2/F3/F4 与其余观察项待确认。）

## 背景（问题）

- `finishBuildSummary`（`src/extension.ts`）此前**无条件** `codeblocks.buildLog.focus` —— 成功/失败/取消都会把底部面板抢到 Build Log。
- 失败 toast 无条件弹（成功侧已有 `codeblocks.ui.quietSuccess`）。

## CB 取证（message_manager）

- `compilergcc.cpp:4064-4107`（`OnJobEnd` 收尾）：有错误 → `/auto_show_build_errors`（**默认 true**）弹出消息面板 + **总是**切换到 Build messages + `/auto_focus_build_errors`（**默认 true**）聚焦第一个错误；无错误有警告 → `/auto_show_build_warnings`（**默认 true**）保持；否则 `HIDE_LOG_MANAGER`（`/auto_hide` 默认 false）。
- UI 默认值：`environmentsettingsdlg.cpp:212-220 / 611-615`；标签 `env_settings.xrc:459/482/493`（"Focus first error in the editor after build finishes"）。

## 修复

### F1 面板聚焦门控

- 新设置 **`codeblocks.ui.buildLogAutoFocus`**（枚举，**默认 `errors` 对齐 CB**）：
  `errors`（仅本次构建有错误）/ `errorsAndWarnings` / `always`（旧行为）/ `never`。
- 新纯模块 `src/ui/buildLogFocus.ts`（`normalizeBuildLogAutoFocusMode` / `shouldAutoFocusBuildLog` / `maybeAutoFocusBuildLog`，副作用经回调注入便于单测）；`finishBuildSummary` 改为门控调用；配置**每次构建实时读取**。
- 构建**开始**时的 `outputChannel.show(true)` 保持无条件（对齐 CB `PrintBanner`，不在本项范围）。

### F1 首个错误跳转（`auto_focus_build_errors`）

- 新设置 **`codeblocks.ui.buildLogFocusFirstError`（默认 true 对齐 CB）**：构建结束存在错误时跳转到第一个错误（`buildLogTreeProvider.gotoFirstError()`，打开文件并定位行/列，preview）。与 `buildLogAutoFocus` 独立；关闭后仍可用 `F4` 逐个查看。

### F1b 失败 toast 静默

- 新设置 **`codeblocks.ui.quietFailure`（默认 false）**：失败不弹错误 toast（日志 + Build Log 树 + 状态栏诊断徽标不受影响）。

## 行为变化（注意）

- 成功（无错误）构建与取消构建**不再抢占面板**（旧行为可设 `buildLogAutoFocus: "always"` 恢复）；有错误时默认聚焦面板并跳转首个错误。
