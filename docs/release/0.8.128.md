## 汇编注释（0.8.128-dev）

- 默认值：`language-configurations/asm.json` 行注释标记 `#` → `//`（预处理的 `.S` 安全；块注释保持 C 风格）；
- 新设置 `codeblocks.editor.asmHashComment`（boolean，默认 false）：开启后经 `vscode.languages.setLanguageConfiguration('asm', …)` **动态注册** GAS 原生 `#`（扩展动态注册优先级高于静态文件配置；仅覆盖 comments，括号等仍沿用静态配置）；关闭即释放、自动回退静态 `//`；**修改即时生效**（`Ctrl+/`、`Ctrl+K Ctrl+C/U`、命令面板等全部注释路径一致）；
- 实测依据：原生 `.s`（GAS 直接汇编）在 RISC-V（binutils 2.28 / 2.43）与 x86 上均拒绝 `//`（整行 junk / 行尾 illegal operands / invalid char），`#` 才是 GAS 原生注释（行首 / 行尾均安全）；`.S` 经 cpp 预处理则两者均可——默认 `//` + 可切回 `#` 并存。
