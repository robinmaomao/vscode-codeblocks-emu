## B1/B2/B3 Banner 精确对齐

- CB：`PrintBanner`（compilergcc.cpp:1786-1830）——bsTargetPreBuild 打 Build、bsTargetClean 打 Clean、
  CompileFile:3156 打 Build file；文案 `-------------- <Action>: <target> in <project> (compiler: <name>)---------------`
  （左 14 连字符+空格，右 15 连字符）。

  `cleanTarget` 开头（每目标 Clean banner）、`compileFile` 开头（Build file banner）三处调用；
  编译器显示名按目标编译器（对齐 PrintBanner 的 GetCurrentCompilerID）。

## B4 无效编译器目标跳过

- CB：`CompilerValid`（1741-1754，GetCompiler 未注册 → null）+ `PreprocessJob:2759-2764`
  报错并跳过目标；`Compiler::IsValid:191-231`：masterPath 设置时检查 C 程序存在性（bin/ 或根目录），
  未设置视为 PATH 查找。
- 实现：`resolveTargetCompiler`（未注册 ID 返回 undefined：无 options_<id>.xml、非用户编译器、
  非当前配置编译器）；`isCompilerUsable`（masterPath 下 C 程序存在性检查）；build 目标过滤
  报错 `The compiler's setup (...) is invalid ... Skipping...` 并跳过（全部无效 → 无动作返回 false）。

## B5 反引号缓存清理

- CB：`cbClearBackticksCache` 在 Build/Rebuild/BuildWorkspace/RebuildWorkspace/CleanWorkspace 入口调用；
  单目标 Clean 不清。
- 实现：`clearBackticksCache()` 在 `build()` 开头调用（覆盖 Build/Rebuild/工作区构建；Clean 命令不进 build）。
