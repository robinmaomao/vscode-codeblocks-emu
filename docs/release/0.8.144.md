## 概述

VS Code 内置搜索无法按「已打开 `.cbp` 工程」排序或白名单过滤：扩展 API 不暴露搜索结果排序，`search.exclude` 只能排除、不能只保留工程文件。本版因此新增**扩展自己的工程搜索视图**，把搜索范围严格限制在已打开工程的文件模型内，并用项目树/活动工程排序提供更符合 Code::Blocks 使用习惯的结果。

- 🔎 **Sidebar 视图**：`Project Search`（`codeblocks.search`），文件 / 内容双模式，活动工程优先，点击跳转。
- 🎨 **UI 对齐内置搜索**：`--vscode-font-size` + 22px 行高、内联 codicon SVG 图标、`Aa` / `.*` / 清除内嵌搜索框、状态行工具条；结果按「工程 → 文件 → 匹配」分组，工程头吸顶并可折叠。
- ⚡ **性能**：文件模式纯内存（prepared entries 缓存 + 签名自校验）；内容模式 `worker_threads` 隔离、可取消、超时终止、失败回退。
- 🕘 **搜索历史**：搜索栏顶部 **搜索历史** 按钮（含模式图标）+ `保留历史` 可视化 switch，点击历史优先跳转上次结果。
- ⌨️ **入口**：`Ctrl+Alt+P`（文件模式）、命令 / C::B Search 菜单 / 工程树右键。
- 🧩 **不改内置搜索**：不写 `search.exclude`、不创建 watcher、不调用 `workspace.findFiles`。
- 🛠 **修复**：视图声明 `"type": "webview"` 并提前注册 provider；新版 VS Code 默认按 TreeView 解析，缺省会显示“no data provider registered”而看不到搜索栏。
- 🛠 **修复（clangd）**：合并打开工程/切换工程/改编译器触发的连续重启请求（1.5s 窗口 + 5s 最小间隔），等客户端 `Running` 后再留 2s 稳定期，并优先调用 `LanguageClient.restart()`（串行 stop→start）；修复 `command 'clangd.applyFix' already exists` 导致语言服务器启动失败。

规模（0.8.144 时点）：命令 **113**、设置 **85**、视图 **6**、快捷键 **34**；新增 7 个测试脚本（纯逻辑 / worker / HTML / Provider / 历史 / 任务 / 命令注册）。

## 一、文件模式

- 数据源 = `openProjects[].files`，在内存中构建 prepared entries（小写 basename/path），按「活动工程 1.25× → 分数 → 路径长度 → 字典序」排序；同路径跨工程去重（活动工程优先）。
- 空查询列出作用域内全部工程文件（Top 500），便于浏览；输入即搜（60–80ms 防抖）。
- 结果按工程分组（工程头吸顶、可折叠、显示文件数，活动工程标记在名称后）；文件行显示语言图标（`.c` 蓝色 C、`.h` 紫色 C（VS Code Explorer 的 Seti 图标字体））+ 文件名 + 目录；单击打开文件，行尾定位按钮在工程树中定位；最多渲染 200 行 + 「加载更多」。
- 多个工程的 `.cbp` `title` 相同（如 `earphone/app.cbp` 与 `esop8/app.cbp` 都叫 `app`）时，分组名改用 `.cbp` 父目录名，避免同名分组难以区分。
- 条目缓存签名 = 活动工程 + scope + 工程/文件数量 + 相对路径滚动哈希；模型变化即重建，漏通知也不会读脏数据。

## 二、内容模式

- `worker_threads` 常驻 worker（`bundle/search-worker.js`，5 分钟空闲退出）；单飞，新搜索取消旧搜索。
- 单文件 4MB / 二进制跳过；UTF-8（含 BOM）/ GBK / UTF-16 BOM；已打开且脏的编辑器文本优先。
- 32MB 字节预算 LRU（mtimeMs + size 校验）；并发 `min(8, max(2, cpus-1))`。
- 字面量用 `escapeRegExp + i/g` 保持 UTF-16 列偏移；`/regex/` 由 `Aa` 控制大小写；零宽匹配推进；正则单行 >4000 字符跳过。
- 单文件 50 条 / 全局 500 条；20s 总超时 + 5s 无进度 terminate；worker 启动/崩溃时字面量回退宿主内扫描。
- 结果按「工程 → 文件 → 行」分组（活动工程优先），工程头与文件行均可折叠，文件行显示匹配数徽标；每次搜索默认全部展开；点击跳转并选中匹配文本；状态区显示「N 个结果，M 个文件 · 耗时」/ 进度 / 截断 / 取消 / 超时。
- 搜索框新增 `Ab` 全字匹配（仅字面量），与 `Aa` / `.*` 一样持久化并写入历史；`Ab` 通过 `\b` 边界实现，`foo(` 这类非单词结尾查询也能正确匹配。
- 搜索结果在搜索完成后固定：切换活动工程只刷新状态，不自动重排或重搜；需要更新时点「刷新」或重新搜索。

## 三、搜索历史与 UI

- 历史存 `workspaceState`（按工作区隔离，版本化 `{version:1, entries}`），文件/内容各 20 条；同模式 + 同原文精确去重并置顶。
- 顶部 `保留历史` switch 写 `codeblocks.search.keepHistory`（Global）；关闭后停止记录、历史面板隐藏，已有历史仍可清空（VS Code 模态确认）。
- 界面与 VS Code 内置搜索对齐：字体取 `--vscode-font-size`、结果行 22px 行高、图标为内联 codicon SVG（无 emoji）；`Aa` / `.*` / 清除内嵌搜索框右侧，状态行右侧为刷新 / 全部展开 / 全部折叠；匹配文本使用高对比橙色背景，不受主题 `editor.findMatchHighlightBackground` 过暗影响。
- 点击「搜索」或按 `Enter` 时立即记录（内容模式 0 结果也记录；文件模式在 `Enter` 提交时记录），打开结果只更新「上次位置」；**子树范围搜索不写历史**。
- 历史区位于视图最底部、默认折叠（按工作区记忆），头部含当前模式条数、`保留历史` 开关与「清空」，只显示当前模式历史；`Ab` 全字匹配状态随历史条目一起恢复。
- 打开结果时用「产生该结果的请求查询」更新 `lastResult`；点击历史：有效上次结果直接跳转，失效则恢复状态并重跑；`↻` 仅重跑。
- 视图状态（模式 / 每模式查询 / 范围 / 选项 / 工程分组与文件展开状态）存 `webview.setState` + `workspaceState`；语言切换重建 HTML。
- 所有颜色使用 `--vscode-*`，支持深/浅/高对比主题；窄栏（<240px）历史文字缩为图标；`role=switch`、`aria-live`、键盘导航。

## 四、入口与设置

- `codeblocks.searchProjectFiles`（`Ctrl+Alt+P` / mac `Cmd+Alt+P`）：打开/聚焦视图，切到文件模式。
- `codeblocks.searchInProjectFiles`：打开/聚焦视图，切到内容模式；编辑器单行选区（≤300 字符）自动预填并搜索；工程树右键节点时限定子树。
- 新增设置：
  - `codeblocks.search.scope`：`openProjects`（默认）/ `activeProject`。
  - `codeblocks.search.keepHistory`：默认 `true`。
- 重置布局顺序更新为 Project → Search → Symbols；不提升布局版本，不覆盖用户已有排布。

## 六、行为边界

- 不替换内置搜索，不修改 `search.exclude` / `files.watcherExclude`，不创建文件监视器。
- 只搜索 `.cbp` 中列出的文件；未打开工程、工程外文件、生成但未登记的文件不会出现。
- 内容搜索为逐文件扫描，不建立全工作区索引；超大工程建议使用更精确的查询或内置搜索。
