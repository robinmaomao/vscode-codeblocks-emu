# 0.8.123-dev

> 打包瘦身（Y1）：esbuild 单文件入口 + 依赖内联，VSIX 由 **199 文件 / 528.46 KB** 降至 **74 文件 / 306.78 KB**。
> 用户确认范围：仅 Y1（Y2/Y3 待另行确认；历史待决项除审计 2.5 / 3.2 外维持现状）。

## 背景

此前打包包含两部分冗余：`dist/**`（74 个 tsc 模块文件，入口仅需其一）与 `node_modules/**`
（`fast-xml-parser` 52 个文件）——合计约占发布包 2/3 的文件数与大量体积。

## 实现

- **入口切换**：`main` 由 `./dist/extension.js` 改为 `./bundle/extension.js`（esbuild 单文件产物）；
  `dist/` 保留原样（本地开发与 19 个测试文件的静态断言依赖 tsc 原形输出，**不覆盖**）。
- **构建脚本**：
  - `npm run bundle` = `esbuild src/extension.ts --bundle --platform=node --format=cjs --external:vscode --sourcemap --outfile=bundle/extension.js`；
  - `npm run package` = `compile → bundle → vsce package`（一键发布）；
  - `.vscode/tasks.json` 新增 `build-extension`（compile + bundle 依序），F5 调试 `preLaunchTask` 与 `outFiles` 同步（bundle 带 sourcemap，调试映射可用）。
- **依赖内联**：`fast-xml-parser` 打进 bundle 后不再需要安装期依赖 → 移入 `devDependencies`；
  新增 `THIRD-PARTY-NOTICES.md`（MIT 归属声明，随包分发）。
- **打包排除**：`.vscodeignore` 新增 `dist/**` 与 `node_modules/**`（`**/*.map` 保持排除——bundle 的 sourcemap 仅本地开发用）。
- `bundle/` 加入 `.gitignore`（生成物不入库）。

## 验证

- `npm run compile` EXIT 0；`npm run bundle` EXIT 0；
- bundle 冒烟：`require("vscode")` 保持 external、`XMLParser` 已内联、无相对 require 残留、
  CJS 导出块含 `activate/deactivate`；**mock vscode 加载 bundle 成功且导出函数可用**（已固化为回归断言）；
- 新增 `tests/test-bundle-packaging.js`（12 断言：main/脚本/依赖/忽略清单/第三方声明 + 产物四项 + 加载冒烟；
  bundle 未构建时仅校验配置）；
- 全量回归 `TOTAL=129 FAIL=0 SKIP=1`；headless 构建检查 `EXIT=0`；文档链接校验 91-0；
- 打包并安装 `codeblocks-vscode-0.8.123-dev.vsix`（vsce 报告 74 文件 / 306.78 KB；`vsce ls` 内容 72 项：
  bundle 1 / dist 0 / node_modules 0；需 Reload Window）。
