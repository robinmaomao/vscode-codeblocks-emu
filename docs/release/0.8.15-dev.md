# 0.8.15-dev

> 发布日期：2026-09-24

## 修复：状态栏「Code::Blocks」按钮常驻入口

修复打开工程后左下角「Code::Blocks」按钮消失的问题。

- **根因**：状态栏 `Code::Blocks 项目 (N)` 按钮原是「检测到未打开 .cbp 的提示入口」，打开工程后待打开列表清空即隐藏。
- **方案 A（三态常驻）**：该按钮改为常驻入口，按状态切换文本与点击行为：
  - 无工程：`Code::Blocks` → 点击打开项目对话框
  - 有待打开 .cbp：`Code::Blocks 项目 (N)` → 点击选择打开检测到的项目
  - 已打开工程：`Code::Blocks: N 项目` → 点击弹出**项目管理菜单**

## 优化：状态栏可见性统一 + 项目管理菜单

- **统一可见性**：无工程时只显示「Code::Blocks」入口；打开工程后才显示 `Target` / `Build` / `Rebuild` / `Compiler` 按钮（此前 Build/Rebuild/Compiler 在无工程时也显示，点击只会弹「请先打开项目」）。
- **项目管理菜单**（新命令 `codeblocks.projectManager`）：QuickPick 提供「打开项目… / 新建工程… / 检测工作区项目…」+ 已打开项目内联列表（活动标识 ●/○），对齐 Code::Blocks 的项目管理体验：
  - **检测工作区项目**：扫描工作区所有 `.cbp`/`.workspace`，多选打开（已打开项则设为活动工程）
  - **实时切换**：选中已打开项目立即切换活动工程，菜单保持打开（`createQuickPick` + `onDidChangeSelection`）
  - **移除项目**：每个已打开项目带 `×` 按钮，点击从侧边栏移除

## 实现要点

- 新增 `refreshStatusBars()` 统一刷新所有状态栏按钮的可见性与文本，在 activate 末尾、`openProject` 末尾、`setActiveProject`、`removeProject` 统一调用。
- `updateCbpStatusBar()` 改三态；`updateCompilerStatusBar()` 增加 `openProjects.length > 0` 判断；`buildStatusBar`/`rebuildStatusBar` 不再 activate 时无条件 `show()`。
- **统一检测源**：删除 `findCbpFiles`，合并为 `findProjectFiles()`（无参，并行扫描 `.cbp` + `.workspace` + `Set` 去重），`autoDetectAndOpenProject` 也能检测 `.workspace`。
- **菜单交互**：`showProjectManager` 用 `createQuickPick` + `action` 字段（替代 label 前缀判断）+ title 空回退 + 实时切换 + 移除按钮。
