## 第六轮对齐 Q1：库输出文件名生成策略（prefix_auto / extension_auto）

对齐 CB `SetupOutputFilenames`（compilercommandgenerator.cpp:648）+ 策略加载（projectloader.cpp:579-583）：

- `BuildTarget` 新增 `prefixAuto` / `extensionAuto`（默认 true），解析 `<Option output prefix_auto="0/1" extension_auto="0/1">`；
- `computeLibOutput` 策略化：仅策略允许时加 lib 前缀 / 追加扩展名；Windows 扩展名比较**大小写不敏感**（Linux 敏感，对齐 `IsSameAs(ext, false)` 分支）；扩展名**追加到完整文件名**（multi-dot 安全：`foo.d` → `libfoo.d.a`）；
- 动态库 import 库**强制平台默认**前缀/扩展（对齐 CB ttDynamicLib 分支，无视策略）；
- 策略贯通三处：ar 打包 `$static_output`、`resolveOutputFile` 静态库最新判定、Clean 的 import 库删除；
- `projectWriter` 写出实际策略值（原硬编码 "1"）。

效果：`.cbp` 中手写 `prefix_auto="0"`（自定义命名）或 `extension_auto="0"`（输出已带扩展名）的目标，打包/清理/增量判定文件名与 Code::Blocks 一致。
