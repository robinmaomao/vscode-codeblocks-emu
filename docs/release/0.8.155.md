> **主题**：P3 架构与健壮性批次

## 概述

本版不新增用户功能，集中处理 P3：WebView CSP 收紧、`.cbp` 未知节点透传、激活期扫描优化、`extension.ts` 首批拆分与架构文档。

## 🛡️ 健壮性

- **WebView CSP nonce**：项目属性 / 构建选项 / 快捷键 / Set Programs' Arguments / 工程搜索五个面板的内联脚本改用 `nonce`，不再使用 `script-src 'unsafe-inline'`。
- **公共运行时**：新增 `src/ui/webview/common.ts`（nonce、CSP、HTML 转义、脚本 JSON 注入）。
- **`.cbp` 未知节点透传**：Project / Target / Unit 下的插件自定义子元素与 Unit 未知 `<Option>` 属性在保存后保留，避免第三方插件数据丢失。
- **激活扫描优化**：`codeblocks.detect.autoOpen=off` 时激活/工作区变化跳过全量 `findFiles`；新增激活耗时 debug 日志。

## 🧩 可维护性

- 新增 `src/features/toolCommands.ts`、`src/features/workspaceCommands.ts`、`src/features/newProjectCommands.ts`，把 Copy Strings / Backtick Cache、Workspace 生命周期、New Build Target/File 从 `extension.ts` 拆出（三批 Feature 拆分）。
- 新增 [架构与模块地图](../dev/architecture.md)：数据流、目录职责、Feature 约定、WebView 约定、P3 后续拆分路线。
