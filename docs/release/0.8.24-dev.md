## 编译/链接对齐第三轮（K1、K18）

### K1：平台过滤（`platforms` 属性）

对齐 CB 的平台支持语义（`projectloader.cpp` / `globals.cpp` / `compilergcc.cpp`）：

- 解析项目级与目标级 `<Option platforms>`（`GetPlatformsFromString` 子串语义：含 "All" 或 Windows+Unix+Mac → spAll=0xff，否则按含 Windows/Unix/Mac 置位，默认 spAll）；
- `supportsCurrentPlatform()` 位与判定（`spWindows=0x04` / `spUnix=0x02` / `spMac=0x01`）；
- 应用点对齐 CB：
  - 目标选择列表排除不支持当前平台的目标（`UpdateProjectTargets`）；
  - 默认目标跳过不支持平台的目标（`GetFirstValidBuildTargetName`）；
  - 构建任务跳过不支持平台的目标（`compilergcc.cpp:2749`）；
  - 项目不支持当前平台 → 整个项目跳过构建并提示（`compilergcc.cpp:2724`）。

### K18：`$objects_output_dir` 分隔符

对齐 CB `GenerateCommandLine`（`target->GetObjectOutput()` + `FixPathSeparators`）：宏值使用原生分隔符（Windows 反斜杠）并受 `forceFwdSlashes` 控制，替代原先的恒正斜杠。
