# 0.8.76-dev

> 调试器能力对齐（第四十九轮 · A 组 11 项）+ 调试缺陷修复（第五十轮 · D1–D11）+ 实机调试加固（修复 1–10）。
> 0.8.47-dev – 0.8.75-dev 期间未单独出发布说明，逐轮记录见 [../开发进度.md](../开发进度.md)。

## 新增（第四十九轮：对齐 Code::Blocks 调试器窗口）

- **反汇编视图**（DAP `disassemble`，源码交织模式，窗口自适应取指令）
- **Memory 内存查看**（`readMemory/writeMemory`，变量右键「查看二进制数据」）
- **Registers 寄存器视图**（`views.debug`，默认禁用：设置 `codeblocks.debug.registers`）
- **数据断点**（变量右键「数据断点」→ GDB watch/rwatch/awatch）
- **指令级步进**（`supportsSteppingGranularity`）、**命中次数**、**日志断点**
- **运行到光标**（`gotoTargets/goto`）、**Set Next Statement**（GDB jump）、**Send GDB Command**（Debug Console `-` 前缀 MI 透传）、**附加进程**
- **调试器设置**：`initCommands` / `printPretty` / `printElements` / `disassemblyFlavor` / `charset` / `gdbPath` / `trace` / `registers`
- **异常断点过滤器**（C++ throw/catch）

## 修复（第五十轮 D1–D11 + 实机修复 1–10）

- 会话生命周期：terminate 回收、`exited/terminated` 事件、栈帧 file/line 解析、日志断点生效、停止原因映射、调试工作目录、宿主调试、帧作用域、GDB 定位与错误上报、`initialized` 时机、求值错误可见
- 实机加固（对照真实 GDB 逐项取证）：
  - `.exe` 输出路径回退；GDB 位置参数空格切分 → 改 MI 注入（`-file-exec-and-symbols`）
  - 断点位置串形式 `文件:行号`（修复非法 MI 导致断点从未插入）
  - F8 启动/继续语义；清理 DAP 协议违规事件
  - **GDB 8.1 三大崩溃规避**：寄存器读取改为显式开关、Step Out 改「返回地址临时断点」、条件断点改**客户端求值**
  - 程序输出转发（MinGW GDB 下被测程序 stdout 为无 MI 前缀的裸文本）
  - `-gdb-set mi-async on`、栈帧 `instructionPointerReference`、`hitCondition` 忽略次数修正

## 工具链覆盖（实测）

| 工具链 | 结果 |
|---|---|
| MinGW-w64 GCC（64 位）+ GDB 8.1 | 全功能 **31/31**（Pause 受平台中断限制） |
| MinGW.org GCC 6.3（32 位）+ GDB 7.6.1 | 核心 **9/9**（含 Step Out / 客户端条件求值） |
