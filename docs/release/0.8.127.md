# 0.8.127

> 发布日期：2026-10-09 ｜ 正式版（0.8.120-dev → 0.8.127-dev 里程碑汇总）

## 概述

本版是继 `0.8.11-stable`、`0.8.119` 之后的第三个正式版：把 `0.8.120-dev` 起至 `0.8.127-dev` 的全部迭代（分叉自 v0.8.119-stable）汇入 main 分支发布，并以本正式版收束。

期间的主线工作：

- **构建性能批次**（0.8.120）：M0 阶段计时探针（设置 `build.profile` / `CB_BUILD_PROFILE=1`）；R1 并行度默认值 `min(逻辑核数×2, 64)`（本机 4C/8T 全量 rebuild 实测约 70s → 40s）；R2 环境准备（2×reg.exe）改「首查同步 + 过期后台刷新」；
- **构建日志与运行前校验**（0.8.121）：无效编译器日志完整对齐 CB `PrintInvalidCompiler` 结构（扩展适配文案 + `Skipping...` 独立条目 + 尝试路径语义），Run 前同款校验（`Run aborted...`）；
- **残留问题核查实施 X1–X4**（0.8.122）：缺 `<Option compiler>` 工程/目标按 CB 加载器缺省 `"gcc"` 解析；平台不支持目标补 CB 原文警告行；调试器 launch.json schema（configurationAttributes / 初始配置 / snippets）；`asm`（.S/.s）语言配置；
- **打包瘦身 Y1**（0.8.123）：esbuild 单文件入口 `bundle/extension.js`，VSIX **199 文件/528.46KB → 74 文件/306.78KB（-63% / -42%）**；
- **同步子进程超时保护 Y2-A**（0.8.124）：反引号命令 15s→3s、编译器版本查询 8s→3s（宿主共享主线程阻塞上限收敛）；
- **A2 惰性命令生成**（0.8.125）：先判过期、仅对过期/强制单元生成编译命令（对齐 `GetTargetCompileCommands:558`，省 ~0.25–0.31s/次）；
- **R4 编译缓存**（0.8.126–0.8.127）：`build.compilerCache`（ccache / sccache，默认 none 零影响）+ 显式路径 + 自动检测 / 询问 / 引导安装；仅标准编译命令注入前缀；检测行为调整（每次打开工作区询问 + 检测结果写输出通道）；
- **工作区整理与去特定工程化**（同期）：注释 / 文档 / 测试全仓通用化，《扩展残留问题核查分析报告》入库。

规模（0.8.127 时点）：命令 **103** 项、设置 **59** 项（7 分区 + 中英 nls）、视图 5 个；回归 `tests/run-all.js` **133 文件 FAIL=0 SKIP=1**，`test-project/headless-build-check.js` 真机构建自检 EXIT 0。

## 构建性能（0.8.120）

- **M0 阶段计时探针**：新模块 `src/build/buildProfiler.ts`（纯模块）+ `buildEngine` 埋点（环境准备 / 收集（增量判定·命令生成）/ 首编译 spawn 延迟 / 编译墙钟 / 宿主输出解析 / 链接 / 脚本）；收尾输出 `[Code::Blocks][profile]` 块；设置 `codeblocks.build.profile`（默认 false，与 `CB_BUILD_PROFILE=1` 等效，修改即时生效）；`test-build-profiler`（18 断言）；
- **R1 并行度默认值**：`maxJobs()` 默认 `min(逻辑核数×2, 64)`；本机 4C/8T 实测全量 rebuild **68.6–77.2s → 38.5/40.9s（约 -45%）**，16 并发为拐点（并行效率 96–98%）；
- **R2 环境准备**：`windowsPath.ts` 改 stale-while-revalidate（首次同步 → 其后返回缓存 + 过期后台刷新，TTL 5s 保留，失败保旧值下周期重试）——构建内「环境准备」实测 ~150ms+ → **~1.0ms（热）**；
- 基准结论（RISC-V 大型工程 487 文件 / 248 编译单元）：扩展侧总开销 ≈ 1%（环境准备 + 收集 + 首 spawn + 解析），优化定向准确。

- 单项目 Rebuild 维持单遍（仅报 1 次，保护性差异）；全目标被跳过后输出 `Nothing to be done` 行；
- **Run 前校验**：`run()` 启动前同款校验（例外 CommandsOnly / `null`），无效则完整消息 + `Run aborted...` 中止；
- 测试：`test-banners-and-validity` 7→19、`test-run-invalid-compiler`（19 断言）。

## R4 编译缓存（0.8.126 → 0.8.127）

- **开关与注入**：`codeblocks.build.compilerCache`（none / ccache / sccache，默认 none **零影响**——基线命令逐字节一致）+ `compilerCachePath`（显式路径优先且唯一，无效即未找到、不静默回退 PATH）；仅 `$compiler` 展开点注入 `"<wrapper>" ` 前缀（链接 / 资源 / 库 / pre-post 脚本 / 自定义命令 / clangd 编译数据库均排除）；未找到工具 → 输出通道告警一次并回退原编译器（构建不失败；每次构建重探，运行中补齐工具下一个构建即生效；跨引擎 10s 去抖）；
- **自动检测链**：显式路径 → PATH（`.exe/.cmd/.bat`）→ 常见目录（WinGet Links / Scoop shims / `.cargo\bin` / Chocolatey / Program Files）→ **WinGet Packages 便携包兜底**（有界递归 + 包名分段匹配）——修复新式 winget 便携包不建 Links、扩展宿主 PATH 为启动快照导致「装了检测不到」；
- **提示矩阵**：未装 → 安装提示；装了未启用 → **每次打开工作区询问是否启用**（文案含版本号；含「不再提示」按钮，修改设置自动重置）；启用未找到 → 失效告警；激活 / 重检的检测结果（**版本号 + 路径**）写入 Code::Blocks 输出通道；
- **引导安装命令** `codeblocks.installCompilerCache`：winget 命令复制 / 终端执行（确认后）/ 打开官方下载页 / 重新检测（winget id 实测核对：`Ccache.Ccache` 4.14.1、`Mozilla.sccache` 0.18.0；**不做**静默安装）；
- **实证**：mock 端到端 14/14（启用后 miss → 删对象重建 **命中**（对象由缓存恢复）、缺失回退（成功 + 恰一次告警 + 无前缀）、路径恢复重生效）；真机（RISC-V 大型工程编译单元 610→161ms / 678→139ms）；响应文件与哈希正确性（`@file` 内容入哈希、改 `-DVALUE` 后对象变化且 2/2 miss）实测；
- 测试：`test-compiler-cache-detect`(37) / `test-compiler-wrapper`(18，含默认 none 逐字节零影响实证) / `test-install-guide`(23) + 设置总数 57→59。
