## 输出目录创建失败处理（方案 B）

对齐 CB 的目录创建失败语义（`GetCompileFileCommand` 的 DebugLog / `GetTargetLinkCommands` 的目录错误提示），
用日志替代阻塞弹窗：

| 场景 | 行为 |
|---|---|
| 对象目录创建失败 | `debug` 日志 + 继续编译（对齐 CB DebugLog，让编译器报真实错误） |
| 链接/打包输出目录创建失败 | `error` 日志（含目录与原因）+ **中止该目标**（返回失败统计，不再执行注定失败的链接命令） |

> 有意差异（写入对齐对照）：不照搬 CB 的模态弹窗——VS Code 模态弹窗会阻塞扩展宿主进程，
> 与异步构建/「随时停止」模型冲突；CB 弹窗后仍会执行必然失败的链接命令，中止更干净。
