## scope 与描述

- `masterPath` / `compilerPrograms` / `debug.gdbPath` → **`machine-overridable`**：不参与 Settings Sync（避免跨机同步坏路径），仍可按工作区覆盖。
- `debug.gdbPath` 描述去除「（第五十轮；…）」内部轮次标记。

## 数值校验与补全

- `parallelJobs` 0–64、`gdbTimeoutMs` ≥1000、`maxReportedErrors` ≥0、`debug.printElements` ≥0（设置页即时校验）。
- `compilerPrograms.properties` 补 `DBGconfig`（与 `CompilerPrograms` 类型对齐）。

## 新增设置（3 项）

| 设置项 | 默认 | 说明 |
|---|---|---|
| `codeblocks.editor.tidyCommentWidth` | `80` | Tidy 注释换行宽度（20–200 校验；此前硬编码 80） |
| `codeblocks.editor.headerGuardStyle` | `ifndef` | 头文件保护风格：`ifndef`（#ifndef/#define/#endif 包裹）或 `pragma-once`（仅顶部 `#pragma once`） |
