# 0.8.18-dev

> 发布日期：2026-09-25

## 遗留已知限制补齐（8 项）

对上一版本报告的已知限制逐项修复，进一步对齐 Code::Blocks 编译/链接/运行行为：

### 编译/链接域

| # | 修复项 | 说明 |
|---|--------|------|
| 1 | `pchSourceDir`（pch_mode=0） | PCH 放 `<源文件目录>/<原名>.gch/<target>_<扁平化名字>`（对齐 `pfDetails::Update` 目录形式） |
| 2 | `extended_obj_names` | 解析 `<Option extended_obj_names="1">`；对象命名保留原扩展名（`foo.c` → `foo.c.o`） |
| 3 | 源文件缺失跳过编译 | 源文件被删除时不再报错中断，跳过编译（对齐 `IsObjectOutdated`） |
| 4 | deps 文件命名 | 对齐 `GetDepsOutput`：`.deps` 目录 + `<name>.depend`；解析 `<Option deps_output>` |
| 5 | include 依赖扫描改进 | 剥离块/行注释与字符串后再匹配 `#include`（`#include` 行保留引号），避免注释内 include 误判、字符串内 `#`/`//` 误认 |
| 6 | `skipIncludeDeps` 设置 | 新增设置 `codeblocks.build.skipIncludeDeps`，可跳过 include 依赖扫描（供非 C/C++ 编译器） |
| 7 | 并行任务数上限 | 默认并行数去掉 8 上限，取 CPU 核数（对齐 Code::Blocks processCount 默认值） |

### 运行/调试域

| # | 修复项 | 说明 |
|---|--------|------|
| 8 | Run/Debug 环境与参数 | 解析 `<Option parameters>`；Run 终端应用项目级+目标级 `<Environment>` 变量并展开执行参数宏（`$(TARGET_OUTPUT_FILE)` 等）；Debug 的 DAP launch 传递 `args`（GDB `--args`）与 `environment`（GDB 子进程 env） |

### 测试与打包

- 新增 `test-strip-comments.js`（8 断言：注释/字符串/转义引号/缩进场景）
- 修复打包产物误含 `.git-msg.txt`，已加入 `.vscodeignore`
- 全量回归 30 pass
