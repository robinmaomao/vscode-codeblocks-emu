# 0.8.97-dev

> `docs/archive/功能与代码问题核查分析报告.md`（已归档）的修复批次：**P1 全部 + P2（除 CI/Lint 门禁）+ P3（除巨型模块拆分）**。
> 对应审计项编号见报告 §1–§3。

## P1 高优先级

### 1.1 VSIX 不再误打包 `release/` 旧产物
- `.vscodeignore` 增加 `release/**` 与 `*.zip`：此前 `release/codeblocks-vscode-0.8.92-dev.zip`（464 KB，约占 VSIX 体积一半）被装入发布包。
- 打包压缩（esbuild）**评估结论**：需要改动构建流程与 `node_modules` 保留策略（fast-xml-parser 为运行时依赖），收益为 108 个 JS → 个位数，属独立批次，本轮先做零风险排除。

### 1.2 测试汇总器不再"永久 FAIL=1"
- `tests/run-all.js` 增加 `KNOWN_MANUAL = ['test-writer.js']` 跳过清单（该脚本需 `<cbp>` 参数，是手工工具）——输出改为 `TOTAL=n FAIL=0 SKIP=1 [test-writer.js]`，真实失败不再被"预期失败"备注掩盖。
- `package.json` 新增 `"test": "node tests/run-all.js"`（配合既有 `pretest` 先编译），`npm test` 可直接跑全量回归。

### 1.3 四个日志/行为设置即时生效
- `src/build/logLang.ts` 导出 `resetBuildLogPrefsCache()`；`extension.ts` 配置监听新增 `build.plainCbLog` / `log.english` / `build.strictQuoting` / `ui.quietSuccess` 四键 → 清缓存。
- 行为变化：以上设置在会话内修改**即刻生效**（此前需重载窗口）。

## P2 中优先级

### 2.1 makefile 项目 `askRebuildNeeded` 异步化
- 原 `spawnSync`（无超时）改为 `runMakeAskRebuild()`：异步 spawn + **30s 超时** + 注册到构建取消句柄；超时/启动失败/取消按"需构建"继续（与 CB 语义一致，退出码 0 仍跳过构建）。

### 2.2 编译器版本号模块级缓存
- 新模块 `src/compiler/compilerVersion.ts`：`queryCompilerVersionString()` 结果按 `exe 路径 + mtime` 缓存（负结果同样缓存，编译器升级/重装后自动失效）；`clearCompilerVersionCache()` 供强制刷新。
- 消除构建期 `getCompiler()` 多次调用导致的重复同步 `gcc --version`（每次 30–100ms，异常环境最长 8s）。

### 2.3 快捷键面板安全加固
- `keybindingPanel` 补 `<meta http-equiv="Content-Security-Policy">`（与另两个面板一致）；移除 `retainContextWhenHidden`（面板状态经 `ready`/`refresh` 重新推送，无需常驻 DOM）。

### 2.4 AStyle 异步化
- `formatWithAstyle()` 由 `spawnSync` 改为异步 `spawn`（stdin 写入 + stdout 收集），语义不变：失败/无输出返回 null → 回退 VS Code 内置格式化；大文件不再阻塞窗口。

## P3 改善项

- **3.1 缓存限界**：`shortPathCache`（512）、`backticksCache`（256）、clangd include/target 缓存（128/64）换用 `LruCache`（`lru.ts` 增加 `has()`）；`backticksCache` 构建入口清理语义不变。
- **3.3 WebView 测试加固**：新增 `tests/test-webview-panels.js`——三个面板模板全量提取（支持插值/嵌套模板的扫描器）+ CSP/转义函数断言 + `<script>` 语法检查（`new Function` 只编译不执行）。
- **3.4 headless 脚本自动还原**：`test-project/headless-build-check.js` 跑完自动 `gcc -g -O0` 还原 `hello.exe`（此前每次需手工重编，调试 e2e 易踩坑）。
- **3.5 约定固化**：新增 `tests/test-code-conventions.js`——禁止无注释的裸 `catch {}`、`console.*`、`@ts-ignore`（含检测器自检）。
