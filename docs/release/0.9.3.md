# 0.9.3

> 发布日期：2026-11-20 ｜ 功能版（0.9.2 → 0.9.3）
> **主题**：Agent 控制面上手体验与安全护栏（Agent Skill / `@codeblocks` / 确认文案 / 脚本总闸）

## 概述

0.9.0 合入 Agent 控制面后，11 个工具、MCP provider 与 `cb-cli` 的能力已经完整，但缺少“从安装到第一条指令”的闭环，
模型也容易跳过 `project_read` / `dryRun` 直接改 `.cbp`。本版补齐文档与工作流，并增加可选的 Agent Skill、确定性
`@codeblocks` 命令、写入/执行前确认，以及默认关闭的全局脚本开关。

## ✨ 新增

- **Agent Skill**：随包提供 `skills/codeblocks-project/SKILL.md`，通过 `contributes.chatSkills` 注册；内容覆盖先读、schema、dryRun、构建失败循环、错误码恢复与脚本安全。新增 **Code::Blocks: Install Agent Skill…**，可安装到工作区 `.github/skills/` 或用户 `~/.copilot/skills/`，已存在时确认覆盖。
- **`@codeblocks` Chat participant**：`/read`、`/build`、`/fix`、`/debug`、`/status`、`/help` 确定性命令，调用与 LM Tools 相同的 `invokeTool` 策略；不替代 Agent 模式的自主编辑。
- **Agent Status**：**Code::Blocks: Agent Status** 显示工作区信任、总闸、只读、脚本策略、已注册工具数、CLI/MCP/Skill 路径，并可复制到剪贴板。
- **确认文案**：LM Tools 在写工程、运行、调试变更、导出、打开/关闭工程前显示 `confirmationMessages`；只读与 `dryRun` 调用不打扰。
- **文档**：Agent 控制指南补 5 分钟上手、权限矩阵、CLI/MCP 路径、安全配置档、排障与 Skill；新增 `agent-recipes.md` / `.en.md`。

## 🔒 行为变化

- 新增 `codeblocks.agent.allowScripts`（默认 `false`）：LM Tools / MCP 修改 `commandsBeforeBuild`、`commandsAfterBuild`、`buildScripts`、`makeCommands`、`customBuildCommands` 时，除单次 `allowScripts: true` 外还必须开启该设置；否则返回 `invalid-input`。独立的 `cb-cli` 不受影响。
- MCP `readOnlyHint` 明确为**工具级**：只有 `project_read` / `build_status` 为 `true`；`compiler` / `workspace` / `debug` 的部分 action 虽只读，但工具级保守标 `false`。
- 新增命令 2（Agent Status / Install Agent Skill）、设置 1、chat participant 1、chat skill 1；工具仍为 11 个。
