## 新增：generatedFiles 自动生成文件机制（A4）

对齐 Code::Blocks `cbProject::AddFile` 的 GenFilesHackMap 机制（`cbproject.cpp:815-978`）：

- **关系来源**：生成关系不写在 `.cbp`，由编译器 XML 的 `gen="file1;file2"` 属性声明（对应 CompileObject/CompileResource 工具，按扩展名匹配）。
- **加载建立**：打开项目时按声明自动建立「生成器 → 生成文件」关系，生成文件加入项目与目标（继承目标归属与默认 compile/link）。
- **宏展开**：生成名支持 `$file_name` / `$file_basename` / `$file_dir` / `$file_ext` / `$file`。
- **构建顺序**：生成器文件先编译，生成文件延后到常规编译完成后（生成器先产出源文件）。
- **对象命名**：生成器文件的对象 = 第一个生成文件的对象（对齐 `pfDetails::Update`）。
- **clean**：自动生成文件在 clean 时额外删除本体（对齐 `GetTargetCleanCommands`）。
- **保存**：`.cbp` 序列化时跳过自动生成文件（对齐 `projectloader.cpp:1794`）。

> GCC 默认工具链无 `gen` 声明，该机制仅在编译器 XML 声明了 `gen` 属性时激活（如 Qt uic/moc 场景）。
