# 0.8.16-dev

> 发布日期：2026-09-24

## 新增：DAP 调试器三项能力

补齐调试器的条件断点、函数断点、修改变量值能力：

- **条件断点**：断点上右键可加条件表达式（`-break-insert -c "condition"`）
- **函数断点**：断点面板可直接按函数名设置断点（`-break-insert <函数名>`，支持条件）
- **修改变量值**：调试暂停时双击变量值可修改（`-var-create` + `-var-assign`，支持顶层变量与一层结构体成员）

### 关键修复：GDB MI 参数序列化 bug

修复了 `GdbMiSession` 的 MI 命令参数序列化错误（原 ` key="value"` 缺 `-` 前缀，对 `-break-insert` / `-stack-list-variables` / `-data-evaluate-expression` 都是错误语法）。**此前断点设置、变量查看、表达式求值可能一直失败**，本次一并修复（新增 `sendMi` 正确序列化选项参数与位置参数；`-break-delete` 修复为按编号删除）。

## 变更：Squirrel 构建脚本明确警告

`<Script file="*.script"/>`（Squirrel 构建脚本）此前被静默忽略，现改为构建时输出明确警告「暂不支持 Squirrel 构建脚本，已跳过」。

## 文档：明确「不支持的功能」

README 与使用说明新增「已知限制」章节，明确列出暂未移植的功能：

| 功能 | 状态 |
|------|------|
| Squirrel 构建脚本 | ❌ 警告跳过 |
| makefile 项目模式 | ❌ 未实现（MakeCommands 仅透传） |
| DAP 深层成员赋值 | ⚠️ 支持顶层/一层成员 |
| 其他工程模板（sdl/qt 等） | ❌ 未移植 |
