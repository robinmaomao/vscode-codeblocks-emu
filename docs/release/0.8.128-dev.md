# 0.8.128-dev

> 汇编注释标记可配置：默认 `//`（预处理的 `.S` 安全）；
> 新设置 `codeblocks.editor.asmHashComment` 开启后动态还原 GAS 原生 `#`（即时生效）。

## 变更

- **默认值**：`language-configurations/asm.json` 行注释标记 `#` → `//`（块注释保持 C 风格）。
- **新设置** `codeblocks.editor.asmHashComment`（boolean，默认 `false`）：
  开启后经 `vscode.languages.setLanguageConfiguration('asm', …)` **动态注册**行注释 `#`
  （VS Code 中扩展动态注册优先级 100 > 静态文件配置 50；仅覆盖 `comments`，括号/自动闭合等仍沿用静态配置）；
  关闭即释放 Disposable 自动回退静态 `//`；**修改即时生效**（无需重载窗口，`Ctrl+/`、`Ctrl+K Ctrl+C/U`、命令面板等全部注释路径一致）。
- 新纯模块 `src/tools/asmCommentConfig.ts`（`ASM_LANGUAGE_ID` / `ASM_HASH_COMMENT_SETTING` / `asmCommentsRule()`）；
  `src/extension.ts` 接线：激活时应用 + `onDidChangeConfiguration` 监听 + `context.subscriptions` 释放。
- **实测依据**（本机工具链）：原生 `.s` 经 GAS 直接汇编时 `//` 在 RISC-V（binutils 2.28 / 2.43）整行报 junk、行尾报 illegal operands，x86 行尾报 invalid char；`.S` 经 cpp 预处理则 `//` / `#` 均安全——故默认 `//` + 可切回 `#` 并存。
