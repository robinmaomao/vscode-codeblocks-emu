# 0.8.157

> 发布日期：2026-11-19 ｜ 体验版（0.8.156 → 0.8.157）
> **主题**：AutoVersioning/Profiler 正确性 · 编译器元数据与全量资源

## 概述

本版不新增命令/设置，集中修复 0.8.156 落地功能的正确性与性能问题，并补齐 Code::Blocks 编译器 XML 资源与显示名元数据。

## 🔢 AutoVersioning 正确性

- **不再无条件重写 `version.h`**：内容完全相同时跳过写入，避免 mtime 抖动导致包含该头文件的源文件反复编译。
- **构建计数去重**：`prepare` 返回构建会话 token，`complete` 只对同一会话生效；失败/取消不递增，虚拟目标/工作区构建不会重复计数。
- **真正支持 `do_auto_increment` / `ask_to_increment`**：构建前检测工程脏文档；开启时递增版本，`ask_to_increment` 弹确认。
- **Bump / Generate / 构建后统一 commit 流程**：三者都按 `update_manifest` 更新 `manifest.xml`。
- **SVN 字段**：`svn=true` 时通过 `svn info` 读取 revision/date，失败只警告并生成空字段。
- **Changes Log**：AutoVersioning… 增加打开/创建 `ChangesLog.txt` 的文本入口。
- **version.h 加入工程**：配置时/命令中可将头文件作为非编译 Unit 加入所有目标。

## 📊 Profiler 运行时

- **拒绝旧 `gmon.out`**：运行前记录候选文件 mtime/size，只接受本次运行新生成或更新的文件。
- **`gprof -A` 回退**：stdout 为空时尝试 `--separate-files`，收集生成的 `*.annotated` 文件；仍为空则给出 `-g`/源码路径提示。
- **报告原子写**：CSV/HTML 导出改用 `writeFileAtomicSync`，失败不会留下半截文件。

## 🧰 编译器资源与元数据

- 新增 `src/compiler/compilerMetadata.ts`：读取 `compiler_<id>.xml` 的显示名、weight/platform 与 master search/fallback 路径（展开 `%ProgramFiles%` 等环境变量，不执行 registry/外部命令）。
- `CompilerOptionsLoader` 使用真实显示名；Build options / Select Compiler 不再只显示 ID。
- 补齐 Code::Blocks `resources/compilers` 的 options 与 metadata 资源（OpenWatcom、Cygwin、MinGW/MSYS2/TDM、D/Fortran、IAR/Keil、LCC、MW、MSVC TK、嵌入式交叉工具链等）。
- 修正 `extends` 继承解析：父级 `gcc` 正确加载 `options_gcc.xml`，所有 variants 的命令模板可加载。
- 新增保守探测：OpenWatcom、Cygwin、MSYS2 MinGW64、TDM64、LCC、DMD、GDC、gfortran；Cygwin/MSYS2/TDM 不按 PATH 泛匹配，避免误判。

## ⚠️ 行为变化与升级提示

- AutoVersioning 开启 `do_auto_increment` 时，构建前可能弹出版本递增确认；关闭该选项即保持原来的显式递增行为。
- `version.h` 内容不变时不再更新 mtime；依赖“每次构建都刷新日期常量”的脚本需显式执行 Generate Version Header。
- 编译器资源全量接入不代表所有专有工具链可自动探测；未安装时仍可在 Select Compiler 中手工选择。
- 新增 XML 仍派生自 Code::Blocks GPL v3 资源，许可证声明不变。
