# 0.8.82-dev

> 第三轮功能盘点·批次2：调试器工程级配置对齐（R3 源目录 / R4 远程调试 / R5 设置补齐）——嵌入式调试关键项。

## R3 调试源目录（search_path）

- 解析 `<Project><Extensions><debugger><search_path add="..."/>`（对齐 `ParseSearchDirs`）；
- launch 与 attach 会话建立后向 GDB 发 `directory` 命令：工程根 + 公共顶层目录 + 配置目录
  （反斜杠转正斜杠、含空格加引号，对齐 `AddSourceDir`/`ConvertToGDBDirectory`；`$(VAR)` 宏展开）；
- 新设置 `codeblocks.debug.addOtherProjectDirs`（默认 **false**，对齐 CB）：开启后追加其它已打开工程的目录。

## R4 项目级远程调试（TCP / UDP / 串口）

- 解析/写回 `<debugger><remote_debugging target="..."><options .../></remote_debugging>`：
  `conn_type / serial_port / serial_baud / ip_address / ip_port / additional_cmds / additional_cmds_before /
  skip_ld_path / extended_remote / additional_shell_cmds_after / additional_shell_cmds_before`；
- 合并语义对齐 `remotedebugging.h MergeWith`：目标覆盖项目级（连接字段仅在目标有效时覆盖）、
  附加命令按行追加、布尔项以目标为准；全默认条目不写出（对齐 `SetRemoteDebuggingMap`）；
- 准备命令序列完全对齐 `gdb_driver.cpp:141-260`：
  连接前命令 → 连接前 shell →（串口）`set remotebaud` → `target [extended-]remote tcp:|udp:|<串口>`
  → 连接后命令 → 连接后 shell；命令均经宏展开；
- 有效连接（串口需端口+波特率；TCP/UDP 需 IP+端口）时 `configurationDone` 用 `-exec-continue` 而非 `-exec-run`
  （对齐远程 Start 语义；目标已运行，适合 OpenOCD / 串口目标）；
- **工程属性面板新增「调试器」tab**：源搜索目录 + 作用域下拉（项目级默认 / 每目标）的远程表单
  （连接类型、串口、波特率、IP、端口、extended-remote、跳过 PATH/LD_LIBRARY_PATH、连接前后命令与 shell 命令）。

## R5 调试器设置补齐

- 新设置 `codeblocks.debug.userArguments`：附加到 GDB 命令行的参数（引号感知分词，对齐 CB user arguments）；
- `codeblocks.debug.disassemblyFlavor` 新增 `custom` + 新设置 `codeblocks.debug.instructionSet`
  （对齐 CB：custom 时作为 `set disassembly-flavor` 的值）；
- 每次会话自动下发 CB 的固定初始化命令（`set confirm off` / `width 0` / `height 0` / `breakpoint pending on` /
  `print asm-demangle on` / `unwindonsignal on` / `filename-display absolute` / `style enabled off`），
  老 GDB 不支持的项单项失败并忽略；
- 说明：CB 的 `catch_exceptions`（默认 true）与扩展异常断点过滤器语义重叠，保持「默认不发、由过滤器具名开启」。
