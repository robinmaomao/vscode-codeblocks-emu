## Z1/Z2 编译器级选项与目录（实质缺陷，真实 default.conf 取证）

- CB 在关系合并后追加编译器级选项：`SetupCompilerOptions:1017`（/compiler_options）、
  `SetupLinkerOptions:1046`（/linker_options）、`SetupResourceCompilerOptions:1161`（/resource_compiler_options）；
- 链接库键名是 **`/libraries`**（compiler.cpp:466/648），旧版 user_sets 节点全部为大写键；
- 实现：`CodeBlocksConfig.searchDirs` 大小写双兼容 + libraries/link_libs 双键，返回新增
  compilerOptions/linkerOptions/resourceCompilerOptions；`Compiler` 模型加三字段；
  extension/headless 的 applyGlobalDirs 同步；三处 `setup*Options` 追加后整体
  ReplaceMacros → `cbExpandBackticks`。

## Z3 空程序四宏校验

- 对齐 `GenerateCommandLine:332-341`：`$compiler`/`$linker`/`$lib_linker`/`$rescomp`
  任一宏被模板使用且对应程序为空 → 命令清空（此前只查前两个）。

## Z4/Z5 单文件与路径宏字节对齐

- 单文件编译 `$exe_output`：`SetExt(EXECUTABLE_EXT)` → 原生分隔符 → Quote → FixPathSeparators
  （此前强制正斜杠）；无 target 分支同样推导 `$exe_name/$exe_dir/$exe_ext`；
- `$file_dir`/`$exe_dir`：无目录归一为空串（对齐 wxFileName::GetPath()，此前为 `"."`）。

## Z6/Z7 静态库对象前缀 + OpenWatcom

- prependHack：LinkStaticCmd 模板含 `$([-+]+)link_objects` 时逐对象加 `-`/`+` 前缀
  （对齐 GetTargetLinkCommands:724-742，bcc/dmc 等）；

  （对齐 GetTargetLinkCommands:697/752-753/785-788/795-804/835-838）。

  SearchDirsFromBackticks 仅用于「缺失 include 提示」特性，不移植）。
