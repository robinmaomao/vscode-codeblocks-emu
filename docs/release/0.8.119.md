# 0.8.119

> 发布日期：2026-09-30 ｜ 正式版（0.8.12-dev → 0.8.119-dev 里程碑汇总）

## 概述

本版是继 `0.8.11-stable` 之后的第二个正式版：把 `0.8.12-dev` 起至 `0.8.119-dev` 的全部迭代（分叉自 v0.8.11-stable）汇入 main 分支发布，并以本正式版收束。

期间的主线工作：

- **构建引擎全面对齐 Code::Blocks**：编译/链接逐轮逐行对齐（第四轮专项 L1–L19 全部处理完毕），包括 PCH 预编译头、失败即停、编译条目计数强制重链、跨卷/UNC 对象路径、响应文件、AVR/MSP430/SDCC 编译器支持等；
- **调试器能力对齐与实机加固**：反汇编 / Memory / Registers / 数据断点 / 指令级步进 / 命中次数 / 日志断点 / Run to Cursor / Set Next Statement / 附加进程 / 指令断点 / 多会话路由，以及针对 MinGW GDB 7.6–8.1 的多项实机兼容修复；
- **工程管理与菜单/快捷键/设置体系**：第三轮/第五轮盘点的工程树与调试缺口（P1–P4 / M1–M3 / D1–D2）全部实施；菜单全项对齐（9 顶级菜单 92 项）、快捷键补全与可视化配置面板、设置 7 分区与 nls 化；
- **UI 与输出体验**：Build Log 底部面板、状态栏菜单、结构化输出（时间戳 / ⚠️ / ❌ / 汇总块）、构建结束聚焦门控、书签与错误导航、Run 终端复用；
- **性能专项**：编译器探测异步化（约 6×）、解析/deps/LRU 缓存体系、热路径优化 P1–P8（0.8.114）；
- **质量体系**：回归测试 52 → 122 个文件（FAIL=0），两轮代码审计与多轮复核修复。

规模（0.8.119 时点）：命令 **102** 项、设置 **56** 项（7 分区 + 中英 nls）、视图 5 个；回归 `tests/run-all.js` **122 文件 FAIL=0 SKIP=1**，`test-project/headless-build-check.js` 真机构建自检 EXIT 0。

### 第四轮编译链接专项（0.8.86 → 0.8.89，L1–L19）

- **L1** PCH 头 include 前置（`-iquote` / `-I` / `-I.`，GCC 版本分支）；
- **L2** 编译失败「**失败即停**」（对齐 `OnJobEnd` 清队列：首错后不再派发新单元）；

- **L8** C++ 链接判定按 `compilerVar`；**L11** 跨卷对象路径（`objOut + 卷字母 + 去卷路径`，并修复跨卷增量恒过期的拼接缺陷）；**L18** Clean 对无效 `masterPath` 目标仍删对象；

- 命令快照 golden 测试（hello-cb 6 命令逐字节）。
