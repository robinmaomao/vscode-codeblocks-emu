# 0.8.151

> 发布日期：2026-11-12 ｜ 体验版（0.8.150 → 0.8.151）
> **主题**：工程属性 / 构建选项 UI 二次精修（严格对齐 Code::Blocks `project_options.xrc`）+ 工程右键菜单排序

## 概述

0.8.150 把 `Build options…` / `Properties…` 搬进了 VS Code，但 `Properties` 仍是"卡片皮肤"：结构与 CB 对话框并不一致。本版对照 CB 源码 `src/src/resources/project_options.xrc`（`dlgProjectOptions`）逐行重排，并把**按钮与交互控件统一到 Build options 的 `.bo-*` 体系**，同时补齐工程右键的保存/关闭/移除文件/展开折叠能力。

## 一、Project settings 页（按 XRC 重排）

| 区域 | Code::Blocks 结构 | 本版实现 |
| --- | --- | --- |
| 页面骨架 | 单张 2 列 `wxFlexGridSizer`（vgap/hgap = 4，仅第 2 列 growable，四周 4px），**无分组框** | 单张 `.form-grid`，标签列 120–170px，行距 4px；移除原「项目设置 / 预编译头 / 构建」三张卡片 |

## 二、Build targets / Build scripts / Notes / Parser / Debugger

- **Build targets**：左 `Build targets` 静态框（列表 + 竖排 Add/Rename/Copy/Delete/↑↓ + 两个弹簧分组 + `从目标创建工程…`）；右栏 `Selected build target options` **+ 下方 `Build target files:`**（此前文件列表跨两栏，现按 CB 回到右栏）；标签补全角冒号、复选框组后加 `wxStaticLine` 等价分隔线、输出文件名提示改 `title`。
- **Build scripts**：左右 **1:2** 分栏；`工程概览：` 树 + 居中的 `校验所有已附加脚本` 在左栏；`已附加的构建脚本：` + 列表右侧 ↑/↓ spin + 居中 `添加 / 删除` 在右栏。
- **Notes / C/C++ parser**：去掉卡片，`项目备注：` / `附加搜索路径：` + 撑满内容 + 底部操作行。
- **Debugger**：搜索目录列表 + 竖排按钮；远程调试左目标列表（`<Project>` + 各目标）+ 右 3 个子标签，子标签改用 Build options 同款 `.bo-subtabs/.bo-subtab`。

## 三、按钮与控件统一采用 Build options 体系

| 位置 | 复用（`buildOptionsView.ts`） |
| --- | --- |
| 页签 | `.bo-tabs` + `.bo-tab`（**去掉图标**，纯文字） |
| 页脚 | `.bo-footer` + `.bo-toolbar` + `.bo-status`；`保存` 用 `class="default"`（focus 描边） |
| 列表操作 | `.bo-actions`（widget 描边 + secondary 背景 + `data-act="add"` 高亮） |
| ↑/↓ | `.bo-move-buttons` + 与 Build options 相同的 SVG 箭头（不再用文本箭头） |
| 危险操作 | `class="danger"`（透明 + errorForeground） |
| 模态 | `.bo-modal / .bo-modal-box / .bo-modal-title / .bo-modal-body / .bo-modal-actions / .bo-modal-x`（取消在左、`default` 确认在右） |
| 浏览 `...` | `.cb-browse`，皮肤继承 `.bo-actions button`，固定 24×24 |
| 子标签 | `.bo-subtabs / .bo-subtab` |

- 度量：输入/下拉 24px、字号 12px、行距 4px、静态框方角压边标题；内容不再 `max-width` 居中（CB 填满对话框）。
- `#bo-overlay` 移出 `.bo-root`，避免内嵌 Build options 视图继承 24px 紧凑度量（实测仍为 29px 输入高度）。
- 窄面板（≤760px）：两栏网格与标签列自动改为上下堆叠，无横向溢出。

## 四、还原设置与 Build options 细节

- **还原设置**（`Restore settings`，Build options 与 Properties 均有）：打开时对宿主数据做基线快照；保存成功后刷新基线；点击后弹出面板内确认框（`.bo-modal`，不使用 WebView 沙箱禁用的 `window.confirm`）「放弃未保存的修改，恢复为已保存的设置？」，回滚所有草稿并重绘当前页签，状态区提示「已还原为保存的设置」。
- Debugger 搜索目录「添加/编辑」同样改用面板内 `askText` 输入模态（原 `window.prompt` 在 WebView 中静默失效）。
- 底部按钮补描边；Linker settings 全控件包入 CB 静态框；`Linker executable` 在工程级只读展示，并说明「仅构建目标使用；Code::Blocks 按目标保存该值（`<LinkerExe>`）」。

## 五、工程右键菜单与 Expand All

- 工程节点右键分组按 CB `projectmanager.cpp` 顺序：`00_save` / `01_files` / `02_find` / `03_tree` / `04_build` / `05_options` / `06_extra`。
- 新增命令：`Save Project`、`Close Project`、`Remove Files…`、`Project Tree ▸ (Expand All / Collapse All)`；保留扩展已有项（Build/Rebuild/Clean、Run/Debug 等）。
- **Expand All 修复**：VS Code 只对新元素采用 `collapsibleState`；改为清空 `nodeCache`/`dirIndexCache`/`parentMap`/`missingCache` 重建节点，并对工程节点 `reveal({ expand: true })` 兜底。该请求为一次性：`setProjects`/`setCategorize` 会复位标记，工程重载或切换分组后按默认折叠状态渲染。

## 七、兼容与边界

- 不改数据模型与保存协议：所有历史元素 `id`/`name` 保留，`collect*Form` 逻辑未变。
- 保留扩展独有能力：顶部 `目标：` 选择器、目标 ↑/↓、`高级（扩展）` 分组、`...` 浏览按钮；CB 原对话框没有这些。
- 红色说明文字使用主题 `--vscode-errorForeground`（CB 固定 `#800000` 在深色主题不可读），位置/行数/宽度按 CB。
- 视觉基线随本版 UI 重构重新生成；命令总数 113 → **118**（新增 5 个），视图与设置项总数不变。

### 8.1 启用联动（对齐 `projectoptionsdlg.cpp` / `compileroptionsdlg.cpp`）

- **Properties**：`执行目录` 仅「使用自定义 Makefile」可编辑；`导入库文件名` / `定义文件文件名` 需「对应复选框已勾选 **且** 目标为动态库」；`创建导入库` / `创建 .DEF 导出文件` 仅动态库可勾选；静态库清空导入库/定义文件名，非控制台程序禁用「执行结束后暂停」，仅命令目标清空并禁用输出/导入库/定义文件/工作目录/对象目录。
- **Build options**：自定义 Makefile 工程隐藏 Compiler / Linker / Search 三页并默认停在 Pre/post；**Commands only** 目标四页灰显、自动切到 Pre/post；Link libraries 与 Search directories 支持 **Ctrl/Shift 多选**（Edit 需恰好 1 项、Copy 只复制选中项、↑/↓ 按选中集合边界判断）。
- 无目标 / 无选中文件 / 编译器不支持 PCH 时对应控件禁用；工程声明的编译器未安装时选项页整体禁用并红字提示。

### 8.2 Build options 严格对齐（删除 CB 没有的 UI）

| 移除项 | 原因 |
| --- | --- |
| `Extensions` 页 | CB `compiler_options.xrc` 无此页；扩展字段不再塞进 CB 对话框 |
| Project custom variables 文本域 | 同上（`<Extensions>` 项目自定义变量只保留数据，无图形入口） |
| `Dist-clean project/target` | XRC 中 `<hidden>1</hidden>`；保存时按 `<build> > $(CMD_NULL)` 派生 |
| `Silent build:` | 同上（始终派生，无需输入） |

- **Make 命令页**只保留 CB 可见的四行：Build / Compile / Clean / Ask。
- `externalDeps` / `additionalOutput` 只在「依赖…」对话框编辑；`depsOutput`、`project.customVariables` 仅保留数据。

### 8.3 Set Programs' Arguments…（新增，对齐 CB `SelectTargetDlg`）

- 新面板 [runTargetsPanel.ts](../../src/ui/runTargetsPanel.ts)：目标列表 → `此目标提供工程的主可执行文件` → `程序参数：` → `宿主程序：` + 浏览 → `在终端中运行宿主程序` → 确定/取消；切换目标先暂存，双击等同确定。
- 写回 `executionParameters` / `hostApplication` / `runHostApplicationInTerminal` / `default_target`（仅非空且不等于第一个目标时落盘）。
- 菜单项移到 `Notes…` 之前；库 / 仅命令目标未勾选终端时直接 `spawn` 宿主程序、不建终端；`runHostApplicationInTerminal` 默认改为 **false**（对齐 CB）。

### 8.4 Selected file properties…（新增，对齐 CB `ProjectFileOptionsDlg`）

- 标题 `Properties of "<相对路径>"`，三页 General / Build / Advanced，底部 `确定 | 取消`（取消丢弃修改，确定才写回）。
- **General**：只读工程名 + `.cbp` 路径、工程根目录、绝对/相对路径、行数统计（`CountLines`/`AnalyseLine` 语义：`//` 与 `/* */`、代码+注释混合行计入实际代码行、未知语言不计行数）、文件大小、`DD/MM/YYYY HH:MM:SS` 时间戳、`文件为只读`（确定时 `chmod`）、自动生成文件加粗提示。
- **Build**：编译/链接、`归属构建目标：`（150 px 列表）、`优先级权重：` 滑块（0-100 步进 10）+ 红字提示。
- **Advanced**：`编译变量：` 自由文本（保存时若勾选编译且为空补 `CPP`）、`对象文件：` 只读（`SetObjName` 规则）、`自定义构建` 组按**编译器**分别保存 `useCustomBuildCommand` / `buildCommand`、`默认：` 显示该编译器的 `ctCompileObjectCmd` / `ctCompileResourceCmd`；空命令不写盘。自动生成文件的 Build / Advanced 整页禁用。
- 新增 [src/model/fileStats.ts](../../src/model/fileStats.ts)（统计 + 对象名）、`tests/test-file-properties.js`（36 断言）与视觉面 `props-file-general/build/advanced`。
