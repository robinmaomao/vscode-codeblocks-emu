# 0.8.153

> 发布日期：2026-11-18 ｜ 体验版（0.8.152 → 0.8.153）
> **主题**：状态栏 Menu 显示优化 + 168 项逐项对齐 Code::Blocks

## 概述

状态栏最左侧的 `Menu` 是 Code::Blocks 菜单栏的移植入口。本轮先做全量逐项排查（9 个顶级菜单、168 个菜单项），再按 CB 源码修正显示与结构：

- 对照 `main_menu.xrc`、`compiler_menu.xrc`、`debugger_menu.xrc`、`projectmanagerui.cpp::CreateMenu`、`compilergcc.cpp::BuildMenu`、`todolist.cpp::BuildMenu`、`codecompletion.cpp::BuildMenu`、`toolsmanager.cpp::BuildToolsMenu`。
- 修复 **70 项无图标 / 1 个非法 codicon / 11 条中英混排标签 / 1 条译文重名**。
- 调整 **8 组菜单归属与顺序**，补齐已有命令的缺失入口（不新增功能路径）。
- 新增菜单展示模型与 VS Code 1.85 codicon 白名单回归，避免最低支持版本出现空图标。

## 🎨 显示与交互

- **图标 100% 覆盖**：除分隔线外每项都有语义 codicon；`Undo` 的非法 `undo` 改为 `discard`；测试使用 `tests/fixtures/codicons.json`（取自 VS Code 1.85）校验全部图标 id。
- **子菜单标记**：label 末尾统一追加 `$(chevron-right)`，不再在 description 写“子菜单 ›”。
- **description 统一**：固定为 `快捷键 · 不可用原因`，不再混入“子菜单”等结构文案。
- **一级收敛**：固定 9 个顶级菜单；Recent Files / Recent Projects / Workspace Build Order 移入 File。
- **面包屑与返回**：每个子层级第一项为“返回”，QuickPick 标题显示 `Code::Blocks › File › …`。
- **动态列表**：最近工程 / 构建顺序补图标、相对路径与活动工程 ✓；清空入口、自定义工具、返回项均有图标。
- **可过滤**：`matchOnDescription` / `matchOnDetail` 开启，可按快捷键搜索菜单项。

## 🧭 结构与 Code::Blocks 对齐

- **File**：新增 `New ▸`（Empty File / Project… / From Template…）、`Recent Files ▸`、`Recent Projects ▸`、`Workspace Build Order ▸`、Save Project、Close Project、Project Properties；按 CB 重排 Save / Close。
- **Edit**：按 CB 顺序重排；补 Uncomment、Select Skip to Next Occurrence、Fold / Unfold Current Block、Transpose；Find Next/Previous Selected 与 Goto changed line 移入 Search。
- **View**：TODO List 从 Search 移入（对齐 CB TODO 插件位置）。
- **Search**：Find Next/Previous、Find Next/Previous Selected、Replace、Goto Line/Changed Line/File 按 CB 排序；Project Search 收拢为子菜单；Open Include File 保留。
- **Project**：补 Remove Files…；Project Tree 子菜单按 CB 调整；Set Programs' Arguments → Notes → Build Options → Properties 顺序对齐 compiler 插件插入位置。
- **Build**：Export Makefile… 从 Tools 移入 Build（backlog M1 完成），位于 Select Target 之后。
- **Debug**：新增 Debugging Windows ▸（Breakpoints / Call Stack / Variables / Watch / Registers / Disassembly）；Debug Information 更名为 Information 并移到 Attach 之前。
- **Tools**：自定义工具插到 Configure Tools… 之前（对齐 CB ToolsManager）。
- **Settings**：按 CB 顺序排列 Environment / Editor / Compiler / Debugger / Global Variables / Backtick Cache；clangd 维护入口收拢为 `clangd / IntelliSense ▸`；Keybindings / Default Config 置后。

## ⚙️ 可用性与设置

- `needsProject` 修正：`Code Statistics…` / `TODO List` / `Export compile_commands.json…` / Save Project / Close Project / Project Properties / Remove Files / Workspace Build Order 补齐；`Find File…` 不再误标。
- 新增 `needsWorkspace` / `needsDebugSession`：分别标注“（无 .workspace）”“（无调试会话）”。
- `Categorize by File Types` 用 check / list-flat 图标表示当前开关状态。
- Settings 过滤串改为扩展作用域 + 对应设置组：Editor / Compiler / Debugger / Build & Log 不再打开全部 VS Code 编辑器设置或只命中单个键。
- `Export compile_commands.json…` 无工程时给出提示（此前静默无反馈）；AStyle 格式化、Open Include File 无编辑器时给出提示。
- 无工程 / 无 .workspace / 无调试会话的项保留可见并统一标注，不隐藏、不置底。

## ⚠️ 行为变化与升级提示

- Menu 一级列表不再出现 Workspace / Recent Projects，改到 File 菜单内。
- 标签调整：`New…` → `New ▸ Empty File`；`Project tree` → `Project Tree`；`Debug Information` → `Information`；`Search Project Files…` → `Find Project Files…`。
- `Export Makefile…` 从 Tools 移到 Build。
- `TODO List` 从 Search 移到 View；`Find Next/Previous Selected`、`Goto Next/Previous Changed Line` 从 Edit 移到 Search。
- 菜单快捷键仅显示扩展实际声明/托管的键位；Move Project Up/Down 的 Ctrl+Shift+Up/Down 仍只在工程树聚焦时生效。
- 不新增命令与设置项（命令 **118** / 设置 **88** / 视图 **6** / 快捷键 **34** 不变）；不修改 `.cbp` 数据模型与保存协议。
- 版本号 `0.8.153`；VSIX 文件名 `codeblocks-vscode-0.8.153.vsix`。
