- **CB 证据**：`projectmanagerui.cpp:958/1042/1062/1469` `_("Find file...")`（工程/文件夹/工作区节点右键；

## 3. D 组：调试器（缺口 3 项 + 记录 3 项）

### D1 ✖ Detach（分离调试器，目标进程继续运行）

- **CB 证据**：`debugger_menu.xrc` 菜单项 `Detach`；`debuggergdb.cpp:2488` `m_State.GetDriver()->Detach();`
  （GDB 侧 `detach`，被调试进程脱离且继续运行）。
- **扩展证据**：`gdbDebugAdapter.ts` 无 detach（0 命中）；VS Code「Stop」= terminate（杀进程树）。
- **影响**：调试 GUI 程序后想让它继续跑（不杀）无法做到；只能重启程序。
- **建议**：⭐ 实施（XS，≈30 行）：命令 `codeblocks.debug.detach` → DAP disconnect
  `{ terminateDebuggee: false }` → 适配器发 `-target-detach`；**需实测 MinGW GDB 8.1 兼容性**（崩溃风险
  与既有 `-exec-finish` 同类需验证）。

### D2 ✖ Add symbol file…（运行时加载附加符号文件）

- **CB 证据**：`debugger_menu.xrc` 菜单项 `Add symbol file`（对已加载模块 `add-symbol-file <file> <addr>`）。
- **扩展证据**：`gdbDebugAdapter.ts:311` 仅在 **attach 时**可选符号文件（"可选符号文件（附加前加载…）"），
  无运行时交互命令。
- **影响**：调试 dlopen 插件/无符号主程序时无法手工补符号。
- **建议**：⭐ 实施（XS，≈40 行）：命令 `codeblocks.debug.addSymbolFile`（输入路径 [+可选基址] →
  `add-symbol-file` → 输出通道回显）。

### D3 ✖ 调试菜单补项（Run to Cursor / Remove All Breakpoints / Set Next Statement）

- **CB 证据**：`debugger_menu.xrc` 含 `Run to cursor` / `Remove all breakpoints` / `Set next statement`。
- **扩展证据**：`codeblocks.debug.setNextStatement` 命令**已存在**（round 49）但未接入 Debug 菜单；
  Run to Cursor（VS Code 原生 `editor.debug.action.runToCursor`）与 Remove all breakpoints
  （`workbench.debug.viewlet.action.removeAllBreakpoints`）未映射。
- **影响**：仅菜单可达性；功能本体已具备。
- **建议**：⭐ 实施（XS，≈20 行，纯菜单接线 + 菜单测试同步）。

### D4 ▷（不建议）CDB / WinDbg 调试器支持

- **CB 证据**：`debuggergdb/cdb_driver.cpp`、`cdb_commands.h`（同一插件内建 Microsoft CDB 驱动，
  `Active debuggers` 菜单可切换 GDB/CDB）。`debugger_menu.xrc` 首项 `Active debuggers`。
- **扩展证据**：仅实现 GDB（`gdbDebugAdapter.ts`）；MSVC 编译 XML 已打包（msvc17），但 **MSVC 产物无法在本扩展内调试**。
- **影响**：MSVC 用户需依赖 VS Code 的 `cppvsdbg`（微软官方，不属本扩展范围）。
- **建议**：**不实施**（L 级：需完整实现 CDB 协议/命令层）；文档注明「MSVC 调试请使用 C/C++ 扩展（cppvsdbg）」；
  本轮记录。

### D5 ▷ 指令级步进菜单（记录：已等价）

- **CB**：`Next instruction` / `Step into instruction` 菜单项。
- **扩展**：DAP `supportsSteppingGranularity: true`（`gdbDebugAdapter.ts:234`）+ `granularity=instruction`
  处理（:686-687）；VS Code 由步进粒度下拉暴露，无需独立菜单。**记录（已等价）**。

### D6 ▷ Active debuggers（记录：n/a）

- VS Code 单调试适配器模型，无插件切换概念。**记录**。
