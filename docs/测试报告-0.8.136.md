## 3. 本版变更与回归范围

| 项 | 说明 |
|---|---|
| 新增设置 | `codeblocks.workspace.pathGuard`（`off` / `prompt` / `auto`，默认 `prompt`）——检查工作区路径是否含 glob 元字符（`[ ] { } * ?`），报告命中段与 VS Code 实际使用的搜索根，并可把 `.github/instructions` / `.claude/rules` 两处 AI 指令扫描写入**用户设置**（`chat.instructionsFilesLocations = false`，不写工作区 `.vscode/settings.json`） |
| 新增命令 | `codeblocks.checkWorkspacePath`（`Code::Blocks: 检查工作区路径`） |
| 新增单测 | `tests/test-workspace-path-guard.js`：元字符判定（含未闭合/转义）、搜索根截断（含 UNC）、文件计数上限与盘符根短路、设置合并幂等、设置与命令注册 |
| 回归同步 | `tests/test-settings-structure.js`：设置项 81→**82**、配置分组 7→**8**；`docs/测试覆盖矩阵.md` 重新生成 |
| 行为边界 | 不改编译/链接流程、不改 `.cbp`、不禁用 Copilot Chat、不写工作区设置；`off` 时不自动检查（手动命令仍可用） |
| 已知限制 | 若目标 VS Code 版本没有 `chat.instructionsFilesLocations` 键，写入不会生效（输出中同时给出"改目录名"这条恒定有效的路径） |
